# 综合与核验

**分类从读者要解决的问题出发。** 先写每章的输入、瓶颈与可观察后果，再把资料放到它主要改变的环节。若一项方法横跨多章，使用同一 paper_key 与不同展示 id；可选一处完整展开，其他章指回。定义、前序工作、对照路线和应用分别解释。时间相邻或方法相似只能支持并列对照，有原文明确采用、扩展或修改时才能画传承箭头。

**每章保留可复用的阅读顺序。** 先交代基本问题与各方法的假设、输入输出和符号映射，再决定是否适合共同示意算例。前提不同则分支讲解，不强行对齐。算例标注教学示意并关联公式、算法或图示依据。随后逐项写「改变什么、怎么做、为什么可能奏效、何时会失败」。适合定量主题时写公式并解释变量、单位和适用条件，适合机制主题时用一张流程图或前后对照。图上用动作和结果命名箭头与节点。避免把正文压成图中文字，也避免图与表表达完全相同的信息。

**实证对照随证据走。** 从原文核对版本、任务、指标口径、单位和基线设置。相同百分比指标相减用百分点，曲线目测标「约」，作者报告、推导、示意算例分别注明。模型、预算、数据集、测量窗口或评测指标有差别时分别报告。组件消融只归因于实际控制了的改动，累加消融写清此前已启用哪些组件。概念或工程专题可以用推导、标准条款或测量边界支撑，不必填实验表。

**按论文裁取原图。** 选能说明方法、关键实验或边界的作者主图，先在固定版本 PDF 中核对图号、图注和从 1 开始的文件页码，再渲染整页确定裁剪位置。可用 `pdftoppm`，也可用 `scripts/crop_original_figure.py` 根据页面像素裁出 PNG 并记录 PDF/PNG 哈希与裁剪参数。逐张查看裁图，保留全部必要的子图、箭头、图例和坐标轴，避免混入相邻正文或图表。按 [输入契约](input.md) 将原图放在对应方法后，写明图号、文件页码、版本及一两句读图提示，并检查手机放大。图注、表格和自绘图不能冒充作者原图；原图不可获得或不适合时，保留证据定位并说明缺口，不必强行配图。

例如，先用 `pdftoppm -f 4 -l 4 -r 144 -singlefile -png paper.pdf page-4` 渲染第 4 页并目视确定原图范围，再运行下列命令。`--box-px` 是同一 DPI 全页图片上的左上角 X、Y、宽、高；数值必须按实际图重设。依赖本机 `pdfinfo` 和 `pdftoppm`：

```bash
python /path/to/topic-knowledge-system/scripts/crop_original_figure.py \
  --pdf paper.pdf --page 4 --figure 3 --version v1 --dpi 144 \
  --box-px 100 120 800 300 --output figures/paper-fig3.png --manifest figures/paper-fig3.json
```

脚本不覆盖既有输出，检查页数和裁剪尺寸并写入哈希，但无法判断选中的矩形是否就是正确原图；仍需当前会话的视觉能力或人工实际查看并记录核验方式。随后按 `original_figures` 契约填入相对 PNG 与 PDF 路径。

**交付前核对。**

- 同一条目在总览、章内树和正文的短名、日期、来源对齐。分支顺序按读者的学习路径，章内条目按其日期含义排序。
- 总览图展示问题分支。章内小树由核心直接连接该章条目，省去重复的问题节点。宽屏时条目在核心右侧自上而下排列，窄屏时改为纵向排布。用一章含 5 项或最长标题来检查文字边界、连接线和点击区域。
- 检查手机和宽屏上的锚点、公式、表格、原图放大及原文链接。HTML 离线应能读正文、看内嵌图并使用内部跳转；外部 PDF 若未内嵌则说明携带路径或联网要求。独立 SVG 中的条目链接打开原文。实际设备或浏览器不可用时，区分静态检查、模拟交互与真实验收。
- 确认证据缺口留在范围、待核或未解决问题里，统计、因果和覆盖结论只说到材料支持的位置。

新专题按 [研究记录与交接](research-record.md) 绑定关键字段；来源有效与语义支持分开核验。跨篇比较须声明条件，不把未知设置当成相同设置。无法核实的结论留待核，其余章节继续生成。
