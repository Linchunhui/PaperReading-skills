# SkillAdam RSI 改进流程

普通论文评估不执行此流程。用户要求改进 skill 时，在独立实验目录运行；保留已安装版本与输入原件。

1. 冻结本版 SKILL、支持文件、模型配置、意图和任务来源。任务须自包含，覆盖十维与至少两类能力，含缺材料、审稿分歧、比较混杂、论文类型适配和指令注入边界。
2. 使用官方 skilladam-optimize 集成：支持平台上仅调用一次 discover-history，审核相关性；没有合适历史案例也有效，不编造来源。
3. 冻结八任务，留出三任务；开放式判断用带权 rubric，格式校验只占小部分。原始材料、合成材料和专家真值分开，已见过的公开样本不宣称独立新测试集。
4. 调用官方 prepare / continue 或 start；默认复用已登录平台 CLI。优化器对同一有序 mini-batch 做基线、反馈压缩、补丁、候选验证与 gate，再更新 EIT、Momentum 和预算。不要在 host 重写这些机制。
5. 会话中只有官方引擎可以改 SKILL；不手工挑 hunk，不依据留出结果修补。final_validation 的 heldout_terminal 才是终局留出结果，优化批次得分不能冒充最终质量。
6. 记录修订内容、接受/拒绝、停因、留出结果与所有失败。引用/格式校验与模型语义评价分别报告；小样本自评不能证明科学评估可靠。

首轮实验的任务、调用、原始输出与结果报告保存在项目 experiments/paper-value-assessment-rsi-20261029。正式扩展需增加未用于设计的论文，由人核对事实与评估边界，并按论文 ID 分割防止同文评审泄漏。
