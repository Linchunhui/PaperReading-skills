# 同行评审证据

OpenReview 等评审是带来源的观点，不是单篇质量真值。保留原始 review_id、venue/year/track、量表、阶段、原始评分与自报 confidence；不能把 confidence 当作正确概率。需要归一化时另存规则与原值，未知初始评分不能补零。

处理顺序：定位具体观点 → 对齐主张/方法/实验 → 关联作者回应 → 查后续逐项认可 → 有独立检查时记录范围。录用、meta-review、改分只属于背景。评审之间有分歧时保留双方及理由；不平均后抹平异议。

四种不同事实：作者承诺未来给代码；链接检查已可访问；执行日志表明程序已运行；相同条件结果与论文相符。后者才支持对应范围的复现判断。给出代码 URL 本身甚至不能证明链接可访问。

公开样本的限制：Aspects 的 fine labels 多为评论对象，不是有序质量级别；Re² 的初始分缺失不表示改分；PeerSum 小样本可能全为录用论文；ReGround 的对齐标签不是科学真实性标注。人工观点标签、LLM 标签、自动对齐和本 skill 的生成判断分别保留。

关于数据集、许可与本次设计输入，见 sources.md。未经针对性校准，不用审稿总分训练一个跨会议“质量真值”。
