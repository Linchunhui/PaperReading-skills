# 评估与理由

| 维度 | 生成结论 | 主要依据 |
|---|---|---|
| B1 创新实质 | 相对具体前作改变/沿用什么 | 贡献、机制、实际取得的前作；只读本文说明归因与范围 |
| B2 问题重要性 | 哪个瓶颈影响什么用途 | 问题与受益范围，潜在影响与已验证影响分开 |
| B3 实质进展 | 同条件收益、代价、退步或新增能力 | 原值、指标方向、任务、数据、预算、假设、误差 |
| V1 可借鉴性 | 可用模块/配方/资源及迁移前提 | 机制、接口、资源和迁移证据；未运行不声称目标收益 |
| Q1 技术自洽 | 已检查部分的自洽/疑点 | 方法、公式、假设、反例或执行记录；未发现错误不等于证明 |
| Q2 主张支持 | 主要结论的支持与缺口 | 主张→实验/消融/证明；实验数量不代替支持程度 |
| Q3 比较有效 | 哪些对照可比、哪些混杂 | 模型/数据/split/预算/过滤/硬件/协议；固定更新量不等于固定成本 |
| Q4 稳健边界 | 已验证设置与不稳定情形 | 跨设置、误差、失败、退步、假设；缺OOD不自动判差 |
| Q5 复现准备 | 声明、可访问、运行分别到哪 | 材料/依赖/许可和核查记录；未开源不自动低质量 |
| Q6 报告完整 | 定义、条件和范围是否清楚 | 文本/图表/设置；排版问题与核心解释缺失分开 |

创新回答“改了什么”，突破还要求“重要问题上有充分支持的实质跨越”。缺独立前作比较，B1通常只能preliminary；作者first声明、冷门标题、向量距离都不能代替。

只有 B1/B2/B3/Q1/Q2/Q3/Q4 都 supported、存在具体前作比较和可比结果、没有未解核心反证，才生成正面 breakthrough 理由；否则保留范围内 progress，证据不足不填理由。数据/评测贡献可评价资源、任务和协议价值，不硬要求刷新模型指标。

理由来自已生成判断和事实，不重写摘要。角度是候选池，不是必填栏；同一事实不跨角度重复包装。优先选能说明为什么读、能拿走什么的2—3条，必要条件就近保留，其他说明放scope/caveat。不用无依据的“显著提升”代替结果。

评审观点、作者回应、后续认可、独立验证分开。承诺补实验不等于已完成；录用和均分不代替真值。
