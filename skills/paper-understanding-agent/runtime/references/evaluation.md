# 评测与迭代

只在构建评测集或对照版本时使用本规程；正常分析论文不额外启动建集和阅卷。

## 固定输入和答案点

用同一版本的论文材料生成正常结构化输出，待测模型不能看到参考答案、得分点或其他配置的预测。保存输入、Skill 版本、输出与参考点的哈希。已有流程是基线时保留原有流程，不换成空提示。

先从原文形成独立参考点，再做预测。一个点描述一个可核查的对象—关系—限定，保存 `point_id / field / proposition / weight / full_match / partial_match / critical_qualifiers / evidence / label_status`。证据包含论文版本、unit_id 和连续原文片段。机器生成与复核的答案称银标；多个 Agent 同意不能使它成为专家真值。

核心点权重2、支持点权重1是可用的起始约定。权重和半分规则在测试前冻结；见到系统结果后不为分数调答案。标签确有错误时保留旧版本和改动理由，并重评所有配置。

## 分开评分

| 模块 | 评什么 | 不能替代它的检查 |
|---|---|---|
| 身份与资源 | 标题/标识符匹配、作者—机构配对、日期类型、资源状态准确性 | JSON 能解析 |
| 八字段理解 | 参考点覆盖、关键关系与条件、字段错位；新增主张回源 | 相似词出现次数 |
| 实验结果 | 模型/任务/数据划分/指标/值/单位/方向/条件的对应及漏项 | 单个数值匹配 |
| 价值与质量判断 | 判断—支持证据—反向证据—范围是否一致；缺证据时是否克制 | 与参考的 strong/moderate 标签一致 |
| 推荐理由 | 是否有具体收益或机制、必要限制、证据；理由之间是否重复 | 流畅、好听或条数多 |
| 借鉴建议 | 模块、迁移前提、操作与最小验证是否具体；执行状态是否真实 | 建议声称能提高效果 |

主分范围预先定义。评八字段时，事实库和阅读卡里存在的内容不能补八字段漏点；它们可以另报覆盖。跨字段命中可得分，同时记录错位。

- `full=1`：对象、作用关系与必要条件完整，接受同义表达。
- `partial=0.5`：只缺可分离的非决定部分，且参考点允许半分。
- `missed=0`：未表达、只有术语，或缺决定性关系。
- `contradicted=0`：对象/数值/关系或条件错误改变结论，另列错误。

加权覆盖率 = Σ(权重×命中分) / Σ权重。每个参考点只计一次；重复不加分；一句话可以覆盖几个不同的点。另报各字段覆盖和宏平均，避免总体分数掩盖某模块失败。

反向拆解预测中的原子主张，回原文标 `supported / contradicted / unsupported / uncertain`，记录预测与原文的精确片段。参考点未收录的正确补充不算错。抽查时说明抽样范围，只报抽查支持比例和错误，不能冒充全部事实准确率。

## 阅读效果与复核

在覆盖和正确性可比的前提下，比较有效信息密度、重复、必要限制和清晰度；短本身不加分。可辅助报告“获得的加权点/正文字符数”，但不同参考点集之间不可直接比较，也不能用该数鼓励删限定。

采用隐藏配置的 A/B 阅卷；需要复核时由不同上下文独立判分，再核对分歧。记录逐点状态、预测片段、证据和理由，使用固定程序汇总。公布样本数、重复次数、模型、评委、银标属性及已用于迭代的样本。保留未见论文作为后续验证；调过的案例只能算回归。

按失误类型改通用规则，例如“关键奖励不能只存于事实库”，不往 Skill 写特定测试论文答案。保留失败版本和评分记录。先修漏核心关系与无依据断言，再压缩重复；没有实测 token 或耗时时留空，不用字符数伪装成本。

## 完整阅读交付

完整解读另外评测实际渲染文本的语义要点覆盖、解释关系、主张与证据及重复；事实库或未渲染字段不能补阅读得分。字符数只作描述，不是深度指标。比较固定输入、模型和设置；调用日志区分实际独立模型turn、重试、缓存复用与阶段产物。旧多Skill内容链与完整入库流程范围不同，成本和耗时不能直接当同任务对比。
