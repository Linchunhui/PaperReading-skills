# 论文完整理解

对外一次提交，内部多次调用模型，最后返回统一论文记录和可以直接阅读的完整解读。用户明确要求短摘要、首页卡片或局部模块时再缩小输出；默认完整解读需要讲清研究背景、具体问题、解决思路、关键方法以及实验和结果。

## 执行流程

接受已解析文本、保留页码和原文单元的解析记录。先读[流程](references/workflow.md)，按需读[字段契约](references/contract.md)。PDF获取解析接已有工具；没有真实页码就保留片段编号，不猜页号。正文从题名作者摘要到结论，参考文献、附录与致谢分别标记；正文后的署名和机构可作为独立元数据来源。

完整处理时使用 scripts/run_workflow.py：逐页抽取各一次独立模型调用，按章节再分别调用总结，随后分别调用元数据归并、整篇理解、十维评估和阅读内容生成；参考文献另用完整区域或不切断条目的批次独立调用。每阶段输入包含其原始材料及需要的上游结果，不只传层层压缩的短摘要。缺失或失败保留状态和原始响应，只重试受影响阶段；不要把保存多个JSON文件计作多次模型调用。

模型调用后，使用 scripts/assemble_record.py 合并与校验来源、身份、范围和依赖，生成统一 paper-record.json。完整阅读输出使用 scripts/render_card.py --mode detailed；另需短卡时使用 --mode compact。完整模式不经过 display.highlight_item_ids 筛选。真实调用日志记录请求、响应、调用身份、上游指纹、重试和实际使用量；未知使用量留空。

## 抽取与解释

先抽取事实再解释：标题、完整可见作者、机构及对应、日期与类型、原始摘要、venue、标识符、代码/数据/项目链接，以及全部可见参考条目均属常规产物。正式作者与贡献者角色分开；缺失和冲突写明，不能把生成摘要当原始摘要，也不能把资源声明当访问或执行。

逐页事实保留原文连续证据和单元ID；数字带主体、任务、数据/划分、指标、单位、方向及关键比较条件。本文、前作、评审、回应和执行记录分开归属。模型不能用外部记忆补材料未提供的结果或身份。

解释机制时区分原文明确陈述、由公式或操作直接推出的含义，以及仅属合理猜测的功能解释。不得仅凭组件名称推断其具体作用，也不得把启发式操作改写成已证明的效果；描述迭代更新时严格限定原文指明的操作对象，不能由“重掩码本轮预测位置”扩写为此前已解除掩码的位置也会再次修改。确需推断时标明 basis、限定措辞，并引用足以支持该推断的单元，图注只能支持其明确写出的数据集或图表范围。

整篇 understanding 的八字段与 content_products.deep_read 均要承担实质解释。背景说明任务场景和研究动机；问题指出已有路径在什么条件下遇到何种瓶颈；思路说明本工作改变了哪一环节、为何这样设计；方法讲清输入、操作、输出、阶段关系以及影响理解的训练目标、推理或数据构造过程。不要把多个重要步骤压成方法名清单或一条长句。

实验与结果说明每组关键实验要验证什么、对照与指标如何设置、观测到了什么，以及它如何支持或限制主张。保留主要正向、持平和负向结果，必要时解释消融与成本取舍。作者给出的机制解释与实验已证明的因果结论分开。理论论文展开假设与命题；系统、数据和评测论文展开接口、构造和协议，不硬套刷新模型指标。

## 完整解读与短版

先形成整篇理解，再单独生成完整 deep_read，最后按需生成 abstract、home_digest 和短卡。deep_read 是可直接阅读的连贯说明，围绕背景、问题、思路、具体方法、实验与结果、结论和边界组织自然段；贡献复杂时分模块展开。每段保留可追踪依据，解释事实之间的关系，而非仅将既有短条目换组重放。

写作充分程度由解释链是否闭合决定，不用最低字数、固定条数或泛泛背景凑长。读者应能回答：旧路径为什么不足；本设计接在哪里、改变什么信息或训练信号；具体如何执行；哪项证据支持这一变化、哪些结论仍不确定。删重复、空话和无关细节，保留理解和复用核心贡献必需的细节。材料不足时如实说明，不能编造解释。

完整模式保留这些展开内容；短卡才选择核心定位、机制、主结果与必要边界。推荐理由从质量、价值、创新与进展中选择有依据且不同义的角度，说明具体受益者与可带走的东西，不能只重复摘要或泛称创新高。借鉴建议给出前提、改造和最小验证，未运行不声称迁移收益。

价值评估按[十维规程](references/assessment.md)分别记录支持、反向证据、条件与缺口。缺独立前作时创新通常只能初步；突破性还需重要问题、可比实质进展和充分可靠性证据，不能用作者自称、热度或录用替代。

## 检查与评测

检查原文到事实、事实到整篇解释、整篇到实际渲染解读三层是否丢失关键关系。核对公式、数值、单位、主体、比较条件和反向结果；缺图表或解析损坏明确标记。格式与引用通过不代表解释充分或科学正确。

评测使用[冻结要点规程](references/evaluation.md)，同时检查实际阅读解读。信息密度是具体、正确且有关系的信息，不是短句数量；重复得分点和无证据扩写不加分。新对照采用同一输入、同一模型设置并保存真实调用轨迹，不将单上下文阶段撰写的旧结果冒充独立多次调用。

自然语言研究方向、问题签名、本文相关工作差分保留；分类体系重建、跨论文聚类和知识图谱另由外部流程承担。完整流程schema见 references/workflow-output.schema.json，旧1.0核心兼容契约见 references/output.schema.json。
