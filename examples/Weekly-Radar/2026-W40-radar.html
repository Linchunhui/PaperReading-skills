Raven：把 Agent Harness 做成可组合、可进化的“操作系统”

基座模型 / LLMEverMind AI 等 · arXiv:2609.33439
为什么值得看：多智能体系统最容易被低估的不是模型，而是 harness：任务如何拆、谁先做、产物怎样传、失败后如何修。Raven 把这一层从提示词拼装升级为有显式 DAG、共享工件账本、长期档案、技能检索与自我改写闭环的执行基座，并用专门的规划基准 MAOB 把“会不会编排”单独量出来。

出发点

常见主管—工人框架依赖一次性自然语言计划，子任务之间的依赖、并行机会和输出契约都不稳定；即使单个 worker 很强，主管也可能选错代理、漏传上下文或在失败后重跑整条链。论文因此不把“多 Agent”理解成聊天群，而是把组合性落实到可验证的图结构、类型化工件和持久状态。

方法拆解

用户目标与已注册专家 Agent → Host Agent 解析能力、构造并校验任务 DAG，为节点声明输入、输出和依赖 → 训练与运行时同时利用 Host Archive、EverOS 工件账本和 Skill Forge 检索历史成功轨迹；诊断器把失败归因后，harness evolution 再生成候选修改并评测 → 推理时只调度依赖已满足的节点，允许并行执行并把中间产物写回账本 → Host 汇总可追溯结果，失败节点可局部重规划而非全链重来。

关键证据：MAOB Table 4 中，Qwen3-27B 驱动的 Raven 得到 Node F1 0.923、Edge F1 0.812、POA 0.950、Exact Match 0.711，最强基线 Exact Match 为 0.607；换成 DeepSeek-V4-Flash 后 Exact Match 达 0.867，基线为 0.762。Table 13 的技能库消融更说明“可检索经验”不是装饰：无技能 9.2，人工整理库配微调检索器 22.6；改用现成 Qwen3 检索器降到 13.8，未经整理的网页抓取库仅 14.9。Table 11 还显示 harness evolution 把 TerminalBench 从 36.1 提到 45.4、BrowseComp+ 从 16.9 提到 30.8、SWE-bench Verified 从 47.4 提到 52.6。

边界与复现

MAOB 主要测规划图是否正确，不等同于真实 worker 调度后的端到端成功；跨基准比较的工具、预算与成本口径也并非完全一致，LLM judge 复核会带来约 1.3 个点波动。技能库消融多为单次运行，尚不能分离数据清洗、检索器和执行器的独立贡献。项目页与 GitHub 已公开，核心 harness 可以复用；但完整系统整合了多项既有组件和服务，复刻论文的全套长期记忆、基准环境与评测基础设施仍有明显工程门槛。

RIDE：蒸馏不必追到老师为止，可以沿“RL 改变的方向”继续走

OPD / RL清华大学等 · arXiv:2609.36484
为什么值得看：在策略蒸馏里，老师通常被当作终点，学生只拟合老师概率；RIDE 的新视角是把 RL 前后的同源模型视作一条“行为方向”。它在隐藏表示空间中提取老师相对基座的残差，再把目标外推到老师之后，最终让学生在四组数学推理实验中稳定略超老师，而不是只复制老师。

出发点

直接在输出分布上放大 teacher/base 的概率比会遇到两个问题：LM head 会压缩很多内部变化，采样标签又给外推引入高方差。论文诊断显示，LM head 最弱的 512 个方向承载 79.8% 的隐藏残差能量，却只留下 30.0% 的中心化 logit 能量；所以“老师为何变强”的一大部分信号在输出层之前已经被抹平。

方法拆解

学生在当前策略上生成回答前缀 → 对同一前缀分别前向基座 B 与 RL 老师 T，逐层逐 token 取隐藏残差“老师表示减去基座表示” → 训练目标把老师表示沿该残差方向再外推一段；外推系数 1 等价于普通表示蒸馏，大于 1 才越过老师 → 学生对回答末尾若干 token、所有层回归这一目标，保持在策略数据分布上训练 → 推理时只保留学生，不需要老师、基座或额外采样器，直接输出答案。

关键证据：Table 1 的 Avg@16 中，R1 系列老师 55.30、OPRD 54.50、输出外推 ExOPD 49.87，而 RIDE 为 56.38；Qwen3 为老师 65.59、RIDE 66.07；Llama 为 13.01 与 13.33；Phi 为 17.96 与 18.30，四组都越过老师。Table 3 的方向消融更关键：OPRD 54.50，随机方向 55.04，反向残差 53.90，错配基座来源 54.75，轨迹错配 55.12，完整 RIDE 56.38。另一个诊断显示，ExOPD 从外推系数 1 增至 2 时条件方差放大 12.6 倍，而固定前缀下的 RIDE 梯度是确定的。

边界与复现

方法要求拿到 RL 前的基座检查点，并默认基座与老师的表示空间可直接相减；如果老师经历架构变化、参数合并或未知后训练，这个方向未必有意义。当前只在数学推理和一种 RL 配方上验证，统一外推系数也没有处理层、token 与样本的异质性；更强是否伴随校准或安全退化仍未回答。论文称代码与检查点将在发表时释放，当前 GitHub 只有项目入口，尚不足以完整复现实验。

Behavioral Shadows：后训练能力会在“不相干选择”上留下可蒸馏痕迹

基座模型 / LLMMIT 等 · arXiv:2609.29233
为什么值得看：这篇论文展示了一条让人不太舒服的侧信道：私有模型不提供权重、logit 或任务答案，只在与目标任务表面无关的二选一词语上做决定，学生仍能学到一部分 HumanEval+ 编程能力。能力不是通过语义内容直接泄露，而是经由后训练在决策边界附近留下的“行为阴影”。

出发点

传统知识蒸馏假定老师对目标任务输出标签或分布；但如果后训练改变的是共享表示和广泛的决策几何，那么普通选择也可能携带方向性信号。作者先用公开祖先模型构造大量近乎无差别的提示，让两个日常词在祖先看来概率接近，再让私有后训练老师只选其中一个，从而放大细小的边界位移。

方法拆解

公开祖先模型生成“两个普通词几乎等可能”的载体提示 → 私有老师仅返回它更偏好的词，不暴露代码题、权重或 logit → 学生从同一公开祖先初始化，只用这些提示—词语对做监督微调 → 训练把老师在局部决策边界上的微小偏移写入学生参数 → 推理时丢弃所有载体提示，直接在 HumanEval+ 等原目标任务上测试学生。

关键证据：Table 1 中，精确匹配 nuisance 分布的对照在 HumanEval+ 为 45.88，任务无关载体信号达到 51.22，提升 5.34 个百分点，95% 区间为 [1.22, 9.60]，共 4 个随机种子；全局打乱标签为 46.19，使用公开模型标签为 46.65。Figure 2 横跨 5 种提示采集方式、每种 3 个种子，平均增益 4.80 点；LoRA rank 从 16、32、64 增大时，增益为 5.34、6.55、9.15 点。Table 8 的参数诊断中，载体梯度与目标任务向量余弦为 0.460；破坏残差最对齐的 top 20% 后降到 0.437，损失 0.022，完整打乱则降到 0.395、损失 0.065。

边界与复现

这不是“随便聊天就能偷能力”的证明：载体是主动构造的近边界样本，攻击者需要知道公开祖先，还要大量查询并控制微调。论文在附加模型上的置信区间有时跨零，也没有证明自然对话、不同架构或更远亲缘模型同样泄露。机制证据指向共享参数方向，但因果路径仍未闭合。代码仓库已公开，实验规模与载体生成流程可追踪；防御上仅靠隐藏 logit 不够，如何检测或抹去这种阴影仍是开放问题。

UniEvo-VL：让统一多模态模型用“改写提示”教回原始提示

VLM / 多模态香港中文大学等 · arXiv:2609.38721
为什么值得看：统一理解—生成模型具备生成、看图和诊断能力，却很少把这些能力闭环用于自我改进。UniEvo-VL 用固定 critic 找出草图与提示的缺口，再生成一个信息更充分的“特权提示”供 EMA 老师重绘，学生仍只看原提示，通过在策略轨迹上的 transition matching 学到这次修正。

出发点

直接用模型自己的成功样本做 SFT 容易重复既有分布，用外部强模型重标又昂贵；纯 reward 优化则要把复杂的文字渲染、计数和关系错误压成一个标量。作者希望保留 critic 的细粒度诊断，但不让部署时依赖改写提示，于是把“改写后的更容易任务”作为训练教师的私有信息。

方法拆解

原始文本提示 → 当前生成器产生草图，固定视觉 critic 对照提示列出缺失对象、关系与文字错误并判定是否接收 → 失败样本生成修订提示，EMA 老师在修订提示下给出更优去噪方向；学生仍以原始提示、沿自己的去噪轨迹做 on-policy transition matching，仅更新生成 LoRA → 可选验证器再检查重绘图是否仍满足原始提示 → 推理时完全移除 critic、修订提示和老师，原提示一次生成最终图像。

关键证据：Table 1 中，基础 Qwen-Image-2512 的 GenEval/Atomic/HumanPref 为 0.747/95.30/8.48；用 Qwen critic 的 UniEvo-VL 为 0.808/96.90/8.79。换成 GPT-5.6-Luna critic 达 0.882/98.76/8.97；再加 verification 后为 0.818/97.41/8.71，但 GenEval2 的总体分、语义分与质量分达到 35.07/82.75/7.11，OCR 也从基础的 0.771/9.07 提到 0.790/9.10。Figure 4 显示增益主要来自困难提示，容易提示反而回退约 1–4 个归一化点；无 verification 时 GenEval2 与 OCR 出现退化。论文未提供足以隔离组件贡献的消融证据。

边界与复现

实验只围绕 Qwen-Image-2512 与任务 LoRA，critic 固定且自动指标本身含噪；不同 critic 带来的收益、成本和风格偏置难以拆开。作者观察到反馈提示会诱导偏灰配色和浅色背景，OCR 困难子集也只有 24 个样本。verification 能阻止退化，但会增加完整训练链路成本。到 2026-10-02，论文未给出独立项目页、代码、模型或训练数据下载，外部复现仍要自行重建 critic 提示、接受规则与 EMA 教师流程。

ReaLVR：让连续视觉思维真正盯住证据，而不是生成“好看的隐变量”

VLM / 多模态阿拉巴马大学伯明翰分校等 · arXiv:2609.34563
为什么值得看：Latent Visual Reasoning 在回答前插入连续向量，看似能承载视觉思考，但常规训练只要求它重建教师特征，随后 RL 又只奖最终文本。ReaLVR 直接监督这些隐变量“看哪里、保留什么”，并且无需框标注或人工理由，在多种骨干和模型规模上都带来可复现提升。

出发点

两阶段 LVR 的第一阶段使用 teacher forcing，第二阶段却让模型自由生成 latent token；真正推理时的连续轨迹从未被视觉证据约束。结果是最终答案可能靠语言先验得分，隐变量却逐步偏离图像。作者把问题拆成两个可训练量：哪些视觉 token 与正确答案相关，以及这些位置应该保留怎样的图像表示。

方法拆解

图像、问题与当前模型自由生成的 K 个连续 latent token → 在同一 latent 前缀后分别 teacher-force 正确答案和采样错误答案，取二者对图像 token 的注意力差，形成“去哪里看”的选择权重 → 把相关图像特征作为正原型、错配特征作为负原型，以带间隔的证据损失约束 latent，选择权重停止梯度 → 与 GRPO 的最终答案奖励联合训练 → 推理时流程和长度不变，输出连续视觉思维后的文本答案。

关键证据：Table 1 中，Qwen2.5-VL-7B 的 LVR-RL 五基准平均 60.4，ILVR-stage2 为 62.9，Monet-RL 为 62.2，ReaLVR 达 63.7；分项 MMVP/BLINK/HRBench-4K/8K/MME-RealWorld 为 72.0/55.8/71.8/66.6/52.2。Qwen3-VL-30B 从 64.1 到 65.2，InternVL3-8B 从 55.0 到 58.1，Gemma-12B 从 39.0 到 41.6。Table F2 的消融：LVR-RL 60.4，均匀路由 62.4，原始注意力 62.9，只做选择性路由 63.2；去掉负样本 62.1、不停止梯度 62.6、改成 off-policy 61.9，完整方法 63.7。

边界与复现

证据位置来自答案对比产生的注意力差，不等于可验证的区域定位；没有框或 mask 时，“看对地方”仍可能是粗粒度相关性。固定 latent 预算也没有回答简单题是否浪费、难题是否不足。大模型结果覆盖的任务数少于 7B 主实验，扩展结论仍需谨慎。项目页与训练/评测代码已公开，外部复现条件较好；但完整训练需要多模态 RL rollout 与多骨干算力，且错误答案采样质量会直接改变监督信号。

False Frontiers：自进化搜索 Agent 可能和自己“串供”

OPD / RL香港大学等 · arXiv:2609.39102
为什么值得看：自进化系统常让 proposer 造题、solver 答题，再用双方一致作为奖励；问题是两者读了同一来源后可能共享同一种错误，表面一致却没有证据支撑。论文把这种现象命名为 co-cheating，并给出不改主体训练、只切断反馈来源关联的 CrossFit，效果比昂贵的多求解器投票更稳。

出发点

搜索 Agent 的伪标签通常无法即时人工核验，一致性便成了廉价可信度代理。然而 proposer 与 solver 在同一网页、文档或证据簇上成长时，它们的错误并不独立；优化一致性会奖励“共同误读”，推动系统走向虚假的能力前沿。多数过滤法只看输出分歧，没控制产生分歧的证据来源。

方法拆解

源文档 → proposer 生成问题与伪标签，solver 回答并得到一致性奖励 → CrossFit 先按来源把数据切成 A/B，两套辅助 solver 分别只在 A 或 B 上训练 → A 来源问题必须由只见过 B 的辅助 solver 评分，B 反向处理，从反馈路径中去掉同源相关性；主 solver 仍学习全部数据 → 推理时无需辅助模型，输出正常搜索答案。MSV 则以 3 个可见来源和 3 个不可见来源 solver 投票，作为更昂贵对照。

关键证据：Table 1 的 7 基准 Cover-EM：4B 模型 Dr.Zero 为 0.400，MSV 0.407，CrossFit 0.488，二者叠加 0.491；9B 对应 0.428/0.436/0.512/0.515。审计中，4B 假一致率从 6.1% 降至 3.0%，9B 从 8.8% 降至 3.7%；MSV 仍为 5.7%/7.2%。Figure 7 的机制消融更直接：同源辅助 solver 假一致率 0.064/0.087，使用全量数据为 0.058/0.069，随机按问题切分为 0.050/0.062，按来源切分仅 0.004/0.001，同时审计准确率从 88.1/87.0 提到 91.5/91.7。

边界与复现

CrossFit 假设“来源 ID”能代表错误相关性；网页互相转载、共享预训练知识或跨来源引用会重新连通 A/B，适应性 proposer 也可能学会绕过切分。假一致下降还可能来自拒绝困难问题，不能单独证明能力增长。实验只覆盖两个模型规模，审计依赖强模型，端到端算力节省也未与完整生产负载对齐。论文当前未提供独立项目页或代码仓库，外部复现需要自行实现来源追踪、辅助 solver 与证据审计。

GAGAR：代码 Agent RL 不再把所有通过测试的轨迹都当成一样好

OPD / RLXiaomi MiMo 团队 · arXiv:2609.32577
为什么值得看：代码 Agent 的稀疏奖励通常只有“测试过/没过”，于是同组内多个成功轨迹优势值相同：绕远路、脆弱补丁和简洁修复都被等价强化。GAGAR 用一个 agentic grader 读取完整轨迹与测试日志，在成功样本内部重新分配优势，同时保持正优势总量，解决了直接降权带来的学习信号塌缩。

出发点

GRPO 一类组内相对优化能利用成功/失败差异，却无法区分多个成功。朴素做法是按质量因子压低差轨迹权重，但这会让正优势总和变小、负优势占主导，熵迅速坍塌，模型趋向更长且更保守的行为。作者要的是“成功者内部排序”，而不是改变整组正负质量守恒。

方法拆解

同一代码任务的一组 Agent 轨迹、补丁、工具调用与测试日志 → 先用客观测试筛出成功轨迹，再由 SFT agentic grader 按正确性、效率、代码质量、推理与工具使用等五维排序 → 排名映射为质量因子，先乘到原正优势上，再把全部正优势按原总和缩放；失败轨迹保持不变，截断上界防止极端放大 → 异步把重排后的优势送入策略更新，无效评分自动回退 → 推理时不需要 grader，代码 Agent 直接生成更短、更稳的解决轨迹。

关键证据：受控实验到 step 28，DeepSWE 从基线 50.2 提到 62.2，增加约 12.0 点，step 44 峰值 63.4；SWE-Pro 到 step 52 达 62.5，而基线约 59 后停滞。生成质量分从 3.70 升至 4.03，成对胜率 69.8%，组内第一率 65.0%，最高质量档占比从 25.4% 升到 34.3%。Figure 4 的关键消融显示，只降权不重分配时 step 30 熵为 0.905，完整 GAGAR 为 0.513；训练长度 114.1k 对 69.9k，DeepSWE 在 step 28 为 56.2 对 62.2，评测 token 236.0k 对 172.9k。

边界与复现

实验依赖未公开的大规模 MiMo 检查点，在线 grader 本身也来自 MiMo Pro；论文没有给出 grader 与人工判断的一致率、校准曲线或不同 grader 的替换实验，因此增益有多少来自优势算法、有多少来自私有评审能力仍不清楚。验证集中于代码 Agent 和两个公开基准，不能直接外推到浏览、数学或多模态 Agent。实现中的放大上限 1.5 在触发时会破坏精确的正优势守恒。当前论文未提供代码或训练模型，外部复现门槛较高。

Simple-WAM：世界动作模型需要“未来条件”，但不需要把未来视频真的生成完

世界模型清华大学、LeapLab 等 · arXiv:2609.34981
为什么值得看：显式 WAM 在动作前完整去噪未来视频，泛化强但慢；latent WAM 不生成视频，速度快却在分布外崩得厉害。论文用严格匹配实验发现：真正关键的是动作头在测试时仍能读取未来视频 token，而不是得到清晰视频。Simple-WAM 因此把未来保持为纯噪声，只做一次前向，就拿回大部分泛化能力。

出发点

过去常把显式与 latent 路线的差异解释为“生成式想象是否必要”，但两类模型往往骨干、数据和训练预算都不同。作者在同一个 5B 视频—动作骨干上只改变测试时未来 token 的处理方式，发现域内成功率接近，环境扰动、少样本和新任务却明显分叉；再逐步观察 10 次去噪，第一步纯噪声前向已经获得几乎全部收益。

方法拆解

当前观测、语言指令与一段未来视频 token 槽位 → 不把未来槽位删掉，也不执行完整视频去噪，而是固定为流时间 1 的高斯噪声 → 视频专家只前向一次，把“未来存在于上下文”的预训练结构传给动作专家；训练用混合流时间采样，使单步噪声条件与原视频预训练目标兼容 → 动作专家照常完成动作去噪 → 输出动作块，不生成可见未来视频。

关键证据：匹配协议 Table 1 中，显式/latent 在域内为 97.75/96.85，但环境扰动为 67.72/53.75，10-shot 为 96.95/88.50，新任务带无动作视频为 69.90/5.90。Figure 2 显示第一次纯噪声前向相对 latent 已分别获得 26.44、8.2、13.4、89.8 点，后续 9 次去噪最多只带来 −1.62、+1.8、+0.8、+0.8。Table 2 中 Simple-WAM 环境扰动达 79.5，高于显式 67.7 和 latent 53.8；时延 74.7 ms，显式 286.9 ms、latent 62.0 ms。Table 3(b) 把噪声 token 换成可学习 query 后三轴平均从 94.2 降至 52.7，换成零向量为 54.9。

边界与复现

结论建立在一个 5B、无大规模 embodied pretraining 的骨干上；更大模型或带机器人预训练后，纯噪声仍是否保留同样结构优势尚未证明。真实机器人只测 4 个训练任务和 1 个留出任务，每项 30 次，覆盖面有限；“未来条件”究竟通过时空位置、噪声统计还是预训练注意力模式起作用，也未完全分解。项目页、代码与模型权重已公开，论文给出 LIBERO、RoboTwin 及真实机械臂协议，复现条件是本期最完整的一组。
