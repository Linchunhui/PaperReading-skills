01 · VLM / 通用视觉定位

GroundingPI

把点、框和文字位置变成同一种可生成的接口

原稿 HF 候选日 2026-10-13 · arXiv 2609.39601 v2 · 身份与版本 · 一手全文

背景、任务与前作缺口

让机器人抓物、让 GUI 智能体点击、让 OCR 返回文字位置，都先要回答“目标在哪里”。输入是图像和指令，输出可能是点、框或文字—区域对。前作常为检测、指代、OCR 分别设计头部与字符串格式；密集框用普通数字文本串行生成，既长又难统一几何约束。本文的主贡献仍是语言条件感知，机器人与驾驶属于迁移验证，不能把所有定位输出都叫连续动作策略。

解决思路

改动从输出协议开始：将几何坐标作为语言词表中的原子 token，使不同任务共享可组合的视觉原语；再用与几何、覆盖率和识别正确性对应的奖励修正生成结果，而非只拟合文字答案。

具体机制：从输入走到输出

  1. 图像进入语言骨干。MoonViT-V2 编码图像，projector 聚合相邻 2×2 视觉特征，经两层 MLP 映射到 Qwen3-4B 的嵌入空间。指令决定要找什么；语言解码器自回归生成语义标签、协议标记和 1,000 个量化坐标 token（0–999）中的元素。没有所查类别时输出 None。
  2. 监督先把格式与位置对上。基础 VLM 先冻结两侧骨干只对齐 projector，再进行多模态训练。定位 SFT 对 assistant 响应中的标签、标记、坐标做下一 token 监督；先更新全部模块，再冻结视觉编码器与 projector，继续语言侧精炼。坐标不是一个额外检测头，而是响应的一部分。
  3. 奖励针对不同错误。GRPO 对同一图像—问题采样 8 个响应。定位奖励一部分按参考目标的最大 IoU 匹配看覆盖，另一部分检查类别、严格定位、重复框、格式、数量和顺序；OCR 则用 Hungarian 一对一匹配联合评估文字与几何。冻结 SFT 参考，只更新语言参数，组内相对优势鼓励更可靠的输出。
  4. 使用时解析结构。短坐标 token 还原成图像位置，可交给 OCR 解析器或下游控制模块。定位基座与下游策略不是同一对象；驾驶和机器人实验还包含相应适配。

主结果：整套方法支持什么

Table 3：SROIE / M6Doc 为 72.47 / 74.82，对比 GPT-6 Astra 53.57 / 60.59；34 项能力指标的综合平均为 73.68，对比 71.54。这里只能支持论文所用任务与协议下的总体表现：混合指标平均不能说明每一类任务都胜出，也不是等算力、等训练数据比较。

消融与分析：哪些设计起作用

Figure 10：改用文本坐标，综合分数由 73.68 降为 71.21，相对速度为 0.25×；去掉 Stage III RL 得 72.86。Table 5：COCO / Dense200 每框输出 token 为 7.6 / 5.1，SEED1.5-VL 为 148.8 / 74.5。前一个是表征选择的受控诊断，后一个是跨模型效率对照，不能混成同一因果实验。量化协议与后训练都贡献收益，但各任务收益并不一致。

带条件总结与迁移边界

小目标、高 IoU、TotalText、FSC147 与前沿 GUI 仍有短板；驾驶是 open-loop，不能推导闭环安全。坐标量化、分辨率、解析器与下游适配须一并固定。总结：如果系统需要统一的“看见并指出位置”接口，短坐标词表与任务特定奖励值得借鉴；它缓解的是感知输出碎片化，不是一次训练就得到通用机器人控制。

证据定位：正文所列 Section / Table / Figure 均指 GroundingPI 本次获取原文；没有运行论文代码，结果为作者报告而非本地复现。

02 · VLM / 空间机制分析

S-Space

把“看错了”与“坐标变换算错了”分开诊断

原稿 HF 候选日 2026-10-12 · arXiv 2610.13527 v1 · 身份与版本 · 一手全文

背景、任务与前作缺口

空间问题输入图像与对象关系查询，输出左右、上下、远近等判断。例如换到桌子背面看，杯子是否还在苹果左边？只看答题准确率无法区分视觉感知、空间表征和视角计算的错误；普通 probe 能解码位置，也不能证明模型真的使用了这份位置。

解决思路

作者寻找模型中层对象名称 token 的三维线性子空间，再同时做读出与因果写回。核心检验不是“能训练一个分类器”，而是固定空间方向是否跨提示可读、只改变这些方向是否选择性改变空间判断。

具体机制：从输入走到输出

  1. 从答案变化找方向。对左右等相反答案取 logit 差，分别对查询对象与参考对象的隐藏状态求梯度；用角色反对称的梯度差抵消共同变化，再跨样本、模板与对象交换顺序平均，得到水平、垂直、距离三条单位方向。方向特定于模型和层，不是跨模型通用坐标。
  2. 用一次前向读出位置。对象名最后一个 token 的隐藏状态投影到三轴；查询与参照在某轴上的坐标差的正负决定关系。水平与垂直是图像平面坐标，不是经严格三维重建得到的世界米制坐标。
  3. 编辑而非只观察。改动子空间坐标并写回隐藏表示，保持图像、问题和子空间外分量不变，再恢复模型生成；与随机编辑和颜色问题对照。共同平移两个对象不应改变相对关系，这是设计中的负对照。
  4. 外置变换隔离瓶颈。在 SpinBench 中先读出坐标，再施加预设视角旋转，按固定规则回答。这里旋转由外部算法完成，不能把高分说成模型自身已经会做同样的心智旋转。

主结果：整套方法支持什么

Table 1 的无前提 SpinBench：直接回答三模型均为 60.96；S-Space 加外置旋转后，Molmo2、Qwen3.5-4B、Qwen3.6-27B 分别为 94.52、91.10、95.21。有正确关系前提时为 99.31、97.92、99.31。结果支持“可读的空间信息比原生答案利用得更好”，不证明外置旋转可泛化到任意真实三维场景。

消融与分析：哪些设计起作用

§3.2 / Figure 4：坐标编辑改变空间判断，颜色判断大体保留；共同位移不明显改变相对关系。§3.3：非空间提示仍能读出有用空间坐标。§5.3 / Figure 10：east 与 right、north 与 above 的读出方向耦合，暴露参照系混淆。这些是机制干预和诊断，不是删除训练模块的消融；作者把耦合归因于预训练地图式语境属于解释性假说。

带条件总结与迁移边界

测试限于三种模型、选定中间层和空间任务；遮挡、动态、多视角与闭环机器人不在同等证据范围。总结：需要定位空间失败来源时，可先检查对象表示是否包含足够信息，再考察计算是否正确使用它。S-Space 提供了读写探针，而非保证几何正确的通用世界模型。

证据定位：正文所列 Section / Table / Figure 均指 S-Space 本次获取原文；没有运行论文代码，结果为作者报告而非本地复现。

03 · RL / 通用屏幕游戏控制；非 VLA

Player-1

让合成环境提供探索与失败恢复的反馈

原稿 HF 候选日 2026-10-15 · arXiv 2610.20584 v1 · 身份与版本 · 一手全文

背景、任务与前作缺口

输入任务、截图及短交互历史，输出键盘鼠标动作而非攻略文字。游戏控制需要转视角、长按与并行动作；只做行为克隆容易局限于演示覆盖，直接在复杂商业游戏内训练又昂贵。它有 reward 参与策略优化，故归 RL；没有真实机器人连续控制，不归 VLA。

解决思路

先用统一动作接口学会基本操作，再让可验证、可随机化的合成 2D/3D 世界提供探索反馈；期望学到可跨游戏迁移的控制规律，而不是记住训练地图。

具体机制：从输入走到输出

  1. 扩充可执行动作。绝对指针坐标之外加入相对位移；按键/鼠标可保持一个控制步，也可组合并行执行，如前进加跳跃、瞄准加射击。相对位移按屏幕宽高归一化，但转角仍受游戏相机增益影响。
  2. 监督初始化。6,044 条轨迹、295,097 个交互回合统一映射到动作区间，由 VLM 补任务与逐步视觉解释；动作均衡采样增加罕见控制曝光。模型学习由输入生成解释和动作。SFT、RL、评测均保留最近两轮图像—动作及更早两轮仅动作历史，不把先前解释不断堆回去。
  3. 用环境状态评分，不给策略偷看状态。16 个环境覆盖瞄准、战斗、驾驶、导航、UI。状态规则提供分数增量，作为稠密奖励；策略只看截图。外观、相机、场景、控制增益在支持的环境内共同随机化。
  4. PPO 更新与迁移。跨回合回报给早期动作信用，按环境归一化优势，避免大分值游戏支配更新。最终固定策略到未训练游戏观察—动作闭环，不在目标游戏上再做本论文的 RL。

主结果：整套方法支持什么

Table 2，MineDojo-300 每任务 8 次：9B SFT 成功率 10.54%，RL 后 38.33%；35B-A3B 为 23.38%→41.04%，外部 GameWAM 为 12.63%。Table 3，ViZDoom 归一化回报：9B 0.4361→0.6922，35B-A3B 0.5644→0.7236。跨游戏结果比只看训练回报更能支持迁移，但不能代表所有长时游戏任务。

消融与分析：哪些设计起作用

§5.1 / Figure 5c 的另一诊断协议在 100 步 RL 后，SFT→RL 为 51.67%，Base→RL 为 16.67%；不能与 Table 2 的主结果直接混用。§5.2 在同一 SFT 起点、25,600 episode / 100 更新的固定总预算下比较 2/4/8/16 环境，已有环境多样性控制，并非仅“多训练就更好”。§5.3 组合动作占比从 64.7% 到 85.4% 再到 93.2%（0/50/100 步），没有专门组合奖励，属于行为变化证据，不单独证明组合动作造成了全部提升。

带条件总结与迁移边界

奖励、合成环境和动作接口仍有人为设计；真实桌面安全、多人博弈、极长时规划未验证。总结：在观察—动作接口能够对齐时，少量演示加可验证合成交互能改善控制与跨游戏迁移；迁移前提是动作语义和反馈有用，而非环境越逼真越好。

证据定位：正文所列 Section / Table / Figure 均指 Player-1 本次获取原文；没有运行论文代码，结果为作者报告而非本地复现。

04 · 基座模型 / 原生集合决策

Jeva

将候选之间的竞争，与候选是否覆盖答案分开

原稿 HF 候选日 2026-10-14 · arXiv 2610.18773 v2 · 身份与版本 · 一手全文

背景、任务与前作缺口

给定状态、问题与动态候选集合，系统要选择一个选项、判断布尔命题或返回评分。把候选拼成语言 prompt 会引入位置偏好；固定分类头又限制类别数。独立双塔打分虽可缓存，但增加第三候选无法改变原有两项的相对偏好。还有一个不同问题：选项间不确定，并不等于所有选项都不适用。

解决思路

候选独立编码后保持不变，让紧凑的请求状态反复读取整个集合。这样既保留可缓存的候选记忆，又得到集合相关的判断；再用独立覆盖门判断有没有适用选项，而非把 None 塞入普通 softmax 竞争。

具体机制：从输入走到输出

  1. 两种模板分别编码。同一 Qwen3.5-4B 编码请求与每个候选，取最后非 padding token 后投影。候选模板只含决策类型与候选文本，不含当前问题、状态、序号或其他选项；因此同模型、类型、编码政策下可跨请求复用。
  2. 只更新请求状态。每层从请求构造 query，从固定候选向量构造 key/value；按相似度 softmax 加权汇聚候选证据，再残差更新请求并经过前馈网络。候选行不更新，但请求读过整个集合后，A 与 B 的相对分数可因 C 改变。共享打分与对称求和保证精确算术下的置换等变。
  3. 竞争与覆盖分工。最终请求与每候选内积得到 s；q = softmax(s/τdec) 表示“已有合适候选”的条件分布。覆盖率 ρ = sigmoid((max s − bcov)/τcov)，开放集合输出 p空 = 1 − ρ、pi = ρqi。最高分控制可用性，候选竞争分配已有质量；增加低分候选在固定最终分数条件下不改变覆盖率，但集合精炼仍可能改变分数。
  4. 三种接口不能混淆。Choice 选候选；Noul 返回正布尔候选的 qtrue，不是空答案概率 p空；Score 对候选的数值 rubric 按 q 加权求期望。训练用候选交叉熵与覆盖 BCE（开放集联合等价交叉熵），全空样本只教可用性、不强造候选排序；LoRA、投影和决策头训练，服务前合并 LoRA 再构建缓存。

主结果：整套方法支持什么

Table 1：Jeva-4B 在 8 个切片中领先 7 个，Mind2Web K=16 的跨任务 / 网站 / 域准确率 79.99 / 62.25 / 66.23%。Table 2 的 Noul Brier 为 0.0184，衡量布尔输出概率保真，不是专门的 null Brier；600 个 Choice 样本的置换测试翻转率 0.00%，全顺序正确率 76.67%，JevK5 分别为 26.17% / 47.83%。开放集 null detection 另在 §4.2 检验。

消融与分析：哪些设计起作用

§3 的构造证明说明一个集合读取块即可产生独立 scorer 无法表达的偏好逆转；对称性与缓存等价结论假设固定权重、确定性和精确算术，不是训练得到的经验承诺。§4.3：K=2048 长度感知 batching 把 p50 由 94.459 s 降至 12.040 s，准确率同为 69.88%。§4.4 缓存的最大概率差 0.00736 提醒有限精度不等于比特相同。这里是结构、排列、批处理及缓存诊断，不冒充逐模块训练消融。

带条件总结与迁移边界

依据 10/18 的 v2 原文重核；不是 10/16 旧稿时已经拥有的证据。候选仍要先被召回，缓存须随模型/编码配置失效；无候选开放生成不在接口能力内。总结：Jeva 的可迁移点是“独立记忆＋集合条件请求＋覆盖门”的解耦；仅当业务可以提供候选与适当监督时，结构对称和复用优势才转化为可靠决策。

证据定位：正文所列 Section / Table / Figure 均指 Jeva 本次获取原文；没有运行论文代码，结果为作者报告而非本地复现。

05 · 基座模型 / 可见无推理行为评测

Thinking Inertia

不要用开关或长度，代替对输出行为的测量

原稿 HF 候选日 2026-10-13 · arXiv 2610.11765 v2 · 身份与版本 · 一手全文

背景、任务与前作缺口

部署者有时只想要答案，但关闭 thinking、没有 think 标签、文本很短，都无法说明输出不含显式推断。短前缀可以包含推理，长前缀也可能只是复述。本研究评价可观察文本，不试图识别模型未公开的内部计算。

解决思路

把最终答案与其余可见内容拆开，分别问是否严格 answer-only、是否与问题相关、是否含推断；再把这些行为指标与最终正确率并列，避免把合规性当能力。

具体机制：从输入走到输出

  1. 统一响应边界。在常规干预 M1–M5 中把响应归一化为答案前文本 T 与答案 A；ETR 要求 T 无实质内容且答案可按许可格式解析。QRel 用指令感知嵌入测问题与 T 的相关性；EIR 由盲化裁判判 T 是否有显式推断，空 T 在相关性和推断率中记零。
  2. 干预而非重训。六模型、六数据集覆盖布尔、多选、开放答案，测试原生开/关、逐步提示、软/严格抑制与 assistant prefilling。裁判只看问题与 T，不看模型身份、干预、最终答案及其正确性。
  3. 特殊前缀单独定义。M6 预填答案框后，首个框决定答案得分；移除首个完整答案声明后的剩余可读文字作为 T。后面改答案不能替代首框，框内推断不进入剩余文本的 EIR。不能把不同模式的 T 无条件视为相同量。
  4. 分离题目与答案空间。把同一数学题改成布尔核验、多选或开放生成，减少“只是不同 benchmark 难度不同”的混杂。另以人工和第二模型裁判检查指标。

主结果：整套方法支持什么

§3.3 / Figure 5：开放题从 Think-off 到 Strict，平均 ETR 由接近 0 升到约 40%，正确率约下降 15 个百分点；该开放答案比较中的 EIR 为 99.69%→62.00%。同节布尔为 5.15%→0.12%，多选为 45.57%→5.39%。这里保留原文的近似读图口径，不把“约”改成精确表值；多选末值已按现原文纠正。

模型/API 版本、提示、输出通道和边界解析均会影响结果；多语、代码、工具、多轮、随机采样不能直接外推。总结：若要服务端 answer-only，必须同时测格式合规、可见推断与答案正确率；更严格的抑制在开放答案构造中可能牺牲正确性，“少输出推理”不能被宣传为“停止内部计算”。

ROAD MOPD

同一学生轨迹，先检查 token 分歧，再保护参数更新

原稿 HF 候选日 2026-10-15 · arXiv 2610.13521 v2 · 身份与版本 · 一手全文

背景、任务与前作缺口

多域学生可以按题目路由到专门教师，但学生参数共享：数学教师的更新仍可能破坏医疗或代码能力。只决定“谁教当前题”没有解决跨教师冲突；全投影又可能把目标域梯度几乎清空。医疗只是验证域之一，贡献是通用多教师优化方法，故按通用 RL/蒸馏保留。

解决思路

让辅助教师评价同一条学生响应，把它当兼容性约束而非当前领域真值。先调节 token 级监督强度，再在参数级只削弱冲突部分，同时保留最低更新范数。

具体机制：从输入走到输出

  1. 同轨迹评分。学生按当前策略生成响应，路由教师、辅助教师和冻结参考在完全相同的学生前缀上评价已采样 token，无须辅助教师另生成轨迹。以相对参考的 log-prob 改变量比较两教师建议。
  2. 信用分配。建议同向时提高路由教师相对奖励，反向时衰减；裁剪限制放大/缩小。该信号和学生—参考 log-ratio 形成停止梯度的优势，PPO 风格 surrogate 通过策略重要性比更新学生，辅助教师不是第二个答案标签。
  3. 参数冲突保护。目标梯度来自调节后的主损失；辅助梯度来自辅助教师在同一目标域轨迹上的普通 OPD 损失，并非它在自己的数据域上的梯度。逐训练参数张量检查内积：不冲突不改，冲突则沿原梯度到正交投影之间选点，尽量去掉冲突分量，但范数至少保留原来的 m（实验 m=0.6）。
  4. 只有目标更新被执行。多辅助教师顺序施加约束，共用原目标梯度的范数下限；各域修正目标梯度按域等权汇合、裁剪后做一次 AdamW 更新。辅助梯度不单独更新参数。推理时仅用学生，无教师调用。

主结果：整套方法支持什么

Table 1 的 Qwen3-4B 数学×医疗两域平均 47.92，CaMOPD 47.20；代码×医疗为 55.38。协议分别为代码 Avg@4、数学 Avg@32、医疗 Avg@1：它们是多次完成平均正确率，不是“至少一条成功”的 pass@k。较小 1.7B 学生的单个数学/代码域并非都最佳，优势主要体现于域间平均权衡。

消融与分析：哪些设计起作用

Table 4：数学×医疗完整模型 47.92，去信用分配 46.76，去梯度保护 47.65，改为全投影 47.09；支持两个层面的处理与保留策略各有作用。§4.3 / Figure 2 按教师分歧分组，数学原始冲突率 24%→40%，医疗 46%→76%，是关联诊断，不能说分歧必然导致退化。与保留同样信用分配/范数机制的 PCGrad 比较也支持同轨迹约束的价值。

带条件总结与迁移边界

仅局部一阶辅助损失几何保护，不保证实际优化后辅助域不降，也没有全局多目标收敛保证。跨教师额外前向与梯度计算增加训练成本。总结：当教师确有互补能力且共享学生出现更新冲突时，可在同轨迹上检查兼容性；范数下限是在保护与继续学习之间取舍，不是消除所有冲突。

VideoJev

共享视频前缀，直接判断时间区间和答案候选

原稿 HF 候选日 2026-10-14 · arXiv 2610.18615 v1 · 身份与版本 · 一手全文

背景、任务与前作缺口

同一长视频常被反复提问：找出事件发生区间，或从几项答案中选择。自回归模型要生成时间戳字符串或解释，重复查询还带来重复开销；最终任务本来就可以表达为候选评分。输入视频与查询/答案候选，输出一个连续区间或一个选项，而非自由文本描述。

解决思路

保留预训练多模态表征，去掉最终生成读出，让时间候选和文本候选共用 scorer；视频位于因果前缀，所以后续多个问题可共享计算。时间结果仍须结构化解码，不能只把逐帧高分当完成定位。

具体机制：从输入走到输出

  1. 构造候选读出。移除最终 MLP、替换 LM head，每候选末尾放 option_end，列表末尾放 decide。两个隐藏状态分别线性投影到 512 维并单位归一化，相似度乘固定 10 再加偏置得 si。决定 token 看见完整候选列表；候选 token 可见之前候选，所以本架构不像 Jeva 一样天然置换不变。
  2. 时间候选是帧对区间。主干两倍时间压缩把帧配对；相邻帧对之间中点划边界，首尾到 0 和视频时长。两帧平均时间落入标注事件并集则标签为正。sigmoid 分数表示归属，以 BCE 学局部标签；按区间时长加权的 Soft-IoU 让整段覆盖与区间外误报进入目标。
  3. 不是直接阈值化。令 wi = si − log(0.25/0.75)，寻找 Σwi 最大的非空连续范围，用 Kadane 算法 O(K) 求解，再把首尾候选边界转为时间。全部为负仍返回最强单区间，并做轻量边界后处理。一个低分点可以被整体收益覆盖，因此“超过阈值的帧合并”不是等价算法。
  4. QA 与训练。文本选项分数做 softmax，交叉熵监督正确选项；训练对不依赖位置的选项做可复现乱序。30% 视频只训练头，冻结骨干和标记嵌入；余下 70% 更新语言骨干、标记与头，时间目标 BCE + 2 Soft-IoU。视觉编码器与 merger 始终冻结。4B 用 Qwen3.5，35B-A3B 用 Qwen3.6。
  5. 缓存或联合。缓存模式每问题从同一视频 KV 前缀分叉；联合模式把问题组接在视频后一次前向。后问能看到前问与候选，但不会插入前问预测/参考答案，不可声称问题彼此完全隔离。

主结果：整套方法支持什么

Table 2：4B 四个视频 QA 均分 74.3，对比 Qwen3.5-4B Thinking 74.9；前向延迟 1.123 s vs 144.929 s，约 129×。256K 上下文、最高 2,048 帧等输入配置是结果条件；延迟排除了预处理与传输，不是完整产品响应速度。

消融与分析：哪些设计起作用

Table 6：Soft-IoU 使三套 grounding 平均 mIoU 60.7→65.3，QA 73.9→74.3。Table 3 等训练数据、单阶段对照：直接架构比 AR 提升 grounding 1.3、QA 1.9 点，不能把全部主榜优势归因于架构。Table 8 两阶段 65.3/74.3，单阶段 65.4/74.7：前者主要省语言骨干更新成本，不是更高分。§3.5 QA 平均 ECE 仍约 8 个百分点，直接输出概率不意味着已校准。

带条件总结与迁移边界

候选必须存在，开放问答、音频/字幕与多事件输出不在这套结论中；单连续区间解码也有结构限制。总结：若需求可化成区间定位或多选，直接评分与共享视频计算可省掉串行生成；应同时保留正确区间解码、候选召回和端到端成本测量，不能用 forward 加速替代完整部署评估。

GreenWAM

原稿 HF 候选日 2026-10-14 · arXiv 2610.18774 v1（PDF） · 身份与版本 · 一手全文

背景、任务与前作缺口

机器人数据的关节顺序、符号、单位和本体不同，视频模型又通常只会生成外观。世界模型要预测行动如何改变场景，策略则要选择动作。输入指令、相机观察、状态及相应条件，输出未来视频/状态或可执行控制，两种能力需要共享真正有意义的动作接口。

解决思路

从已有 action-trained 视频基座 Cosmos 3 Edge 出发，先统一 20 类机器人本体的解剖坐标，再用同一生成器联合训练多种条件/目标配置；策略适配时复制出动作专家，保留视觉动态通路，而不是彻底丢掉世界预测训练。

具体机制：从输入走到输出

  1. 编码前确定身体对应。每本体 codec 选择、重排、翻符号、对齐零点，将原生通道映射到 79 个共享槽（腿、躯干、手臂、手）。缺失坐标用 mask 排除损失，不拿零当真实目标。只有一组共享输入/输出 projector，不替每本体另学一个头。
  2. 状态和动作含义不能省略。前向/WAM 模式中的部分关节是相对块起点 q0 的状态偏移，既不是速度，也不是连续累加增量；手指等可保留绝对值。可靠末端位姿有另一路视图与 SE(3) 编码，projector 不做正/逆运动学。
  3. 一个模型七种题。模式由哪些流干净、哪些流加噪决定：文字到视频、图到视频、带历史图到视频、前向动态及带历史版本、逆动态、世界—动作。生成流共享噪声等级，以 rectified-flow 速度预测学习视频 latent 与解剖状态的变化；前向动态把已给动作作为条件，WAM 同时生成未来视觉和状态。
  4. 适配控制闭环。复制生成器塔初始化 action expert，视频/动作各自投影和前馈，但每层联合注意力。起始函数不变，训练后两塔分化。目标机器人演示监督未来状态；推理按 q0 解码为本体命令，只执行预测前缀，再观测和重规划。实时设置另蒸馏成单步学生。

主结果：整套方法支持什么

§6.4–6.5 / Figure 15：真实人形分布内指令成功率 95.6%，父模型适配策略 88.9%，π0.5 84.4%。单步蒸馏延迟 35.4 ms，是未优化策略的 12.32× 加速；不是对任意机器人任务的通用实时保证。世界预测与控制均评估，但各 benchmark 都需要相应后训练。

消融与分析：哪些设计起作用

§7.2 相同 3,000 步适配，起始函数相同，拆 action expert 平均成功增加 3.3%，代价是新增一座生成器大小的参数塔、训练步约增加 8%。§7.3 / Figure 21：同起点 2,500 步，WAM/前向动态/图生视频按 0.9/0.05/0.05 混合，比纯 WAM 随机场景成功提高 8.0 个百分点；50 任务中 31 升、9 降，clean 无显著变化。两组 WAM 本来都预测视频，所以支持的是额外世界模式作用，不是“有视频胜无视频”。

带条件总结与迁移边界

长 rollout 自条件误差会累积，桌高和初始构型变化仍敏感；真实控制只验证有限本体与任务。总结：可迁移的是明确动作语义、联合建模与适配时保留辅助世界任务；共享基座能兼顾预测和控制，不等于无需本体映射与演示的零样本机器人。

文档输入不仅要识字，还要恢复框、表格、公式、字段和语义。纯结果奖励可能看不出一个关键数字错在哪；教师 token 监督更细，却可能把教师的局部错误压给已更强的学生。统一 OCR 基座必须兼顾任务宽度与可信训练信号。

解决思路

先以多能力数据和统一条件生成做 SFT，再保留 GRPO 的结果监督，用“教师本身可靠吗、是否稳定优于当前学生”控制每个样本的 OPD 权重，而非随时间统一衰减。

具体机制：从输入走到输出

  1. 把任务与验证器配对。识别、定位、解析、抽取、视觉文字理解、OCR 推理形成数据体系，合成管线与质量验证补长尾；SFT 学习相应输出结构。后训练的 verifier 按任务使用编辑相似度、IoU、公式 CDM、表格 TEDS、字段 F1 或开放 VQA judge，映射到共同奖励范围。
  2. 比较能力而非参数大小。训练前采样教师响应，经相同参考与 verifier 估教师能力并缓存；当前学生每批生成一组响应，在线估学生能力与师生差距。正平均差还不足够：两者都差时，也可能有一个“相对更好”的坏教师。
  3. 独立校准路由。固定校准集分出独立采样 A/B：A 模拟训练可见有限样本统计，B 估教师质量和胜过学生的概率（平局计半）。拟合正斜率 sigmoid 映射后冻结。权重为校准教师质量乘超出 0.5 的胜率部分；胜率不超过 0.5 时蒸馏权重为零，路由停止梯度。
  4. 两种监督各做一件事。GRPO 始终按组内结果差给学生策略更新；冻结教师沿学生自己生成的前缀提供 token 分布，以学生到教师的 reverse KL 蒸馏，乘样本路由权重。教师不更新；推理只保留学生标准自回归生成，不调用 router/教师。样本级可靠仍不能担保每个 token 正确。

带条件总结与迁移边界

verifier、参考质量、校准分布、教师都决定路由可信度，局部错字仍可能被页级高分掩盖；大规模语料许可与复现成本也重要。总结：对于可验证的多任务文档生成，可将细粒度教师指导限制在它可靠且仍领先的样本上；收益不是“任何教师都可加”，而是控制何时停止模仿。
