背景、问题、方法与实验。时间线采用首次公开日期，正文方法及实验链接保留具体论文版本。

单张图回答只要求在一个观察中找证据，多图和视频还需要保持对象身份、时间顺序与坐标系一致。更长输入并不自动带来更完整理解：采样、压缩、注意力回取、空间几何和评测口径都可能成为瓶颈。

贯穿教学场景是一段桌边录像：红杯先在左、蓝杯在右，一只手将红杯移开；中间换了相机视角并出现一次碰撞声。每章都沿用这个场景，依次检验模型是否把两帧对应好、能否回取远处事件、是否混淆视角与物体运动、声音是否对齐。

本专题不把几何估计器、系统并行和视频基准当成同一种方法。它们分别提供空间证据、可容纳规模和可检验标准；正文明确各自改变的环节。

下面的章节沿具体问题展开；最后进一步讨论跨小时、跨天的证据怎样记住并取回。

01

问题 01

跨图对应与统一输入

多张图中哪个对象还是同一个，关系怎样变化？

两幅图里的“红杯”可以是同一个杯子的两个时刻，也可以是两个相似杯子。没有图像边界、顺序或跨图监督，模型可能把它们混成同一个静态场景。

因此先解决输入协议和训练分布，让多图、视频帧和多视角成为一条可以被共同引用的序列，再讨论更精确的时间或几何推理。

读图前的算例 · 教学示意

给t=0和t=2两帧，先回答“哪只杯子移动”，再要求说明各帧证据。这里不假定像素坐标可直接跨视角比较。

LLaVA-NeXT-Interleave: Tackling Multi-image, Video, and 3D in Large Multimodal Models

2024-07-28

把多图、视频帧和多视角图像统一为交错输入，用混合指令数据学习跨图关系。

  1. 单图基座已经能解释一个杯子，但把两幅图简单拼接并不等于知道哪一幅先发生、同名对象是否相同。论文把图片标记和文字穿插为一个序列，让不同图像成为同一次回答的条件。
  2. SigLIP 图像特征经两层 MLP 接入 Qwen1.5。M4-Instruct 同时覆盖多图、多帧、多视角和多 patch 场景；从已有单图指令模型继续训练，并混入单图数据以保留基础能力。
  3. 接着算例：输入 t=0 红杯在左、t=2 红杯被放到右侧的两帧。模型需要输出“移动了红杯”，不把两帧当成同一张静态图中的两个红杯；再加第三视角检查杯子身份。
  4. 改动首先发生在输入组织与训练任务，而非显式三维几何求解器。跨视角问答能得到监督，但度量距离和相机位姿仍需单独验证。

02

问题 02

长视频容量、取证与压缩

怎样在大量重复帧中保住短暂关键动作？

若每帧保留196个token，1000帧就产生196000个视觉token；计算与显存随之扩大。均匀少采帧可能错过碰杯瞬间，全量保留则增加训练和服务负担。

长上下文训练/并行解决“接得住”，片段压缩和逐层选择解决“少花预算”。两条路线需要用同一事件检索与问答验收，避免将窗口长度当成理解上限。

读图前的算例 · 教学示意

将同一段动作埋到两小时录像中：先检查事件被采样，再检查它能否被回取；最后比较压缩是否删掉动作前后关系。

LongVILA: Scaling Long-Context Visual Language Models for Long Videos

2024-12-13

先扩展语言上下文，再以长视频任务训练；MM-SP 把视觉负载与语言序列分别分片。

  1. 把视频采样为带顺序的帧，再转成视觉 token。若只扩大推理窗口而不训练，模型可能接得住长序列却不会利用远处证据；因此先做长文本上下文扩展，再进行长视频 SFT。
  2. 五阶段流水线把视觉对齐、视觉语言预训练、指令训练、上下文扩展和长视频指令训练分开。最后一阶段用长视频描述与问答，让模型学习从较远帧中取证。
  3. 多模态序列并行先按图像/帧分散视觉编码，再按 token 切分语言模型计算，缓解某张卡拿到大量图像、另一张卡只有短文本的负载不均。
  4. 接着算例：将两帧扩展为两小时录像，杯子只在第17分钟移动一次。先保证该帧被采样，再保证模型能在长上下文中回取它；并行训练解决可容纳规模，不能替代事件检索能力。

VideoChat-Flash: Hierarchical Compression for Long-Context Video Modeling

2025-07-13

先在短片段中合并相似 token，再在语言层逐步丢弃视觉 token，用压缩换长视频容量。

  1. 逐帧编码容易重复墙面、桌子与静止背景。HiCo 先用短视频编码器建模局部时空变化，再做 Similar Token Merging，压成每帧较少的代表 token。
  2. 语言主干内部继续做 progressive visual dropout：浅层保留较均匀的覆盖，深层再按注意力挑选与问题相关的 token。早期过度依赖尚未成熟的注意力可能错删证据。
  3. 接着算例：10,000帧中桌面几乎不动，不能反复花预算编码背景。短 clip 保留“手伸向杯子”的局部变化；深层针对“先移动谁”保留关键事件，而非仅看最终摆放。
  4. 把同一段视频的压缩率逐步提高，记录答案和显存。若微小接触动作先被合并掉，后续扩大语言窗口也不能恢复，这是此路线的主要适用边界。
Nvisual = F × K；F=1000，K=196→16 ⇒ 196000→16000

03

问题 03

空间关系与跨视角几何

把像素上的左右远近变成有坐标含义的证据。

同一个杯子在换视角后可能从画面左侧变到右侧。单帧语言常识不能分辨相机运动、物体运动与尺度变化；像素间距也不是物理距离。

空间监督让VLM学到常见三维关系，几何网络则直接输出相机、深度与点图。两者互补，但并不等价：前者仍是估计式回答，后者需要语义绑定才知道哪些点属于杯子。

读图前的算例 · 教学示意

固定杯子，移动相机。先比较两个视角相机与杯子三维位置，再解释红杯是否移动；把对象识别错误与几何误差分别记录。

SpatialVLM: Endowing Vision-Language Models with Spatial Reasoning Capabilities

2024-01-22

用视觉专家合成带物理空间含义的问答，让语言模型学习相对方位和粗略距离。

  1. 通用图文数据常说“桌上有杯子”，很少提供杯间距离或谁更靠近相机。论文从普通图片出发，检测/分割对象、生成描述，并用单目深度把对象位置提升到三维。
  2. 再进行重力方向规范化，构造左/右、前/后、高/低以及距离等定性和定量问题；把这些合成空间数据与一般视觉语言任务共同训练。
  3. 接着算例：左侧红杯与右侧蓝杯在像素上相隔100格，真实距离未必相同。若已估计两杯三维中心，先在同一坐标系比较，再输出带单位的距离或定性关系。
  4. 视觉专家的深度误差会进入标签；训练只是在大量有噪声监督下学空间估计。对于玻璃杯、尺度模糊或远距离场景，需要暴露不确定性。

VGGT: Visual Geometry Grounded Transformer

2025-03-14

直接从多视角图像联合预测相机、深度、点图和轨迹，为空间问答提供几何工具。

  1. 输入同一场景的多幅RGB图，不要求预先给相机参数。DINO patch token 加相机与寄存 token，交替执行帧内注意力和跨帧全局注意力。
  2. 相机头输出内外参，DPT头输出深度/点图，轨迹头输出匹配；多任务几何监督让这些输出相互约束。它不是一个文字问答模型，应作为VLM外的可检查证据通道。
  3. 接着算例：保持两杯位置不变，移动相机拍第二视角。先重建相机和杯子的三维位置，再判断杯子是否真的移动；避免把视角变化误当物体动作。
  4. 需要更高精度时，以预测为初始化做BA。一次前向的快结果与后优化结果必须分开记时，也要分清未知相机和已知真值相机的比较组。

04

问题 04

声画时间对齐与一致性验收

多种证据怎样对齐，又怎样证明解释没有自相矛盾？

声响、画面变化和文字字幕可能出现在不同时间尺度。把它们简单拼接，模型可能用错邻近事件；而平均单题分数又容易掩盖同一事件的回答互相矛盾。

因此既要为输入建立统一时间轴，也要在输出端用成组问题检查对象、顺序与因果是否一致。一个是表示机制，一个是测量机制，应分开归因。

读图前的算例 · 教学示意

碰撞声附近画面被手遮挡。允许模型用声音补证据，但要求“接触时间、涉及对象、后续移动”三个回答相互兼容，缺失证据处保留不确定性。

Qwen2.5-Omni Technical Report

2025-03-26

把音频与视频放到同一时间坐标，Thinker-Talker 分工支持理解与流式语音回答。

  1. 音频先转为声学特征，视频以动态帧率采样。TMRoPE 把帧和音频片段的时间位置绑定到真实时间，而非仅依赖它们在序列中的排列编号。
  2. Thinker 整合文本、图像、视频与音频，生成语义文本；Talker 依据语义和历史语音生成音频token，后续滑窗/分块解码为声音，降低一次等完整答案的等待。
  3. 接着算例：录像中先听见杯子碰撞声，随后手遮住杯子。把声音t=12.4s与附近帧对齐，可以支持“发生接触”的判断；它不能单凭声音判定究竟哪只杯子破裂。
  4. 比较无音频、字幕和原始音频三种输入，分别量化互补信息。语音回答流畅与事件时间对齐正确是两个不同验收目标。

把相互关联的问题放在一组，用非线性计分检验能力一致性与推理连贯性。

  1. 单题平均分可能奖励碰巧答对关键一题，却隐藏同一事件的对象、先后顺序与因果问法互相矛盾。评测按跨帧信息、时序因果和叙事社会物理等能力组织分组问题。
  2. 对每组4题，能力一致性用正确比例的平方给予更严格得分；推理连贯性进一步检查从简单到困难的连续正确前缀。它改变的是测量规则，并非新的推理模块。
  3. 接着算例：依次问“谁碰杯”“碰撞前红杯在哪”“发生了什么”“为何移动”。答对3题但先后顺序矛盾，不应与一条完整正确事件链得到相同可信度。
  4. 分别报告逐题准确率与组级得分，并区分音频/字幕条件。同一模型在去除辅助信息后掉分可暴露依赖，但不是严格的单模块因果证明。
Sgroup = (Ncorrect/4)²；3/4题正确 ⇒ 0.5625

对能力一致性分组的教学说明：同样75%逐题正确率在该组只得到56.25%的非线性分。推理连贯性分组另有连续前缀规则。

问题 05

跨小时、跨天的证据怎样记住并取回？

从长窗口容量，转向实体、事件和行为层面的可用记忆。

上下文能放进更多帧，只是容量条件。回答跨天问题还要记住对象状态、事件先后与重复行为，并能找到支撑结论的片段。

EgoMemReason

2026-05-11

把跨天视频记忆拆成实体状态、事件关联与行为规律三类推理，而不只测试单个片段的定位。

  1. 问题只能访问查询时刻之前的观察；问题生成后，人工检查答案、歧义、干扰选项和视觉依据。
  2. 500道题平均需要5.1个证据片段，并回溯25.9小时；这些统计描述证据分布，不是模型输入的统一采样预算。

更密集的帧采样或增加字幕、描述，在该基准中都没有带来一致改善；覆盖更多输入不能直接保证跨天推理。

VideoEvolve

2026-10-07

交替优化记忆构建与检索策略，使保存什么和怎样取回能够共同随问答反馈改进。

  1. 从低帧率概览建立可复用记忆；记忆模块选择性补充证据，检索模块搜索记忆并在需要时回看原视频。
  2. 每次冻结一侧优化另一侧；BEF判断当前瓶颈，CEF把训练分配给尚弱但可学习的能力并保持覆盖。

反复针对固定问题优化，可能把记忆专门化；作者以能力层面的课程反馈缓解，而非宣称固定记忆已能覆盖所有新问题。

§1；HTML行103–122；v1 ↗

EgoMemReason规定记忆必须支持哪些跨天推理；VideoEvolve让记忆与检索从下游反馈共同学习。两者提示，长视频系统应同时检查保存的证据是否充分、是否能取回，以及取回后能否完成状态聚合和时间推理。
