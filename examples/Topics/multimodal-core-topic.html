背景、问题、方法与实验。时间线采用首次公开日期，正文方法及实验链接保留具体论文版本。

共同问题不是能否写出一段解释，而是解释中的对象、文字和关系能否回到输入图像中。视觉编码时丢失的小字、语言层错误绑定的对象和推理阶段的错误前提，需要在不同位置处理。

贯穿教学算例是一张房间图：左侧红杯、右侧蓝杯、远处小字标牌以及半遮挡的窗户。我们保持图片和问题不变，再改变分辨率、压缩、定位接口、推理格式与反馈；示意算例没有被当作这些论文的真实实验。

这份报告覆盖视觉接入、原生分辨率与 token 预算、密集接地、结构化推理和评价反馈。多图/长视频/三维关系在相邻专题展开，扩散语言主干的 VLM 改造见 Diffusion LLM / VLM。

下面的章节沿具体问题展开；最后进一步讨论如何分开感知失误与推理幻觉。

01

问题 01

视觉接入与对齐训练

先把足够的视觉信息交给语言模型。

传统做法将视觉编码器的输出投影为语言 token；问题在于输入分辨率、序列长度和预训练/对齐阶段往往分开设计。即使语言主干很强，也不能保证被压缩后的图像仍保留所问的细节。

本章分别考察原生动态分辨率的视觉通道和原生多模态预训练。前者改变证据的进入方式，后者改变跨模态能力怎样共同学习。

读图前的算例 · 教学示意

同一房间图里，标牌的字高只有十几个像素。先检查编码后是否还可区分字形，再问“红杯是否在标牌左下方”；所有后续判断都以这个可见性条件为前提。

Qwen2.5-VL Technical Report

2025-02-19

原生分辨率编码、局部注意力和空间合并，让视觉证据以可变长度进入语言主干。

  1. 输入图像按原生比例处理，高宽调整到 28 的倍数；14×14 patch 进入带二维位置表示的视觉编码器。这里先决定小字和远处杯子的细节是否还能被看到。
  2. 多数视觉层使用窗口注意力，保留指定全注意力层；相邻四个 patch 的特征拼接后通过两层 MLP 映射到语言嵌入空间，减少交给 LLM 的序列长度。
  3. 图像 token 与问题文字一起成为语言解码器的条件；视频输入进一步把时间位置与绝对时间关联。训练仍需图文数据和指令监督，结构本身不保证看对每个细节。
  4. 接着房间图算例：若桌边标牌被整图缩小后只剩几个像素，后续推理无法凭空恢复字形。先保留分辨率，再检验 token 合并是否保住文字与杯子的位置；最后才比较回答。

InternVL3: Exploring Advanced Training and Test-Time Recipes for Open-Source Multimodal Models

2025-04-19

02

问题 02

视觉预算与细粒度保留

更多像素怎样转成有用而非冗余的 token？

整图缩放便宜，但细节可能不可逆地消失；切图或保留原生分辨率能增加证据，却扩大视觉序列。把压缩全放在末端，又无法减少前面视觉层的计算。

因此需要把“什么时候看细”与“什么时候压缩”联合设计，并分别检查 OCR、空间关系和通用问答。只看一个平均分会掩盖受损的细粒度任务。

读图前的算例 · 教学示意

先用细网格编码标牌和杯沿，再逐层压缩背景。若同样保留256个视觉 token，尽早合并背景与均匀丢掉细节的结果可能不同；这里的256是解释模块的教学预算。

LLaVA-UHD v3: Progressive Visual Compression for Efficient Native-Resolution Encoding in MLLMs

2025-11-26

在视觉骨干内部渐进压缩 token，把细粒度观察与低序列成本组合起来。

  1. RPE 把原有粗 patch 权重转换到更细的 patch 网格，以更高空间粒度开始编码，而非一开始就把整图压到低分辨率。
  2. 在多个 ViT 深度位置插入 WTC，逐层压缩局部窗口。内容自适应池化根据特征分配权重，避免只在投影器末端一次性丢弃信息。
  3. RPE 与 WTC 联合调节输入粒度和后续长度；压缩位置越早，计算节省越多，但小字与稠密结构也越容易损伤。
  4. 接着算例：先让标牌和杯沿在细网格中被编码，再把背景墙等冗余区域逐级合并。检查“红杯在左侧”与标牌文字，不能只看整体答案平均分。

03

问题 03

从语言指代到密集空间输出

把“是哪个物体”变成可验证的位置或掩码。

语言回答“左边的杯子”仍可能发生对象偷换。坐标框提供粗定位，掩码进一步给出空间范围；视频还要求同一指代在时间上持续对应同一个对象。

密集输出接口与语言主干可以分工：语言层解释语义，专门的分割模块处理像素边界。训练时既要保留对话能力，也要为对应关系提供空间监督。

读图前的算例 · 教学示意

把“红杯在左侧吗”改成“给红杯画掩码，再判断它与窗户的关系”。先验收指代掩码，才知道错误来自选错杯子还是关系推断。

Sa2VA: Marrying SAM2 with LLaVA for Dense Grounded Understanding of Images and Videos

2026-08-24

让语言主干产生分割接口，再交给 SAM-2 输出与语义对应的图像或视频掩码。

  1. 文本、视觉提示和图像/视频编码为 token，由 MLLM 组织语言语义；另由 SAM-2 编码器提供密集空间特征。
  2. LLM 输出 [SEG] token，其隐藏表示作为 SAM-2 解码器的提示，形成二值掩码或跨帧 masklet。回答一个物体名称与真正定位该物体被拆成可检验的两部分。
  3. 单阶段指令训练混合问答与分割任务，优化文本及掩码损失；选择性更新 MLLM、解码器和适配模块，保留预训练视觉能力。
  4. 接着算例：问题由“哪个杯子在左侧”改成“标出左侧红杯”。输出文字以后还要检查掩码覆盖杯身还是误选桌面；这是内容描述没有提供的空间验收。

04

问题 04

结构化推理与反馈验收

长解释需要可修正的阶段和可检查的反馈。

感知与定位完成后，模型仍可能把空间关系推错。生成更长的解释增加了可见中间过程，也增加了错误被后续步骤继承的机会。

结构化阶段使回溯成为可能；评价器则提供比较回答的外部反馈。两者都需要预算控制，也都不能替代真实视觉证据。

读图前的算例 · 教学示意

若 Caption 已把红杯写成蓝杯，先回溯描述；若描述正确却把左右推反，再修正推理。评价器必须看到图像并检查指代，而不是仅偏好更长或更自信的文字。

LLaVA-Critic: Learning to Evaluate Multimodal Models

2025-03-04

训练图像条件评价器，再用它产生偏好数据，检查回答质量与证据理由。

  1. 数据同时包含单回答评分和双回答偏好，评价输入包括图片、问题、回答与标准；监督不仅给分，也包含判断理由。
  2. 在 LLaVA-OneVision 基础上微调 Critic，使其评价视觉回答；然后从策略候选中选择较好和较差响应，构成迭代 DPO 的偏好对。
  3. 评价器改变的是外部反馈和选择，不会让错误的图片证据自动变成真值。应观察它是否引用了真实可见内容，以及是否与人类判断一致。
  4. 接着算例：两条回答分别说“红杯在左”和“红杯在右”。Critic 需要回看实际图像与指代对象；如果只奖励流畅解释，两条错误推理可能得到相似高分。

2025-07-21

05

问题 05

如何分开感知失误与推理幻觉？

用可控视觉条件诊断错误，再约束推理链与答案之间的支持关系。

一张图里看错杯子的颜色，与多张图之间把杯子的身份混淆，最终都可能生成流畅但错误的答案。诊断应定位错误发生在哪一环。

RC-DPO

2026-05-27

固定同一个优选答案，比较它在不同推理链条件下的偏好，给推理链提供直接的训练信号。

  1. 用MCTS寻找视觉依据充分的正例推理链，再通过注意力引导的词元裁剪构造负例条件。
