阅读起点

六个词，连成一条生成过程

潜变量 / token
VAE把图像变成更小的表示；DiT再把它切成token。减少token能省单步计算，但需要检查细节恢复。
Score
某噪声水平下，数据对数密度随输入变化的方向。网络估计它或等价的噪声、速度，并据此更新图像状态。
PF-ODE / flow
将随机生成分布联系到一个连续确定性流；实际部署仍需数值积分。连续轨迹与有限步求解存在误差。
CFG
常见形式为无条件预测＋w×（条件预测－无条件预测）。普通实现需两个分支；蒸馏引导可以把它学进单个分支。
蒸馏
训练学生以更少的评估完成任务。学生未必更小，也不一定逐像素复现教师同seed结果。
JVP
雅可比与方向向量的乘积，表示输出沿某个方向如何变化。训练中出现JVP，不代表推理也要算JVP；单纯NFE也未必囊括这类额外算力。

这是教学解释。变量的正反时间方向、噪声/速度参数化应以各论文定义为准；入门可连读 DDIM、EDM、CM。

方法关系

同样是少步，学习对象并不相同

沿原轨迹更好地走

DDIM、DPM-Solver/++、UniPC、EDM、AYS改积分公式或时刻。原则上复用兼容权重；更高阶并不一定减少NFE。

改变轨迹或端点配对

InstaFlow先reflow再蒸馏；PD把教师两步压成学生一步；PeRFlow分段整流。它们改变学习目标，不能与单纯换solver混为一类。

学习端点或区间映射

CM/LCM让同一路径状态指向同一端点；AYF把映射推广到任意两时刻；MeanFlow学习区间平均速度。相似的推理预算并不说明训练目标相同。

学习输出分布与真实感

DMD/DMD2通过score匹配学生分布；ADD组合教师信号与对抗监督；LADD把判别特征和训练移到潜空间。混合配方可以跨组。

Flow Matching是一类拟合概率路径速度场的训练思路；Rectified Flow采用线性端点插值，而reflow是再利用模型配对重训的过程。线性插值目标不等于已经学到完全直的生成轨迹；一步推理通常仍需专门训练或蒸馏。参见 InstaFlow §2.2、AYF。

分组与关系解释为本专题综合；不按年份虚构直接继承。ADD→LADD有后者§3明确比较支持。Calibri主要是少量标量的黑盒质量对齐，可能以更少NFE达到质量目标，不能归为标准轨迹蒸馏。

公平比较

步数、NFE、延迟与算力分别记账

量怎么记录常见误读
采样区间 / steps去噪调度走了几个区间Heun一个区间可含两次网络评估
论文NFE保留作者原定义，并说明是否把guided field视为一次不能一律将所有表格的NFE乘2
等效单分支评估数每个时刻各分支实际参与的评估数之和batch=2合并一次API调用仍有双分支工作；缓存、token减少后每次成本不同
API调用 / kernel launches框架调用、融合、图捕获分别统计调用少不必然算力少
请求延迟文本/思考、去噪、解码、传输、排队；区分冷启动和稳态内核TOPS倍数不是完整出图倍数
吞吐 / GPU-seconds固定并发下images/s；每张图各GPU占用秒数求和2卡用半时间，资源成本未必减少；GPU-seconds也不能直接跨卡型比较

教学账本：普通50步CFG双分支约100次等效单分支评估；单分支8步约8次，评估数之比12.5，并不是已测12.5倍加速。步数比50/8=6.25；另一个因素来自移除双分支，此外固定组件和内核效率也会改变。

重叠通信：T总 ≈ T固定 ＋ Σ(T计算＋T通信－T重叠) ＋ T排队；或直接记录未被隐藏的通信。张量并行、流水与CFG并行优化的是关键路径；在profiler中计算真实重叠，不能把两条时间线重复相加。DistriFusion原文

例子：固定组件0.8秒，去噪4.2秒；去噪快5倍后总时间1.64秒，完整速度仅约3.05倍。教学值，未运行。

实际选择

先问权重能否变，再看硬件能否兑现

路线 / 代表训练或校准架构与成本近似 / 质量风险硬件与叠加边界
执行优化 / FlashAttention、编译、CUDA Graph无权重训练兼容U-Net/DiT；NFE/CFG通常不变FlashAttention数学精确；浮点与编译数值仍需验先核mask/shape/dtype；图捕获、动态shape和offload需验证兼容
采样 / DDIM、DPM++、UniPC、EDM、AYS通常无权重训练；AYS需离线时刻优化噪声/速度参数化必须匹配；steps不等于NFE积分误差；步数少时文字布局可能先受损低改动入口；蒸馏模型应采用其训练匹配调度
近似缓存 / DeepCache、TGATE、TaylorSeer通常无权重训练，阈值需调U-Net高层、attention或DiT特征；名义NFE可能不变跨步特征不相同；误差随prompt、时刻累积四步模型收益可能很小；先测缓存单项，再与蒸馏组合
token与空间 / ToMe、DDiT、SANA、DC-AEToMe可无训练；可变patch/新AE通常需适配或训练token数、attention和解码成本变化合并、粗patch或压缩可能损伤细字新AE潜空间不可随意替换已有权重；稀疏需有实际加速内核
量化 / Q-Diffusion、ViDiT-Q、SVDQuant、SageAttention2++PTQ需校准；注意力量化可在线U-Net/DiT方法有别；NFE/CFG一般不变权重、激活、注意力的误差位置不同低位宽需要匹配卡型与融合实现；LoRA、缓存组合重新测
少步学生 / PD、LCM、InstaFlow、ADD/LADD、DMD2需后训练，或加载已有学生/LoRA常降NFE，也可能学入CFG；学生不一定更小语义、覆盖度、编辑与文字能力可能改变先验证官方精度与调度，再逐个加缓存/量化；训练费用单列
多卡 / DistriFusion、PipeFusion、xDiT一般不改训练；引擎适配空间/张量/流水/CFG并行；降低关键路径部分方法用陈旧特征近似；精确TP本身不同互联、分辨率与batch决定收益；延迟改善不等于GPU-seconds下降

只能改运行时：先做稳态剖析，验证兼容内核和编译，再调采样。允许换权重：先比较官方蒸馏模型的质量门槛。受显存限制：区分权重常驻与激活峰值，评估量化或offload的传输代价。多卡：同时报告延迟和资源消耗。此顺序是工程建议，不是跨模型实测排名。

精确条件复用的前提：若K=Wₖc、V=Wᵥc，且c、权重、位置处理和条件分支不变，投影可精确复用；attention输出仍随图像Q变化。联合文本—图像注意力中，文本隐藏状态可能随图像演化，不能自动认定K/V静态。TGATE复用后者属于近似。TGATE §4

国产卡与具体框架：论文的CUDA、Triton、FP8或INT4结果只证明对应实现。逐项检查掩码语义、低精度指令、算子融合、通信后端及软件版本；没有同卡实测则留空，不用峰值算力比例预测秒数。

部署案例 / 版本边界

SenseNova：三个独立变量，三组实验

①固定精度和引擎，比较50步CFG=4与官方8步CFG=1蒸馏配置，并同时记录质量。②在同一配置上启用缓存，测增量收益。③同一权重与CFG设置下比较串行/合批/多卡CFG的延迟和GPU-seconds。只有受控变量才可归因。

官方仓库当前说明覆盖U1.5-8B-MoT：8-step LoRA在SFT检查点上训练，可用于基础检查点但不保证最优；不兼容更早Preview。文中保留的原U1对比图库不能冒称U1.5实测。官方base/distill说明，2026-08-28修订

混合注意力包含文本因果和图像span内双向。官方基础设施为此修改Triton/FA3内核；“支持causal=true/false”不自动等价于支持此混合mask。该文的prefill加速不等于完整图像生成加速。U1基础设施说明，2026-04-27修订

vLLM-Omni U1.5社区recipe要求DMD LoRA使用CFG=1；其online FP8路径不支持8步LoRA，建议该组合使用BF16。A800上的FP8还涉及Marlin W8A16回退；这些属于该引擎、该recipe快照的限制，不是所有FP8实现的普遍结论。recipe，2026-09-28修订

低位宽也可能更慢：同一recipe的A800、vLLM0.29、TORCH_SDPA、eager、TP1、batch1、无LoRA、28步、10个prompt比较中，1024²的reserved显存由33.555降至18.561 GiB，但每请求平均步时的P95由187.867增至229.115 ms（已排除预热）。省显存与降延迟应分开验收；这不是完整出图P95。

可复用模板

把“更快”变成可回查的实验记录

  1. 固定输入与版本：model/LoRA哈希、引擎提交、torch/驱动、设备与互联、dtype、分辨率、batch、seed、prompt集；明确思考/改写prompt是否开启。
  2. 拆开预算：steps、论文NFE口径、各CFG分支、cache刷新率、token数、采样器和时刻；不要只写“8步”。
  3. 记录冷与热：冷启动单列加载/编译；预热后重复多次，给样本数与P50/P95。GPU计时同步，区分客户端排队和服务端执行。
  4. 做质量门槛：同prompt多seed；文字逐字准确率/OCR、空间关系、编辑保持、多样性和盲评，搭配FID/CLIP/偏好指标；不要只挑漂亮样本。
  5. 检查资源与组合：峰值allocated/reserved显存、同并发吞吐、每图GPU-seconds。先baseline，再A、B、A+B；出现质量回退时报告，不将单项倍率相乘。
