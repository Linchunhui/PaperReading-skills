01

问题 01

要奖励什么，信号是否真的可靠？

偏好、答案正确与步骤正确是不同监督。

后训练先要明确目标。摘要的人类偏好、数学最终答案、推导某一步正确性，没有统一的天然标尺。奖励模型高分可能来自格式、长度或评分漏洞。

先把监督对象说清楚，再看策略更新；否则“RL分数更高”可能只是更会迎合评判器。

Direct Preference Optimization: Your Language Model is Secretly a Reward Model

2023-05-29

把偏好配对转成相对参考模型的分类目标。

  1. 同一题采到四条答案后，先取正确且偏好的y+和较差的y−。DPO直接提高这对答案相对参考策略的概率差，不需要为每次更新重新在线采样或训练一个显式奖励模型。
  2. 教学设β=0.1，学生相对参考的log比在y+为0.3、y−为−0.1，则偏好logit为0.1×(0.3−(−0.1))=0.04，损失−logσ(0.04)≈0.673；两者相等时损失约0.693。这里比较的是回答概率比，不是只看最终一个token。
  3. 从带KL约束的奖励最大化推导出最优策略与奖励关系，得到偏好目标。数据覆盖、参考模型与β共同限制训练；纯离线DPO看不到学生后来新生成的所有失败状态。
  4. 原论文TL;DR实验在相同GPT-J SFT起点比较DPO与PPO，并另做人评。评判器胜率和数学答题正确率不是一个指标。
Lᴰᴾᴼ = −log σ{ β[log(πθ(y⁺|x)/πref(y⁺|x)) − log(πθ(y⁻|x)/πref(y⁻|x))] }

问题 02

一组回答怎样变成有效学习信号？

省价值模型、过滤无梯度组，也要计算额外采样成本。

GRPO用同题多答案相互比较。全部答对或全错时组内没有区分，长响应与不稳定奖励尺度也会改变训练。

增加有效组比例可能提高训练步效率，却要付出额外rollout；应该同时报告生成量和墙钟。

DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models

2024-02-05

03

问题 03

同样的奖励，哪些token实际拿到梯度？

长度归一化、奖励尺度与裁剪粒度都会改变权重。

把同一个优势复制到所有token还不够。先按回答平均还是按token平均、按题内标准差归一化还是固定尺度、逐token还是逐序列裁剪，都会改变同一批数据的贡献。

优化器并非只看正负答案；它看到的是归一化、重要性比和裁剪共同构造的目标。

读图前的算例

好答案长度2，坏答案长度8；再设某序列token比为[1.5,1,1]。比较各论文如何改变分母与裁剪对象，避免把示意阈值写成论文实参。

Understanding R1-Zero-Like Training: A Critical Perspective

2025-03-26

移除长度与组内标准差带来的隐式权重。

  1. 先拆开两个分母 在章首的等单 token 贡献例子里，原版分别除以 20 和 100，两条回答总权重相同。在两个题组里，同为 +0.2 的奖励差又因除以各自标准差，变成 +2 和 +0.5。
  2. 只换长度分母试一次 Dr. GRPO 对 token 贡献求和后用固定常数缩放。比如共同分母取 100，且两条回答优势同为 1，20-token 和 100-token 的贡献为 0.2 与 1。单 token 权重相同，长回答的 token 更多。
  3. 再换优势公式 去掉组标准差缩放后，两条奖励差为 +0.2 的回答都保留 +0.2。这样题组内仍按组均值分正负，题组之间不再因标准差不同自动出现 4 倍幅度差。两处改动都会改变梯度尺度，学习率需要随比较口径记录。
  4. 实验与消融：算法对照 直接对照同时移除了响应长度和组内标准差两个分母，错答缩短明显，末次准确率接近。表 4 另报告 3K 预算下 Oat-Zero-1.5B 的五项平均为 42.1%，同一基座最佳模板为 33.1%。这 9.0 个百分点属于整套训练配方，单个分母的效应仍需拆开比较。 表 4 · 整套配方结果 ↗

从完整推理到多轮交互，成功该归给哪一步？

最终验证可驱动学习，长程动作还需局部信用。

问题 05

训练更快时，数据还来自当前策略吗？

资源重叠减少等待，陈旧策略需要额外校正。

一轮后训练包含生成、评奖、参考/价值推理、反向和权重同步。只优化单个算子很难填满整个管线。

同步放置与异步解耦解决不同瓶颈。异步提高资源利用也改变数据分布，系统与算法必须一起设计。

HybridFlow: A Flexible and Efficient RLHF Framework

2024-09-28

分离数据流与分布式执行，并优化训练到生成的权重重分片。

  1. 一轮RL不是只有损失计算：同题采四条答案后，还要奖励/参考模型推理、优势计算、actor/critic训练，再同步新权重。各阶段最适合的并行划分不同。
  2. 单一控制器表达模型间数据流；各模型内部使用多控制器执行分布式计算。分层API把通信与算法逻辑解耦，能够实现不同模型放置和PPO/ReMax等图。
  3. 3D-HybridEngine专门设计训练与生成的并行分组，尽量复用本地权重、降低重分片通信；设备映射算法再比较同置/分离等安排。
  4. 原实验为公平性强制等长1024输入+1024输出，避免基线没有continuous batching导致不对等；因此其吞吐不能直接外推到今天的变长长推理任务。

AReaL: A Large-Scale Asynchronous Reinforcement Learning System for Language Reasoning

2025-05-30

异步生成与训练，以陈旧度约束和解耦PPO修正策略差。

  1. 示例四条回答长度不同。同步管线等待最长回答，其他生成设备闲置；AReaL分离生成与训练设备，让已完成轨迹持续进入训练，长回答可中断更新权重后续写。
  2. 代价是同一批甚至同一条回答来自多个行为策略。把采样时的πbehav与约束更新的近端πprox分开，重新计算近端概率，分别处理重要性修正与信任域裁剪。
  3. 教学设某token的πbehav=0.20、πprox=0.25、πθ=0.30，则近端比为1.2、外部修正为1.25，总未裁剪重要性比仍为1.5。不同的是裁剪中心围绕最近策略，而不是很旧的采样策略。
  4. 限定最大陈旧度η，旧轨迹优先消费；实验η=4配合解耦目标保持成绩。无限陈旧度仍劣化，因此异步不是越放开越好。
J ∝ (πprox/πbehav) min[ (πθ/πprox)A, clip(πθ/πprox,1±ε)A ]

最大化的原文Equation 5单token结构；将采样校正与裁剪中心解耦。若最小化损失则取L=−J。

问题 01

一组回答怎样形成学习信号？

一组回答怎样形成学习信号？

GRPO

2024-02-05

用同题多次采样的相对奖励代替价值网络。

  1. 先冻结旧策略，为一道题采样一组完整回答，再给每条回答评分。组内平均奖励构成基线，因此不需要另训一个价值模型去预测每个状态的价值。
  2. 结果奖励设定中，回答的奖励减去组均值，再除以组标准差；同一回答的所有 token 共享这个优势。过程奖励版本则给推理步骤评分，某个 token 的优势累加后续步骤的归一化奖励。
  3. 策略更新仍用旧策略概率比和裁剪约束；论文把参考模型的 KL 直接作为损失正则项。组基线替代 critic，并不等于取消旧策略或参考策略。

结果奖励与过程奖励是不同的信号定义。不能把结果奖励下“一条回答共享优势”的解释直接套到逐步骤累加优势的版本。

2025-03-18

分别调整探索裁剪、有效样本和 token 权重。

问题 02

去掉长度归一化解决了什么？

去掉长度归一化解决了什么？

Dr. GRPO

2025-03-26

去掉逐回答长度除数与组内标准差缩放。

  1. 原 GRPO 对每条回答先除以长度，使长回答内每个 token 的权重变小；作者分析这会偏好较短的正确回答，并减轻较长错误回答中每个 token 的惩罚。
  2. Dr. GRPO 去掉这项长度归一化，也不再除以每道题的奖励标准差，保留减去组平均奖励的优势。实现中可以用固定 MAX_TOKENS 常数缩放，而不是用实际回答长度缩放。

这里的无偏对应论文选定的期望结果奖励梯度目标，并采用 β=0 的分析设定；它不是所有长度、公平权重或离策略问题都已解决的保证。

长度加权的结构性冲突

2026-07-25

结果奖励下，梯度正确性与长度中性可能冲突。

  1. 论文将正确性定义为期望估计量与真实策略梯度成固定比例，将长度中性定义为固定优势时的轨迹贡献尺度不随长度改变。
  2. 在文中策略类、可实现长度与组均值基线假设下，正确性要求长度权重为常数；若不同长度的条件贡献尺度不同，就无法同时满足长度中性。

结论针对只依赖长度的权重函数及指定假设；不应扩写为所有奖励、基线和优化器的不可能定理。

旧策略数据如何继续使用？

旧策略数据如何继续使用？

AReaL

2025-05-30

用有界陈旧度与行为策略校正组织异步训练。

  1. 生成与训练分离。参数更新到来时可以中断生成、刷新参数并重算旧 KV，再续写剩余轨迹；一条回答可能由不同参数版本的片段组成。
  2. 系统以有界陈旧度控制生成领先训练的程度，并优先处理较旧轨迹。陈旧度上限太小会限制吞吐，放宽则会增大行为策略与学习策略的差异。
  3. 算法区分实际产生数据的 behavior policy 与作为近端约束中心的 proximal policy。损失组合行为分布校正与相对近端策略的裁剪比率，训练前重算所需概率。

异步调度和概率校正共同组成训练方案。吞吐提高不能单独推出样本效率或相同 GPU 小时下的最终收益。

陈旧度与学习率

2026-07-02

把策略陈旧度和学习率放在同一个局部稳定性条件中。

  1. 最大滞后 S 与步长 η 共同影响行为策略的偏移。论文在局部更新有界及分布、代理梯度平滑条件下得到 O(Sη) 级的单步代理梯度偏差。
  2. 还要区分单批陈旧度限制与累计学习器漂移。局部条件不成为瓶颈时，训练时域 Tη 可能主导失稳；不能只凭一个陈旧度数值预测崩溃。

分析对象是学习器使用的代理梯度映射，不是对依赖策略的数据分布求完整导数，也不是任意优化器的全局稳定保证。
