背景、问题、方法与实验。时间线采用首次公开日期，正文方法及实验链接保留具体论文版本。

VLM能回答“杯子在左边”，机器人还需要输出正确坐标、时序和夹爪状态。VLA的关键接口是观察与语言到动作分布；动作离散化、连续块生成、跨本体数据和在线反馈决定它是否能真正执行。

贯穿教学任务：抓起桌上的薄纸杯，再放到右侧托盘，期间不能压扁杯子。先只考虑视觉与本体状态；滑移和接触反馈在相邻“接触与全身操作”专题展开。教学数字与轨迹不当作作者实测。

本专题讨论单/双臂通用操作与数据泛化，保留不同控制频率、训练预算和成功定义，不展开导航与自动驾驶。实验按所用论文原表或标数图核对，不从没有数值标注的柱图估算提升。

01

问题 01

语义、视觉与动作接口

理解“抓红杯”之后，怎样输出有坐标含义的控制？

语言知识帮助识别对象和任务，却不会自动定义机器人动作单位。不同本体的末端坐标、关节维度、夹爪范围和频率都要明确，否则同一个token可能对应完全不同运动。

视觉编码还需要保留控制所需的细粒度几何。通用图文预训练提供起点，机器人示范负责将语义与执行接口对齐。

读图前的算例 · 教学示意

先识别纸杯与托盘，再预测一小步末端位移和夹爪状态；执行后重新观察。验收对象选对、动作坐标正确、运动可达三个层次。

OpenVLA: An Open-Source Vision-Language-Action Model

2024-09-05

把预训练视觉语言模型改造成动作token预测器，以多本体机器人示范学习视觉指令到控制的映射。

  1. 输入当前RGB图像和任务文字。DINOv2与SigLIP在同一patch上提取互补特征，拼接后经MLP映射到Llama2-7B的嵌入空间。
  2. 将连续7维动作按数据分位数范围离散为256个bin，借用词表中不常用token表示动作；训练时自回归预测这些token，部署时解码并反归一化为控制量。
  3. 用约97万条OXE示范训练，包含跨机器人数据选择、动作归一化和no-op处理。论文发现需更新视觉编码器并多轮遍历数据，单纯冻结视觉前端不足以保证精细控制。
  4. 接着抓杯算例：图中先识别红杯，输出一个相对位姿/夹爪动作；执行后重新拍图再预测。原版主要是逐步动作，不应把这个流程写成已支持高频长动作块。

问题 02

动作块、连续分布与压缩表示

怎样保留连贯精细动作，又避免长序列解码负担？

逐维分bin容易复用语言训练，但高频长动作块产生大量冗余token。连续生成可同时建模多步动作，却需要迭代去噪/积分；压缩离散码则尝试让自回归也能处理高频数据。

这两条路线改变动作分布的表示与求解方式，不自动解决长动作块执行期间的反馈延迟。评测需同时保留重建精度、动作频率、推理成本和真机成功率。

读图前的算例 · 教学示意

将“靠近、抓取、抬起”放进1秒动作块：连续专家从噪声联合生成，FAST则先将平滑轨迹压成更短码序列；两者都要保住闭夹爪时刻。

FAST: Efficient Action Tokenization for Vision-Language-Action Models

2025-01-16

先去掉动作在时间上的冗余，再用语言token编码，让自回归VLA也能学习高频连续行为。

  1. 朴素分bin对每个时间步、每个维度分别编码。1秒14维50Hz动作需要700个token，即使相邻动作几乎相同也重复预测；高频越高，冗余越严重。
  2. FAST先对归一化动作块沿时间维做DCT，用少量低频系数表达平滑轨迹；系数按尺度量化，再按频率优先排列并BPE压缩。反向过程恢复动作近似，压缩不是完全无损。
  3. 训练策略仍然是自回归预测动作token。FAST+把tokenizer在多本体动作块上预训练，减少每个任务重新学编码的需求；它改变动作表示，不直接增加触觉闭环或物理约束。
  4. 接着抓杯算例：腕部平稳靠近的50个相邻位置不必逐个编码，DCT保留主要运动趋势。闭夹爪的急变需足够高频系数；压缩过强会改变接触时刻，应看重建误差与真实执行。

π0: A Vision-Language-Action Flow Model for General Robot Control

2026-01-08

用VLM理解场景与指令，再由连续流匹配动作专家生成高频动作块。

  1. 观察包含多视角RGB、文字指令和机器人本体状态。图像/文本走预训练PaliGemma主干，机器人状态与动作使用额外约300M参数的专家；专家通过注意力使用视觉语言上下文。
  2. 一次预测H=50步连续动作块。训练把真实动作块与高斯噪声线性混合，让动作专家预测去噪速度；推理用10步Euler积分从噪声得到整块动作。
  3. 图像/文本前缀的KV可以缓存，积分过程只重算动作后缀。不同机器人以统一最大维度容器和缺失掩码接入，但控制坐标与有效维度仍须正确对齐。

问题 03

训练数据、任务层次与泛化

新环境能否执行，取决于示范覆盖及语义到运动的连接。

固定桌面上的高成功率可能依赖背景、视角或物体位置捷径。要让模型迁移到新场景，需要真实/合成数据的多样性，以及对本体和任务层级的恰当接口。

数据系统应同时报告采集成功率、训练策略成功率和真机迁移，防止把自动生成很多轨迹当作模型已会泛化。

读图前的算例 · 教学示意

更换杯形、光照、桌面和相机，再给同一抓杯放盘指令；区分物体识别、动作可达性和抓取执行分别在哪里失败。

π0.5: a Vision-Language-Action Model with Open-World Generalization

2025-04-22

混合机器人动作、语义子任务与网页监督，先离散训练再加入连续动作专家，以层次推理连接开放场景语义和操作。

  1. 在同一模型中混合跨本体动作数据、多环境数据、高层子任务预测、网页VQA/定位及语言示范。网页数据补语义覆盖，机器人数据定义如何执行，不能把二者当成可相互替代的训练样本。
  2. 预训练用FAST等离散动作表示，便于统一任务和高效学习；后训练加入连续流匹配动作专家，同时保留文字预测。将训练时适合学习的表示与部署时适合控制的接口分开。
  3. 部署分两层：同一个模型先低频预测语义子任务，再条件化于该子任务生成高频连续动作块。高层不是另一套外接规划器，模型仍会在选错子任务时误导低层。
  4. 接着纸杯算例：新房间中先预测“拿起纸杯”，低层执行抓取；再预测“放到右侧托盘”。更换杯形时检验对象识别，更换摆放时检验动作迁移，单一平均分无法分出两类失败。

04

问题 04

任务进展、探索与真实RL

如何利用失败与在线经验，改进已有动作策略？

示范学习只覆盖专家走过的状态。机器人执行出错后可能进入训练分布外区域，稀疏的最终成功信号又难以告诉模型哪一步错了。

学习相对任务进展可提供更密反馈，但奖励模型和策略可能共同偏差。探索辅助、人类引导与回放预算需要显式计数，不能把所有改进都归于RL算法本身。

读图前的算例 · 教学示意

抓空以后观察到杯子仍在桌上，进展应停滞或下降；模型需重新对齐，而非继续移动空夹爪并误判任务完成。

A Vision-Language-Action-Critic Model for Robotic Real-World Reinforcement Learning

2025-09-19

把相对任务进展、动作与价值估计接入同一模型，为真实机器人RL提供更密的反馈。

  1. 动作监督教模型模仿“怎么做”，却不直接教它判断失败或退步。VLAC将两张状态图与任务文字作为输入，预测相对进展，并用成功示范时间顺序构造监督。
  2. 模型按提示输出动作或进展token，另从上下文隐状态读取value头；动作log-prob、进展反馈和价值一起用于PPO。进展下降可以反映抓空、掉落等情况，但评分器也可能误判。
  3. 真实探索中加入离线示范回放、返回再探索、人类引导等策略，帮助模型进入成功区域。它不是一个完全无人干预的自动自我提升系统。
  4. 接着抓杯算例：若夹爪闭合但杯子没抬起，不能因手臂靠近盘子就给高奖励。用前后观察判断任务进展，再通过探索/示范修正下一次抓取。

问题 05

推理时世界仍在动，怎样连续执行？

区分生成多久的动作，与实际承诺执行多少动作。

一次生成长动作块可以减少调用，却降低对新观察的反应。推理延迟又意味着新动作到达时，旧块已经执行了一段；连续性与反应速度必须一起设计。

Real-Time Chunking

2025-06-09

当前动作块继续执行时异步生成下一块，把已承诺执行的前缀冻结，并补全剩余动作。

  1. 将延迟造成的重叠区间建模为补全问题；利用扩散或流策略的推理期条件约束保持跨块连续。
  2. 推理期采用软掩码与引导权重裁剪来改善跨块连续性；原策略无需修改训练配方。

预测视野与实际执行视野是不同量；长执行段会牺牲反应，过短又可能在不同动作模式间跳变。

§1–3；HTML行43–79；v1 ↗

Adaptive Action Chunking

2026-04-05

根据当前预测动作的熵，动态选择要执行的块长度，在一致性与重新观察之间调节。

  1. 以平均动作熵随块长的变化寻找差分点，同时考虑最小动作幅度；高熵时缩短执行段，低熵时执行更长。
  2. 该策略在推理期选择执行视野，不要求额外训练或修改基础模型结构。

研究对象是带扩散动作头的VLA；固定块长在不同策略和任务上的最佳值不一致。
