第1章：LLM Architecture and Optimization Methods

大语言模型架构与优化方法——从Tokenization到安全对齐的完整技术栈

来源：Agentic AI · 第1章（pp. 35–104） · 阅读笔记

章节摘要

本章系统性地介绍了构建现代大语言模型所需的全部核心技术。从文本如何被切分为token开始，经过Transformer架构的每个组件（Embedding、Self-Attention、FFN、Layer Norm），到训练优化（Adam、学习率调度、混合精度），再到推理加速（Flash Attention、投机解码、模型压缩），以及对齐技术（SFT、LoRA）和安全性考量。本章构成了后续强化学习与Agent系统章节的理论基础，共覆盖17个小节、70页内容。

1.1 How LLMs Work: An Intuitive Overview

大语言模型（LLM）的核心工作原理可以用一句话概括：给定一段文本序列，预测下一个最可能出现的token。这个看似简单的目标，在海量数据和大规模参数的加持下，涌现出了令人惊叹的语言理解和生成能力。

信息处理流程

LLM的完整信息处理管线包含以下步骤：

  1. Tokenization：将原始文本切分为子词单元（subword units），每个token对应词表中的一个整数索引。
  2. Embedding：将离散的token ID映射为连续的高维向量表示，使模型能够在连续空间中捕捉语义关系。
  3. Transformer层堆叠处理：输入向量经过多层Transformer block，每层包含Self-Attention和Feed-Forward Network，逐步构建越来越抽象的语义表示。
  4. Prediction Head：最终隐层表示通过线性投影+Softmax，输出词表上的概率分布。
  5. Decoding：根据概率分布选择下一个token（贪心、采样、Beam Search等策略）。

关键直觉：LLM并不"理解"语言，而是学会了统计意义上的"下一个token应该是什么"。但当这种统计模式足够精确时（由数万亿token训练而得），模型表现出的行为与"理解"难以区分。这正是Scaling Law背后的核心洞察——模型规模、数据量、计算量的指数增长带来能力的涌现。

Self-Supervised Learning 范式

LLM训练采用自监督学习——训练数据本身提供监督信号，无需人工标注。对于decoder-only模型，训练目标是最大化下一个token的对数似然：

$$\mathcal{L}(\theta) = -\sum_{t=1}^{T} \log P_{\theta}(x_t \mid x_1, x_2, \ldots, x_{t-1})$$

其中 $x_t$ 是位置 $t$ 的token，$\theta$ 是模型参数，$T$ 是序列长度。模型通过最小化负对数似然来学习语言的条件概率分布。

从信息论角度看，这等价于最小化模型分布与真实语言分布之间的交叉熵。当模型完美拟合真实分布时，loss等于语言本身的熵（约1.0-1.5 bits/token对英文文本）。

1.2 Tokenization

Tokenization是NLP管线的第一步，决定了模型"看到"的文本粒度。好的tokenization方案需要在词表大小、覆盖率和计算效率之间取得平衡。

Byte Pair Encoding (BPE)

BPE是目前最主流的tokenization算法，被GPT系列、LLaMA等广泛采用。其核心思想是从字符级别出发，迭代地合并最频繁出现的相邻token对。

算法流程：

  1. 初始词表 = 所有单字符（或字节，共256个）
  2. 统计训练语料中所有相邻token pair的频率
  3. 将频率最高的pair合并为一个新token，加入词表
  4. 重复步骤2-3，直到词表达到预设大小（如32K、50K、100K）

示例：假设语料中 "l o w" 出现100次，"l o w e r" 出现50次。BPE首先可能合并 "l"+"o" → "lo"，然后 "lo"+"w" → "low"，逐步构建出常见子词。最终 "lowest" 可能被编码为 ["low", "est"]。

其他Tokenization方法

  • WordPiece（BERT使用）：与BPE类似，但合并选择基于似然增益而非频率。具体地，选择合并后使语言模型训练似然提升最大的pair。
  • Unigram Language Model（SentencePiece）：从一个大词表开始，逐步裁剪对似然影响最小的token，自顶向下构建词表。可以给出概率最优的多种分割方式。
  • Byte-level BPE（GPT-2起）：直接在字节（byte）级别操作，完全消除OOV问题，任何Unicode文本都能被编码。对非英语语言和特殊字符更友好。

最佳实践与特殊Token

现代LLM的tokenization设计遵循以下原则：

  • 词表大小通常在32K-150K之间（GPT-4: ~100K，LLaMA-2: 32K，Qwen-2.5: 150K）
  • 保留特殊token：<BOS>（序列开始）、<EOS>（序列结束）、<PAD>（填充）、<UNK>（未知）
  • 对话模型额外引入角色标记：<|system|>、<|user|>、<|assistant|>
  • 数字和代码通常需要特殊处理（如将数字逐位切分，或为代码保留缩进token）
  • 词表越大，同一文本编码出的token数越少（压缩率更高），但embedding矩阵占用更多参数

HuggingFace Tokenizer 示例

from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("meta-llama/Llama-2-7b")
text = "Hello, how are you?"
tokens = tokenizer.encode(text)
# tokens: [1, 15043, 29892, 920, 526, 366, 29973]
decoded = tokenizer.decode(tokens)
# decoded: "<s> Hello, how are you?"

# 查看子词切分
tokenizer.tokenize("unbelievable")
# ['un', 'bel', 'iev', 'able']

1.3 The Transformer Architecture

High-Level Structure

Transformer（Vaswani et al., 2017）是现代LLM的核心架构。原始Transformer采用Encoder-Decoder结构，但当代LLM主要采用Decoder-Only变体。一个Transformer模型由 $N$ 层相同的block堆叠而成，每层包含两个子模块：Multi-Head Self-Attention和Feed-Forward Network，每个子模块都配合残差连接和层归一化。

Encoder-Decoder vs. Decoder-Only

特征Encoder-DecoderDecoder-Only
代表模型T5, BART, mT5GPT系列, LLaMA, Qwen
注意力模式Encoder双向 + Decoder因果纯因果（causal）掩码
适用任务翻译、摘要等Seq2Seq通用生成、对话、推理
训练信号Encoder和Decoder分离统一的next-token prediction
扩展性较复杂，两部分需分别优化简单统一，易于scaling

Token Embeddings

Embedding层将离散token ID映射为 $d_{\text{model}}$ 维连续向量：

$$\mathbf{e}_i = \mathbf{W}_E[x_i] \in \mathbb{R}^{d_{\text{model}}}$$

$\mathbf{W}_E \in \mathbb{R}^{|V| \times d_{\text{model}}}$ 是embedding矩阵，$|V|$ 是词表大小。在许多模型中（如GPT-2），输出层的投影矩阵与embedding矩阵共享权重（weight tying），减少参数量并提供正则化效果。

Self-Attention 机制

Self-Attention是Transformer的核心创新，允许序列中每个位置直接关注所有其他位置。给定输入 $\mathbf{X} \in \mathbb{R}^{n \times d}$：

$$\mathbf{Q} = \mathbf{X}\mathbf{W}_Q, \quad \mathbf{K} = \mathbf{X}\mathbf{W}_K, \quad \mathbf{V} = \mathbf{X}\mathbf{W}_V$$ $$\text{Attention}(\mathbf{Q}, \mathbf{K}, \mathbf{V}) = \text{softmax}\left(\frac{\mathbf{Q}\mathbf{K}^{\top}}{\sqrt{d_k}}\right)\mathbf{V}$$

$\sqrt{d_k}$ 缩放因子防止点积过大导致softmax梯度消失。直觉上，Q是"查询"，K是"键"，V是"值"——每个token根据与其他token的相关度（Q·K）来加权聚合信息（V）。在Decoder-Only模型中，使用因果掩码确保位置 $t$ 只能关注 $\leq t$ 的位置。

Multi-Head Attention

将注意力分成 $h$ 个头，每个头在 $d_k = d_{\text{model}}/h$ 维子空间中独立计算：

$$\text{MultiHead}(\mathbf{X}) = \text{Concat}(\text{head}_1, \ldots, \text{head}_h)\mathbf{W}_O$$ $$\text{head}_i = \text{Attention}(\mathbf{X}\mathbf{W}_{Q_i}, \mathbf{X}\mathbf{W}_{K_i}, \mathbf{X}\mathbf{W}_{V_i})$$

不同head可以关注不同类型的关系：有的head关注局部语法结构，有的关注远距离语义依赖，有的捕捉位置模式。$\mathbf{W}_O \in \mathbb{R}^{d_{\text{model}} \times d_{\text{model}}}$ 将多头输出融合。变体包括GQA（Grouped Query Attention，多个Q头共享一组K/V）和MQA（Multi-Query Attention，所有Q头共享同一K/V）。

Positional Encoding

Attention机制本身是置换不变的，需要额外注入位置信息：

  • 正弦位置编码（原始Transformer）：$\text{PE}_{(pos, 2i)} = \sin(pos / 10000^{2i/d})$，$\text{PE}_{(pos, 2i+1)} = \cos(pos / 10000^{2i/d})$
  • 可学习位置编码（GPT系列）：位置embedding作为参数学习，但限制了外推能力。
  • RoPE（LLaMA, Qwen）：将位置编码为旋转矩阵作用在Q/K上，$\langle \mathbf{q}_m, \mathbf{k}_n \rangle$ 只依赖相对位置 $m-n$，天然支持长度外推。
  • ALiBi：在attention score上加线性距离偏置，无需额外参数，外推性好。

Feed-Forward Network (FFN)

$$\text{FFN}(\mathbf{x}) = \mathbf{W}_2 \cdot \sigma(\mathbf{W}_1 \mathbf{x} + \mathbf{b}_1) + \mathbf{b}_2$$

隐层维度通常为 $4 \times d_{\text{model}}$。现代模型使用SwiGLU激活：$\text{SwiGLU}(\mathbf{x}) = (\mathbf{W}_1 \mathbf{x} \odot \text{Swish}(\mathbf{W}_3 \mathbf{x}))\mathbf{W}_2$，其中 $\text{Swish}(x) = x \cdot \text{sigmoid}(x)$。使用SwiGLU时隐层维度调整为 $\frac{8}{3}d_{\text{model}}$。

Layer Normalization

$$\text{LayerNorm}(\mathbf{x}) = \frac{\mathbf{x} - \mu}{\sqrt{\sigma^2 + \epsilon}} \odot \gamma + \beta$$

现代模型多用 Pre-Norm（归一化在子层之前）和 RMSNorm：$\text{RMSNorm}(\mathbf{x}) = \frac{\mathbf{x}}{\sqrt{\frac{1}{d}\sum_{i=1}^{d}x_i^2 + \epsilon}} \odot \gamma$，省去均值计算，更高效。

Model Size 计算

$$N \approx 12 L d^2 + V \cdot d$$

每层：$4d^2$（QKV+O投影）+ $8d^2$（FFN）= $12d^2$。例如 LLaMA-7B：$L=32, d=4096$，参数约 $32 \times 12 \times 4096^2 \approx 6.4\text{B}$。

Attention Pathologies

  • Attention Sink：模型将大量注意力分配给第一个token，因为softmax需要将概率分配到某处，而第一个位置总是可见的。StreamingLLM利用此特性实现无限长上下文。
  • Lost in the Middle：长上下文中对中间位置信息利用效率低于开头和结尾。
  • Quadratic Complexity：$O(n^2)$ 计算和内存开销，催生了Flash Attention等优化。

1.4 Prediction Heads

Prediction Head是将Transformer最终隐层表示映射到具体任务输出的组件。不同的头适用于不同训练目标：

1. Language Model Head (LM Head)：最常见的头，用于next-token prediction。将隐状态投影到词表维度，再通过softmax得到概率分布：

$$P(x_{t+1} \mid x_{\leq t}) = \text{softmax}(\mathbf{W}_{\text{LM}} \cdot \mathbf{h}_t + \mathbf{b})$$

通常与embedding矩阵共享权重（tied weights），即 $\mathbf{W}_{\text{LM}} = \mathbf{W}_E^{\top}$。这既减少参数量，又在语义空间中建立了输入与输出的一致性。

2. Classification Head：取特定位置（如最后一个token或[CLS]）的隐状态，通过线性层映射到类别数：

$$\hat{y} = \text{softmax}(\mathbf{W}_{\text{cls}} \cdot \mathbf{h}_{[\text{CLS}]} + \mathbf{b}_{\text{cls}})$$

用于情感分析、自然语言推理（NLI）、文本分类等任务。

3. Regression / Reward Head：输出单个标量值，用于回归任务或奖励模型（Reward Model）：

$$r = \mathbf{w}^{\top} \mathbf{h}_{\text{last}} + b$$

在RLHF中，Reward Model的输出驱动策略优化。通常基于最后一个token的隐状态。

4. Sequence-to-Sequence Head：在Encoder-Decoder架构中，Decoder的LM Head在每个时间步生成输出序列的下一个token。通过Cross-Attention从Encoder接收源序列信息，实现条件生成。

1.5 Optimization Theory

Gradient Descent 基础

所有神经网络训练的核心是梯度下降：沿损失函数梯度的反方向更新参数。

$$\theta_{t+1} = \theta_t - \eta \nabla_{\theta} \mathcal{L}(\theta_t)$$

$\eta$ 是学习率，$\nabla_{\theta}\mathcal{L}$ 是损失对参数的梯度。全量梯度计算成本太高（需遍历全部数据），实际中使用Mini-batch SGD。

SGD 与动量

随机梯度下降使用小batch估计梯度。动量SGD累积历史梯度方向以加速收敛：

$$\mathbf{v}_t = \beta \mathbf{v}_{t-1} + \nabla_{\theta}\mathcal{L}(\theta_t), \quad \theta_{t+1} = \theta_t - \eta \mathbf{v}_t$$

动量参数 $\beta$（通常0.9）使更新方向更平滑，减少震荡，加速通过窄谷（narrow valley）。物理直觉：像球在损失曲面上滚动，具有惯性。

Adam 优化器

Adam结合动量（一阶矩）和自适应学习率（二阶矩），是LLM训练的标准选择：

$$\begin{aligned} \mathbf{m}_t &= \beta_1 \mathbf{m}_{t-1} + (1 - \beta_1)\mathbf{g}_t \\ \mathbf{v}_t &= \beta_2 \mathbf{v}_{t-1} + (1 - \beta_2)\mathbf{g}_t^2 \\ \hat{\mathbf{m}}_t &= \frac{\mathbf{m}_t}{1 - \beta_1^t}, \quad \hat{\mathbf{v}}_t = \frac{\mathbf{v}_t}{1 - \beta_2^t} \\ \theta_{t+1} &= \theta_t - \eta \frac{\hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon} \end{aligned}$$

$\beta_1 = 0.9$（动量衰减）, $\beta_2 = 0.999$（方差衰减）, $\epsilon = 10^{-8}$。偏差校正补偿零初始化偏差。Adam为每个参数维护独立的自适应学习率——梯度稳定的参数步长大，梯度波动的参数步长小。

AdamW（Weight Decay Decoupled）

标准Adam中L2正则化与自适应学习率耦合（导致正则化效果随学习率变化）。AdamW将两者解耦：

$$\theta_{t+1} = (1 - \eta \lambda)\theta_t - \eta \frac{\hat{\mathbf{m}}_t}{\sqrt{\hat{\mathbf{v}}_t} + \epsilon}$$

$\lambda$ 是weight decay系数（通常0.01-0.1）。所有参数施加相同比例衰减，不受梯度大小影响。AdamW是当代LLM训练的事实标准优化器。

学习率调度策略

  • Warmup：从极小学习率线性增大，避免初始梯度过大导致发散。通常warmup步数为总步数的1-5%。
  • Cosine Decay：$\eta_t = \eta_{\min} + \frac{1}{2}(\eta_{\max} - \eta_{\min})(1 + \cos(\pi t / T))$，最流行的调度器。
  • Linear Decay：学习率线性下降至零或最小值。
  • WSD (Warmup-Stable-Decay)：新兴策略——warmup到peak，长时间稳定，最后快速decay。方便续训练。

Gradient Clipping

$$\mathbf{g} \leftarrow \frac{\mathbf{g}}{\max(1, \|\mathbf{g}\|_2 / c)}$$

阈值 $c$ 通常设为1.0。当梯度范数超过 $c$ 时等比缩放，保证更新步长有上界，防止gradient explosion。

混合精度训练 (Mixed Precision)

  • FP16：半精度，范围 $\pm 65504$，需要loss scaling防止梯度下溢。
  • BF16：与FP32相同指数位宽（8位），范围大但尾数精度低。LLM训练首选——无需loss scaling。
  • 实现方式：FP32主权重（master weights）+ BF16/FP16前向反向。梯度在FP32中累加后更新主权重。

混合精度将内存占用减半，在Tensor Core GPU上计算速度提升2-3x，几乎不损失模型质量。

1.6 Flash Attention

标准Self-Attention的计算和内存复杂度均为 $O(n^2)$。Flash Attention通过IO-aware算法设计——利用GPU内存层级（SRAM vs HBM）重构计算顺序，在不改变数学结果的前提下大幅降低内存占用并提升速度。

Flash Attention v1：Tiling + Online Softmax

核心洞察：Attention的瓶颈不在FLOPs，而在HBM访问。标准实现需将完整 $n \times n$ 矩阵写入HBM再读回。

  • Tiling：将Q、K、V分成小块，每块适配GPU SRAM（~20MB），在SRAM内完成注意力计算。
  • Online Softmax：逐块更新softmax分母，无需存储完整 $n \times n$ 矩阵。
  • 效果：内存从 $O(n^2)$ 降到 $O(n)$，训练加速2-4x。

Flash Attention v2：优化并行度

  • 减少非matmul FLOPs（重组算法减少冗余rescaling）
  • 在序列长度维度上并行化（对长序列更友好）
  • 更好的warp间工作分配，减少共享内存同步开销
  • 相比v1进一步加速约2x，接近理论峰值FLOPS利用率

Flash Attention v3：利用硬件特性

  • Warp Specialization：producer warp负责数据搬运，consumer warp负责计算，两者重叠执行
  • TMA (Tensor Memory Accelerator)：利用Hopper GPU的硬件加速数据搬运单元
  • FP8支持：结合block quantization在FP8下执行attention
  • 在H100上达到约740 TFLOPS（FP16），利用率超过75%

Flash Attention v4 / FlashMLA

  • 针对推理decode阶段优化（KV Cache分页管理）
  • 原生支持GQA/MQA
  • Prefill和Decode使用不同kernel策略

核心哲学："计算是免费的，内存访问才是瓶颈"。通过精心设计算法使数据尽量留在快速SRAM中完成计算，最小化对慢速HBM的读写。这是一种IO-Complexity优化范式。

1.7 Pretraining Best Practices

数据质量与多样性

  • 数据清洗：去重（MinHash、Exact Dedup）、过滤低质量内容、语言识别与分类
  • 数据配比：Web数据（~60-80%）+ 书籍/论文（~10-20%）+ 代码（~5-10%）+ 特殊数据
  • Data Curriculum：训练后期增加高质量数据比例，类似从泛读到精读的过程

Scaling Laws

$$C \approx 6ND, \quad N_{\text{opt}} \propto C^{0.5}, \quad D_{\text{opt}} \propto C^{0.5}$$

Chinchilla Law：模型参数 $N$ 和数据量 $D$ 应同比例增长。7B模型约需140B tokens。但实践中过度训练小模型性价比更高（如LLaMA用1.4T tokens训练7B）。

训练稳定性

  • Loss Spike处理：从spike前checkpoint恢复，跳过问题数据batch
  • Z-loss正则：对logits的log-partition function加正则，防止logits数值过大
  • Embedding正则：防止embedding层梯度过大

1.8 Supervised Fine-Tuning (SFT)

SFT的目标与动机

Pretrained LLM具备强大语言能力但不懂"如何对话"。SFT通过高质量指令-回复对微调，教会模型遵循指令、对话格式和拒绝不当请求。

训练目标

$$\mathcal{L}_{\text{SFT}} = -\sum_{t \in \text{response}} \log P_{\theta}(x_t \mid x_{<t})$$

仅对response部分计算loss，prompt部分被mask。模型学习"如何回复"而不是"如何提问"。

LIMA 原则

"Less Is More for Alignment"：仅用1000条精心策划的高质量样本SFT，效果匹敌数万条数据训练的模型。核心发现：数据质量远比数量重要；模型知识来自pretraining，SFT只是"解锁格式"。

SFT 配置最佳实践

参数推荐值说明
学习率$1 \times 10^{-5}$ ~ $5 \times 10^{-5}$比pretraining低10-100x
Epochs2-5过多导致过拟合
数据量1K-100K samples质量优先
序列长度2048-8192覆盖完整对话

高效训练技巧

  • Packing：多条短样本拼接填满max_length，用attention mask隔离
  • NEFTune：embedding层加均匀噪声 $\alpha/\sqrt{Ld}$，提升生成多样性
  • Gradient Checkpointing：用时间换空间，只存部分激活值

1.9 LoRA and PEFT

LoRA 核心思想

Low-Rank Adaptation基于关键假设：微调中权重变化 $\Delta W$ 具有低秩结构。

$$\mathbf{W}' = \mathbf{W} + \Delta\mathbf{W} = \mathbf{W} + \frac{\alpha}{r}\mathbf{B}\mathbf{A}$$

$\mathbf{W} \in \mathbb{R}^{d \times k}$ 冻结，$\mathbf{B} \in \mathbb{R}^{d \times r}$, $\mathbf{A} \in \mathbb{R}^{r \times k}$，$r \ll \min(d, k)$。初始化：$\mathbf{A} \sim \mathcal{N}(0, \sigma^2)$, $\mathbf{B} = \mathbf{0}$，确保训练开始时 $\Delta W = 0$。推理时可合并回原权重，无额外延迟。

LoRA 超参数指南

  • Rank $r$：4-64，通常 $r=16$ 足够。越大表达力越强但参数越多。
  • Alpha $\alpha$：缩放因子，实际缩放为 $\alpha/r$。通常 $\alpha = 2r$。
  • Target Modules：Q、K、V、O投影，可扩展至FFN。

LoRA 变体

  • QLoRA：基础模型量化至4-bit（NF4），LoRA参数保持BF16。内存降4x。
  • DoRA：分解权重为方向+幅值，LoRA只学方向变化。
  • rsLoRA：缩放因子改为 $\alpha/\sqrt{r}$，不同rank表现更一致。
  • LoRA+：$A$和$B$使用不同学习率，加速收敛。

其他PEFT方法

  • Prefix Tuning：每层添加可学习前缀向量
  • Adapter：子层后插入bottleneck MLP（推理有额外延迟）
  • IA3：仅学习K、V、FFN各一个缩放向量
  • Prompt Tuning：仅学习连续输入embedding

1.10 Mixture of Experts (MoE)

MoE 架构原理

MoE将FFN替换为多个Expert网络，每个token只激活少数Expert。大幅增加总参数量（capacity）同时保持每次前向传播的计算量不变。

$$\text{MoE}(\mathbf{x}) = \sum_{i=1}^{E} g_i(\mathbf{x}) \cdot \text{Expert}_i(\mathbf{x})$$ $$g_i(\mathbf{x}) = \begin{cases} \text{softmax}(\text{TopK}(\mathbf{W}_g \mathbf{x}))_i & \text{if } i \in \text{TopK} \\ 0 & \text{otherwise} \end{cases}$$

$E$ 为专家总数（如8-256），TopK通常为1或2。例如Mixtral 8x7B：8个Expert取Top-2，总参46.7B但每token只用12.9B。

Load Balancing

$$\mathcal{L}_{\text{balance}} = \alpha \cdot E \cdot \sum_{i=1}^{E} f_i \cdot p_i$$

$f_i$ 是路由到Expert $i$ 的token比例，$p_i$ 是门控对Expert $i$ 的平均概率。均匀分配时 $\mathcal{L}_{\text{balance}}$ 最小。$\alpha$ 通常取 $0.01$。

Noisy Top-K Gating

$$\tilde{g}(\mathbf{x}) = \mathbf{W}_g \mathbf{x} + \text{SoftPlus}(\mathbf{W}_{\text{noise}} \mathbf{x}) \cdot \epsilon, \quad \epsilon \sim \mathcal{N}(0, 1)$$

训练时加噪声增加探索性，避免过早锁定少数Expert。

1.11 Diversity in LLM Training

训练数据的多样性对LLM的泛化能力至关重要。缺乏多样性的训练会导致模型偏差、能力不均衡和对少数群体/语言的表现不佳。

多样性的多个维度

  • 语言多样性：覆盖多种语言，不能仅依赖英文。多语言训练可以产生跨语言迁移效果——在一种语言上学到的知识可以帮助其他语言。
  • 领域多样性：科学、法律、医学、代码、文学、对话等多种领域均需覆盖。领域间的知识互相补充。
  • 格式多样性：对话、问答、文章、代码、表格、数学推导等不同格式都应包含。
  • 观点多样性：避免训练数据中的系统性偏见（政治、文化、性别等），确保模型能够代表多元视角。
  • 难度多样性：从简单文本到复杂推理链，从基础知识到前沿研究，覆盖不同认知难度。

提升多样性的技术手段

  • Data Mixing：精心设计不同数据源的混合比例，通过实验确定最优配比
  • Upsampling/Downsampling：对稀缺但重要的数据源进行上采样，对冗余数据下采样
  • Deduplication：去除重复数据，增加有效多样性
  • Synthetic Data：对覆盖不足的领域用模型生成补充数据
  • Quality Filtering：高质量过滤器本身不应引入系统性偏差

1.12 Decoding Methods

训练完成后，LLM需要一种策略从输出概率分布中选择token来生成文本。不同解码策略在质量、多样性和效率间做不同权衡。

1. Greedy Decoding

每步选择概率最大的token：$x_t = \arg\max P(x \mid x_{<t})$。优点是确定性且快速，缺点是容易陷入重复循环且多样性差。

2. Beam Search

同时维护 $B$（beam width）个候选序列，每步扩展所有候选的top-k，保留全局得分最高的 $B$ 个：

$$\text{score}(y_{1:t}) = \sum_{i=1}^{t} \log P(y_i \mid y_{<i})$$

通常使用长度归一化：$\text{score} / t^{\alpha}$（$\alpha \approx 0.6$）避免偏好短序列。Beam Search适合翻译等需要精确性的任务，但生成文本缺乏多样性。

3. Temperature Sampling

通过温度参数 $\tau$ 控制分布的"锐利程度"：

$$P(x_i) = \frac{\exp(z_i / \tau)}{\sum_j \exp(z_j / \tau)}$$

$\tau < 1$ 使分布更尖锐（更确定），$\tau > 1$ 使分布更平坦（更随机），$\tau \to 0$ 退化为贪心。通常 $\tau \in [0.6, 1.0]$。

4. Top-k Sampling

只在概率最高的 $k$ 个token中采样，其余概率置零后重新归一化。$k$ 通常取20-100。问题：固定 $k$ 对不同上下文不够灵活——有时分布很集中（应少选），有时很分散（应多选）。

5. Top-p (Nucleus) Sampling

动态选择最小的token集合，使得累积概率 $\geq p$：

$$\text{Top-p}(P) = \{x_i : \sum_{j \leq i} P(x_j) \leq p\}$$

$p$ 通常取0.9-0.95。自适应地根据分布形状调整候选集大小：当模型很确定时只选少数几个token，不确定时候选更多。

6. Min-p Sampling

设定一个相对阈值：只保留概率 $\geq p_{\min} \times p_{\max}$ 的token，其中 $p_{\max}$ 是当前最大概率。比Top-p更稳定，避免了低概率token的干扰。

7. Repetition Penalty

对已生成的token施加惩罚，减少重复：

$$z_i' = \begin{cases} z_i / \theta & \text{if } x_i \in \text{generated} \text{ and } z_i > 0 \\ z_i \times \theta & \text{if } x_i \in \text{generated} \text{ and } z_i < 0 \end{cases}$$

$\theta > 1$ 为惩罚因子。也有频率惩罚（frequency penalty）和存在惩罚（presence penalty）等变体。

8. Typical Sampling

基于信息论：选择信息量接近条件熵的token，排除过于确定（低信息量）和过于意外（高信息量）的token。直觉是：人类语言倾向于"适度惊喜"。

9. Contrastive Decoding

利用大模型和小模型的对比来提升质量：选择大模型概率高但小模型概率低的token。这鼓励选择"只有大模型才能产生的高质量内容"，抑制通用的低信息量token。

实践建议：大多数应用使用 Temperature + Top-p 的组合。创造性任务（写故事）用较高温度（0.8-1.0）+高Top-p（0.95）；精确任务（代码、数学）用低温度（0.1-0.3）或直接贪心。

1.13 Prompt Engineering

Prompt Engineering是通过精心设计输入提示词来引导LLM产生理想输出的技术。它不改变模型参数，而是利用模型的in-context learning能力。

核心策略

  • Zero-shot：直接给出指令，不提供示例。依赖模型预训练中学到的任务理解能力。
  • Few-shot：提供几个输入-输出示例，让模型通过模式匹配理解任务格式。通常3-5个示例效果显著。
  • Chain-of-Thought (CoT)：要求模型展示推理步骤而非直接给答案。"Let's think step by step"可以显著提升数学和逻辑推理准确率。
  • Self-Consistency：多次采样+投票——生成多个推理路径，取最终答案的多数票。用计算换质量。
  • Tree-of-Thought：结构化探索多条推理路径，允许回溯和评估。

Prompt设计原则

  • 明确性：清晰说明任务、期望格式、约束条件
  • 结构化：使用XML标签、markdown格式组织复杂prompt
  • 角色设定：通过system prompt设定模型身份和行为准则
  • 分步拆解：复杂任务拆分为子步骤逐一完成
  • 输出约束：明确指定输出格式（JSON、列表等）以便程序解析

1.14 Model Compression

大模型推理成本高昂，模型压缩技术在保持质量的前提下减小模型大小和计算需求。

量化 (Quantization)

将FP16/BF16权重转换为低精度格式（INT8、INT4甚至更低）：

  • Post-Training Quantization (PTQ)：训练后直接量化，无需重新训练。GPTQ、AWQ、SqueezeLLM等方法。
  • Quantization-Aware Training (QAT)：训练时模拟量化误差，模型学会在低精度下工作。质量更好但需要重训。
  • 权重量化公式：$x_q = \text{round}(x / s + z)$，其中 $s$ 是scale，$z$ 是zero-point。
$$\text{GPTQ}: \quad \min_{\hat{\mathbf{W}}} \|\mathbf{W}\mathbf{X} - \hat{\mathbf{W}}\mathbf{X}\|_F^2$$

GPTQ通过逐列量化+Hessian信息补偿误差，使量化后的输出尽量接近原始输出。通常4-bit量化后质量损失很小（perplexity增加<1%）。

知识蒸馏 (Knowledge Distillation)

用大模型（teacher）指导小模型（student）训练：

$$\mathcal{L}_{\text{KD}} = \alpha \cdot \text{KL}(P_{\text{teacher}}^{\tau} \| P_{\text{student}}^{\tau}) + (1 - \alpha) \cdot \mathcal{L}_{\text{CE}}$$

$P^{\tau}$ 是温度 $\tau$ 下的softmax输出（soft labels），传递了teacher关于类别间相似性的"暗知识"（dark knowledge）。

剪枝 (Pruning)

  • 非结构化剪枝：将小权重置零，产生稀疏矩阵。需要特殊硬件/软件支持才能加速。
  • 结构化剪枝：删除整个attention head、FFN neuron或整层。无需特殊硬件。
  • SparseGPT：在一次前向传播中确定剪枝掩码，无需重训即可达到50-60%稀疏度。

1.15 Speculative Decoding

投机解码利用一个小型"草稿模型"（draft model）快速生成多个候选token，然后用大模型一次性并行验证，从而将自回归生成的串行瓶颈转化为并行验证。

核心算法

  1. Draft model快速生成 $K$ 个候选token：$\tilde{x}_1, \tilde{x}_2, \ldots, \tilde{x}_K$
  2. Target model对整个序列做一次前向传播，得到每个位置的真实概率分布
  3. 从左到右逐个验证：若 $P_{\text{target}}(\tilde{x}_i) \geq P_{\text{draft}}(\tilde{x}_i)$，直接接受；否则以概率 $P_{\text{target}}(\tilde{x}_i) / P_{\text{draft}}(\tilde{x}_i)$ 接受
  4. 在第一个被拒绝的位置从修正分布中采样
$$P_{\text{accept}}(\tilde{x}_i) = \min\left(1, \frac{P_{\text{target}}(\tilde{x}_i \mid x_{<i})}{P_{\text{draft}}(\tilde{x}_i \mid x_{<i})}\right)$$

关键性质：这个接受-拒绝过程保证最终输出的分布与直接用target model采样完全等价——不损失任何质量。加速比取决于draft model与target model的一致性。

加速效果

  • 典型加速2-3x（draft model接受率60-80%时）
  • Draft model越接近target model，接受率越高，加速越大
  • 变体：Self-Speculative（用模型自身的浅层作为draft）、Medusa（多头预测多个未来token）

1.16 Hallucination Detection

幻觉（Hallucination）是LLM生成事实上不正确但看起来合理的内容。这是阻碍LLM在高可靠性场景部署的核心挑战之一。

幻觉类型

  • 事实性幻觉（Factual Hallucination）：生成与已知事实矛盾的内容，如错误的日期、人名、统计数据
  • 忠实性幻觉（Faithfulness Hallucination）：在摘要/翻译等任务中，输出与源文本不一致
  • 推理幻觉：推理步骤中出现逻辑错误但得出看似合理的结论

检测方法

  • 基于不确定性：模型对幻觉内容的输出概率通常较低或方差较大。通过采样多次看一致性。
  • 基于知识库验证：将生成内容与外部知识库进行事实核查（fact-checking）。
  • 自洽性检查（Self-Consistency）：同一问题多次生成，不一致的部分可能是幻觉。
  • RAG验证：检索相关文档，验证生成内容是否有文档支持。
  • NLI-based：使用自然语言推理模型判断生成内容是否被证据支持/矛盾/无关。

缓解策略

  • 使用RAG提供事实基础，减少模型"编造"的需要
  • 训练时的事实性奖励（RLHF中惩罚幻觉）
  • 推理时加入验证步骤（如搜索+确认）
  • 让模型输出置信度，低置信度时拒绝回答或标注

1.17 LLM Safety

LLM安全性涵盖防止模型产生有害输出、抵御对抗攻击、保护隐私等多个方面。

主要安全威胁

  • 有害内容生成：暴力、仇恨言论、违法信息、虚假信息等
  • Jailbreaking：绕过安全对齐的提示攻击。方法包括角色扮演、编码绕过、多轮诱导等
  • Prompt Injection：在输入中嵌入恶意指令覆盖系统提示
  • 数据泄露：模型记忆并泄露训练数据中的隐私信息（PII）
  • 偏见放大：放大训练数据中的社会偏见（性别、种族等）

安全对齐技术

  • RLHF/RLAIF：通过人类（或AI）反馈强化学习，训练模型拒绝有害请求
  • Constitutional AI：让模型根据一组规则（"宪法"）自我改进和自我批评
  • Red Teaming：专门团队尝试攻击模型，发现并修补漏洞
  • Safety Classifier：在输入/输出端部署分类器过滤有害内容
  • Guardrails：系统级的安全防护层（如NeMo Guardrails），拦截不安全的输入输出

安全与能力的权衡

过度的安全限制会导致"过度拒绝"（over-refusal）——模型拒绝正常、合理的请求。好的安全对齐应该是精准的：拒绝真正有害的请求，同时对合法请求保持helpful。这需要细粒度的安全策略，而非简单的关键词过滤。

本章关键要点

  • LLM的核心是Next-Token Prediction——简单目标+大规模数据+大参数产生涌现能力
  • BPE是主流Tokenization方法，词表大小在32K-150K之间权衡覆盖率与计算效率
  • Transformer的核心是Self-Attention（O(n²)）+ FFN，通过Multi-Head捕捉多种关系模式
  • AdamW + Cosine LR Schedule + Gradient Clipping + BF16 是LLM训练的标准配置
  • Flash Attention通过IO-aware算法设计将内存从O(n²)降到O(n)，加速2-4x
  • SFT通过少量高质量数据"解锁"模型的对话能力（LIMA原则：质量>>数量）
  • LoRA通过低秩分解实现高效参数微调，推理时可无损合并
  • MoE用稀疏激活实现"大参数量+小计算量"，Load Balancing是核心挑战
  • 解码策略（Temperature, Top-p, Min-p等）在质量、多样性、效率间做权衡
  • 投机解码通过小模型草稿+大模型验证实现无损加速2-3x
  • LLM安全需要多层防御：对齐训练 + 安全分类器 + 系统Guardrails

自测问答

Q1: 为什么Decoder-Only架构成为LLM主流？相比Encoder-Decoder有何优势？

Decoder-Only架构有三个关键优势：(1) 统一性：所有任务统一为next-token prediction，简化训练管线；(2) Scaling简单：只需增加层数和维度，无需考虑encoder/decoder比例；(3) 因果掩码天然支持生成：训练和推理使用相同的注意力模式。实验也表明，在足够规模下decoder-only模型可以通过in-context learning完成encoder-decoder擅长的任务。

Q2: Flash Attention为什么能在不改变计算结果的情况下加速？核心洞察是什么？

核心洞察是"计算cheap，内存IO expensive"。标准attention需要将完整$n \times n$矩阵写入HBM再读回（IO bound），而GPU SRAM（~20MB）远快于HBM。Flash Attention通过Tiling将计算分块在SRAM内完成，配合Online Softmax逐块更新归一化因子，避免存储完整attention矩阵。数学结果完全相同（精确等价，非近似），但IO复杂度从$O(n^2)$降至$O(n)$。

Q3: LoRA为什么能以很少的参数达到接近全参数微调的效果？

基于"内在维度"（intrinsic dimensionality）假说：预训练模型已经学到了丰富的表示，微调只需要在一个低维子空间中调整。$\Delta W$的有效秩远小于$\min(d,k)$，所以用$r=16$的低秩分解就能捕捉大部分有用的变化方向。这也解释了为什么全参数微调容易过拟合（自由度太高），而LoRA的低秩约束反而提供了有效的正则化。

Q4: Speculative Decoding如何保证输出分布与原始模型完全一致？

通过精心设计的接受-拒绝采样（rejection sampling）方案：当draft model的token概率不超过target model时直接接受；否则以$P_{\text{target}}/P_{\text{draft}}$的概率接受，被拒绝时从修正分布$\max(0, P_{\text{target}} - P_{\text{draft}})$中重新采样。这在数学上等价于从target model直接采样，因此零质量损失。加速来源于大模型的前向传播可以并行验证多个token。

Q5: MoE中Load Balancing Loss为什么重要？如果去掉会怎样？

没有Load Balancing Loss，门控网络会快速收敛到"赢者通吃"模式——少数expert接收大部分token，其余expert得不到训练信号，形成正反馈循环最终退化为稠密模型（甚至更差）。Balance Loss通过鼓励均匀分配来对抗这种"路由坍塌"。但$\alpha$需要调节：太小不起作用，太大会强制均匀分配牺牲路由质量。Noisy Top-K Gating通过添加噪声增加探索性，是另一种缓解方式。

Q6: 为什么AdamW比Adam+L2正则更好？两者的区别本质是什么？

在标准Adam中，L2正则的梯度$\lambda\theta$会被Adam的自适应学习率缩放（除以$\sqrt{\hat{v}}$），导致对不同参数的正则化强度不一致——梯度大的参数正则化反而弱。AdamW将weight decay从梯度更新中分离出来，直接对参数乘以$(1-\eta\lambda)$，确保所有参数受到一致的衰减。本质区别：Adam中正则化与自适应学习率耦合，AdamW中两者解耦独立作用。
