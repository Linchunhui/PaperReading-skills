先说结论：扩散语言模型开始补“系统短板”

本月最重要的变化，不是又多了一个 mask schedule，而是四块曾经彼此割裂的工程开始合拢：可继承的混合骨干、长上下文训练并行、学习式低步数解码，以及跨 chunk 的受限状态推理。其中 dQwen3.5 把线性／混合注意力正式带进可开源评测的基座；Block Parallelism 和固定状态缓存则分别从训练和推理侧把长上下文账单压下来。

重要主线

新模型 · 混合注意力 · 开源

① dQwen3.5：不必把整个 AR 骨干都改成全双向

它把 Qwen3.5 的注意力层改为双向，但保留占多数的因果 Gated DeltaNet 层。核心判断很实用：序列全局交互可由少量 attention 提供，而线性状态层继续负责便宜的递推。作者发布 0.8B、2B、4B、9B 基座权重，适配训练只用 50B 或 100B token，数据配比为代码 50%、文本 35%、数学 15%，训练上下文 4K。

≈ 1/2达到匹配训练损失所需适配 token，相比全注意力 dQwen3 控制组
6 / 72B、50B-token 版本超过 CoDA（200B token）的评测数
4 / 79B、50B-token 版本相对既有 DLM 取得最佳的评测数

为什么重要：这比“再造一个全双向 Transformer”更接近现实继承路径，也首次把线性／混合注意力与离散扩散基座放在同一条可开源复现实验线上。HumanEval 上，9B 版本在作者测试的每个大于 1× NFE 加速点均领先同类 DLM。

边界：仍是 base 模型，没有 SFT／RL；训练上下文只有 4K。论文中最直接的混合 vs 全注意力控制并非完全同源架构，不能据此把所有优势都归因于混合注意力。

论文 · 9B 模型页

长上下文 · 分布式训练 · Agent SFT

② Block Parallelism：扩散训练不必让每张卡都保存整段序列

Block Parallelism（BP）让不同设备并行处理不同 block；Context-Sharded BP（CSBP）进一步把 block 内上下文分片，针对扩散训练中“目标 token 已知、但遮罩组合不断变化”的结构复用计算。它覆盖 AR→双向扩散转换、SFT 和 drafter 训练。

1.61×16×H200、512K 上整模型训练提速
7.59×8×H100、1M 上 DFlash2 drafter 训练提速
+1 pt12 小时 LoRA SFT 后，SWE-bench Verified 与 Terminal-Bench Lite 均提升约 1 点

Agent 价值：它没有发布一个新的通用 Agent 基座，但直接把 DiffusionGemma 26B-A4B 的代码 Agent 长上下文 SFT 压进 12 小时窗口，并在每个中间 checkpoint 都提高通过率；这是本月最扎实的 Agent 侧增量。

边界：这是训练侧并行，不会直接加速未知 token 的在线生成；最大收益依赖 8–16 张 H100/H200，单机开发者暂时吃不到同等红利。

论文 · Turbo-dLLM 代码

线性状态 · 长上下文 · 缓存

③ Fixed State, Long Reach：真正稳定的是“每步状态大小”

作者在统一的 block diffusion 接口下训练三个 3B 去噪器：全注意力、Mamba、混合。每个模型训练 300B token、训练上下文 1K，并使用可精确缓存的接口。结果把“线性注意力是否适合扩散”从 FLOPs 讨论推进到单卡长上下文实测。

6.8 msMamba 在 256K 的单步延迟；注意力为 29 ms
7.5 GBMamba 在 256K 的显存；注意力为 82 GB
296 tok/sMamba 单流吞吐；注意力为 114 tok/s

长距离“针”检索也更抗外推：Mamba 在 2K／4K／8K／16K 上为 75.7%／32.3%／23.6%／22.3%，全注意力在 2K 已降到 12.3%，8K 与 16K 为 0。混合模型大多居中。

边界：这些模型只在 1K 上训练，256K 主要证明资源曲线，不等于高质量 256K 理解；绝对检索正确率仍低，且 Mamba／混合多 11%–13% 参数。

论文

采样 · 蒸馏 · 推理加速

④ TSD + Early-Bird：把“何时落笔”变成可学习问题

Temporal Self-Distillation（TSD）

让较早时间步的 token 分布靠近模型自己最终承诺的分布，不需离线教师轨迹，也能接在 RL 后模型上。LoRA 只有 83.9M 可训练参数（约 1.05%），论文用 2 张 A100／H200 训练约 3000 步。

4.5×Countdown 达到约 80% 时：约 20 NFE vs 基线约 90 NFE
2.3×MBPP 相对 LLaDA 达到同等质量所需 NFE 的降幅
45 NFEMBPP 约 50%、HumanEval 约 40% 的工作点

Early-Bird Decoding

用轻量 router 预测可同时提交的动态 block，再用位置感知策略决定落笔顺序。作者在 LLaDA-8B、Dream-7B、LLaDA1.5 上报告相对 vanilla 3.53×–18.76× 吞吐提升；相对 Fast-dLLM 最高 1.58×，精度大致相当。

边界：TSD 主要把同等能力搬到更低 NFE，并不提高峰值能力；reward 加权依赖可程序验证正确性。Early-Bird 只测 256／512 长度、batch=1，连续批处理与线上服务尚未验证，部分 router 还受词表与长度绑定。

Agent · RL · 受限状态推理

⑤ Register Tokens：让 chunk 之间传隐藏状态，而不是只传文本摘要

固定数量的 register token 在一段推理完成后保留隐藏状态，普通输出 token 可清空；下一 chunk 继续读这些寄存器。实验基于 LLaDA／Dream，默认 4 个 register、128-token chunk，并提出 chunked diffu-GRPO 做后训练。

+8.5数学任务相对离散文本 carry 的最高提升
+19.5代码任务相对离散文本 carry 的最高提升
+8.1LongArithmetic 上 diffu-GRPO：31.6 → 39.7

Countdown 的有界奖励均值在 200 步 RL 后从 19.7 提到 22.3（+2.6）。这条路线更像 Agent 的“受限工作记忆”：状态常数大小，但能跨步延续，不必把中间推理完全外显成文本。

边界：超出训练 chunk 数后的严格精确匹配仍很少；RL 设置中寄存器对 prompt 可见，不等于完全私有的隐状态。训练成本也高：论文报告多组 8×B200、约 12–24 小时级实验。

早期信号：值得跟，但证据还不够硬

理论

Limits of Confidence

证明逐位置置信度无法判断一组 token 是否条件独立；在 ScanAndAdd 上，所有一次写入 ≥2 个未定位置的组都依赖，生成分布的 total variation 是采样噪声底的 29×，但逐样本指标仍为 1.0。

意义：高置信度并行提交可能系统性错配联合分布。局限：目前主要是合成闭式分布，不是 7B+ 模型实证。
论文

结构

DA-DLM

用位置定向 DAG 显式建模相邻 token 依赖，复杂度由位置自由 DAG 的 O(N³K²) 降到 O(NK²)。LM1B／OpenWebText 上，BD3LM B16 的 3.46／3.11 降到 3.30／2.92；只增约 2.5M 参数。

局限：仍是小规模语料与约亿级 backbone，尚未证明能扩到指令模型。
论文 · 代码

连续表示

RMDM

把外部编码器提取的全局语义表示映到高斯先验，再条件化离散去噪。OpenWebText、1024 长度上，16 步 GenPPL 126.58 vs MDLM 213.44；匹配 GenPPL≤50 时 287 vs 80 tok/s（3.6×）。

局限：同步数约慢 10%，训练时长更高，且仍是无条件文本建模。
论文

AR×Diffusion

Zarya

同一 Qwen3 骨干联合训练 AR 与 masked diffusion，用 2→64 token 的 slot curriculum；推理可选纯 MDM 或能完整复用 KV cache 的 slotted speculative 模式。已开放 0.6B／1.7B／4B。

局限：论文主结果仍只有 0.6B，2K 上下文，且标注为进行中工作。

硬件

Edge BDLM Accelerator

面向 Jetson 级设备的 block-diffusion 协同设计，论文仿真报告 1.5B／7B 能耗降 3.79×／3.96×、延迟提速 2.88×／4.44×，分数下降少于 1 个百分点。

局限：是建模与仿真，并非真实芯片端到端测量。

本月没有出现“新的通用 Agent 型扩散基座”。Agent 方向的实质增量，一条是 register 隐状态 + 分块 RL，另一条是 CSBP 把长上下文代码 Agent SFT 变得更可训练。把它们称为“Agent 工程组件”比称为“新 Agent 模型”更准确。

下月应盯住的三个验证点

  1. 混合注意力是否保住真实长上下文质量。dQwen3.5 证明适配效率，但还缺 32K–256K 训练后的检索、代码仓库级任务与服务侧缓存数据。
  2. 学习式提交策略能否进入 continuous batching。Early-Bird 的 batch=1 吞吐不是线上吞吐；需要报告多请求调度、尾延迟和 KV／状态缓存占用。
  3. 受限状态是否能跨环境反馈循环。Register Tokens 当前主要是分块推理题；真正 Agent 验证应加入工具结果、错误恢复与多轮观测，而非只延长内部算式。

一句话判断：9 月的胜负手不是“扩散能不能并行”，而是并行之后能否保持联合一致性、复用状态，并把训练与服务成本降到可部署区间。
