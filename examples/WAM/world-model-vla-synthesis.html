世界模型 × VLA：三篇 2026 路线对照

MMaDA-VLA · UD-VLA · VLA-JEPA — 在动作输出之前先"看见"未来

2026-05-22 · 三篇都在 2026 上半年公开，都把"未来观察"塞回 VLA · 配合 π 系列编年史 一起看

导读：三篇要给你什么

2026 年开头四个月里，VLA（Vision-Language-Action）领域出现一波明显的转向——不再单纯预测动作，而是同时预测一帧"未来该长成什么样子"。这件事原本是世界模型的活，但这几家不是去做一个独立的世界模型再接动作头，而是把未来观察直接焊进 VLA 自己的训练目标和推理过程里。MMaDA-VLA、UD-VLA、VLA-JEPA 是三家在同一时间窗里、用三种不同方式回答这个问题的代表作。

这份对照笔记要做的事：

  1. 每篇论文单独讲一遍：出发点、方法、关键发现——读完任一节都可独立带走结论。
  2. 把三家放在同一张图上对比：在哪个空间预测未来（像素 / 离散 token / 连续潜在）、用什么损失训练（mask predict / flow matching / JEPA 对齐）、推理时世界模型出不出现。
  3. 讲清三家共享的设计直觉、和最分歧的几条路。
  4. 放回 π 系列的语境里看一下：π 们靠"加数据"，这三家靠"加监督信号"。

三家选了不同的"未来"形态，但共享同一个潜在假设——VLM 主干自己学不到的环境动力学，得靠"预测下一帧"补上。

三篇要回答的同一个问题

过去两年的 VLA 路线里，动作监督一直是孤立的——给一张当前图、一句指令，让模型直接吐出动作向量。这有两个公开痛点：

  1. 没有时间感。"拧瓶盖"这种动作，模型看不到"半圈之后瓶盖会脱开"的中间状态，只能从大量示教里靠相关性学。
  2. 视觉表征跟控制割裂。VLM 主干在 web 上学到的视觉表征针对"识别"而不是"动力学"——能告诉你"这是个杯子"，但说不清"被推一下后它会怎么动"。

三家给出的共识答案是：把"预测未来观察"当成 VLA 的辅助监督，让动作头被未来约束着出。但分歧在怎么实现这个约束：

三个不同的回答：
UD-VLA：把未来图像 token 和动作 token 放进同一条离散扩散轨迹，让它们在每一步去噪里互相条件、互相梯度。
VLA-JEPA：完全不在像素空间预测，让目标编码器（V-JEPA2）从未来帧产出一个潜在向量，让 VLA 的预测头去对齐这个向量——未来从不流进 VLA 主干。
MMaDA-VLA：直接在一个原生离散扩散大模型里，让"目标图像 token + 动作 chunk token"同时被并行去噪生成。

读完这三篇之后会发现一件事：它们其实在解一个更深的问题——动作不是孤立的输出，是"对未来世界的承诺"。三家都在用不同方式让这个承诺被显式建模。

MMaDA-VLA：原生离散扩散主干，目标图与动作 chunk 一起去噪

Westlake University · 2026.03 · arXiv:2603.25406 · LIBERO 98.0 · CALVIN 4.78

出发点

作者把现有 VLA 分成三类，认为各有结构性短板（见 Fig 1a）：

  • Vanilla VLA（VLA-Adapter / OpenVLA）：VLM + policy head，纯端到端。没有显式的世界建模，长时任务容易飘。
  • Generative Policy（GR00T、SEER、VPP）：先有一个独立世界模型生成目标观察，再有一个 inverse dynamics 模块把当前观察+目标观察转成动作。问题：两段式，模块之间有误差累积；架构复杂。
  • Unified MLLM（CoT-VLA、UniVLA）：用一个统一多模态 LLM 同时输出目标观察和动作。但这些都是从自回归 LLM 上 fine-tune 出来的，预训练目标跟"并行去噪动作"天然不一致。

MMaDA-VLA 的解法是：既然存在一个原生离散扩散大模型（MMaDA-8B-Base，文本/图像同一离散 token 空间、mask predict 训出来的），那就直接把动作 token 加进去，端到端 fine-tune 出 VLA——没有从自回归预训练继承下来的不一致，也不需要外挂世界模型。

方法详解

① 把 VLA 变成"联合去噪"问题

策略 $\pi_\theta$ 不再只输出动作 chunk，而是同时输出未来时刻的目标观察 $\tilde{o}_{t'}$ 和这之间的动作 chunk $\hat{a}_{t:t'-1}$：

$$ (\tilde{o}_{t'}, \hat{a}_{t:t'-1}) \sim \pi_\theta(o_{t'}, a_{t:t'-1} \mid o_t, l), \quad t' = t + k $$

翻译：给定当前观察 $o_t$ 和指令 $l$，让策略联合采样未来 $k$ 步后的目标观察和这一段动作 chunk。两件事一起做，不是先做一件再做另一件。

② 统一 prompt 模板（语言/图像/动作同一 token 空间）

所有模态被串成一条 token 序列，用特殊定界符隔开：

$$ x = [\text{SOO}]\tilde{o}_t[\text{EOO}][\text{SOL}]\tilde{l}[\text{EOL}][\text{SOO}]\tilde{o}_{t'}[\text{EOO}][\text{SOA}]\tilde{a}_{t:t'-1}[\text{EOA}] $$

翻译：当前图像（用 MAGVIT-v2 编码成离散 token）、语言指令、目标图像、动作 chunk（每维量化成 256 个 bin 之一）拼成一长串。SOO/EOO 是图像起止符，SOL/EOL 是语言起止符，SOA/EOA 是动作起止符——本质上让动作 token 看起来跟"另一种语言"一样。

③ Mask-predict 损失

训练目标完全沿用 MMaDA 的 mask predict：随机遮蔽一部分 token，让模型预测被遮蔽位置的原始 token。

$$ \mathcal{L}(\theta) = -\mathbb{E}_{t,x,x^m}\left[\frac{1}{N}\sum_{i=1}^n \mathbf{1}[x_i^m = [\text{M}]] \log \pi_\theta(x_i \mid x^m)\right] $$

翻译：从训练样本 $x$ 随机生成一个带掩码的版本 $x^m$，模型只对被掩位置（指示函数 $\mathbf{1}[\cdot]$ 选中）算交叉熵。$n$ 是被掩位置数，$N$ 是归一化常数。这跟 BERT 的 MLM 目标几乎一样，只是 token 词表里同时容纳了图像和动作。

④ Hybrid Attention：模态内双向、模态间因果

在一条 token 序列里，模态内（如动作 chunk 内部的 7 个动作）允许双向看；模态间（如动作看图像）则只允许因果方向（动作看观察、不让观察看动作）。消融显示这套设计比纯因果或纯双向都好。

⑤ 推理：置信度引导的并行去噪

把目标图 token 和动作 token 都初始化为 [M]，模型一次性预测所有位置；保留置信度高的预测（不再换掉），把置信度低的位置重新设回 [M]，下一轮再预测。如此迭代 K 步后输出（论文用 K=16 左右）。关键观察是：动作和目标图的预测在同一轮里互相提供条件——动作越确定，目标图的预测越准；目标图越清晰，动作的预测越准。

⑥ 训练数据

大规模预训练用了 61M 样本，来自 25+ 数据集（DROID 占 49.94%，BC-Z 占 9.95%，其余 OXE 家族零散补齐）。fine-tune 阶段才接入特定 benchmark/真实机器人的数据。

关键发现

  • SOTA：LIBERO 98.0% 均值（超过 π₀.₅ 96.9%、GR00T N1.6 等），CALVIN 4.78 平均完成长度。
  • 世界模型是核心命脉：去掉目标图监督，CALVIN 跌掉 0.48——比换 attention pattern、改并行/串行的代价都大。这给"为什么要预测未来观察"提供了直接证据。
  • 并行优于串行：让目标图和动作一起去噪比"先生成图再根据图生动作"好 0.4。说明 MMaDA-VLA 的"互相条件"不是装饰，是真的让动作和图互相校准。
  • Hybrid attention 优于纯双向 / 纯因果：纯双向掉 0.26，纯因果掉 0.29——模态内放双向、模态间锁因果这种"既要又要"的设计真的有效。
  • 真机 AgileX Piper 上击败 GR00T N1.6：83.3-93.3% vs GR00T <70%，证明扩散主干在真实机器人上不只是 benchmark 选手。

UD-VLA：联合离散去噪过程（JD3P），让图像和动作互为梯度

HKUST(GZ) · 2025.10 · ICLR 2026 · CALVIN 4.64 · 4× AR 推理速度

出发点

UD-VLA 的作者把"统一 VLA"分成两条已有路线，都嫌不够：

  • 路线 1：外挂扩散专家（GR-1、SEER、DreamVLA）——视觉、动作各自有独立的扩散 decoder。问题：模块解耦，视觉生成和动作生成没有直接梯度交流。
  • 路线 2：统一 token 空间但分阶段解码（CoT-VLA、WorldVLA、UniVLA）——把所有模态压到一个 token 空间，但训练时先解码图像、再解码动作；推理时视觉只用作训练辅助，被丢弃。问题：推理时图像生成的好处没了。

UD-VLA 的核心立场是：真正的统一不是把模态拼在一起，而是让它们在同一条去噪轨迹上互相条件、互相梯度。具体做法是离散扩散，未来图像 token 和动作 token 共享同一组 mask schedule、同一个去噪头。

方法详解

① 统一离散 tokenization

所有模态都被量化成离散 token，词表是三段拼接：text（Emu3 词表）、image（VQ tokenizer 输出 $V_v$ 维）、action（FAST tokenizer 输出 $V_a$ 维）。再加上 [BOI][EOI] 和 [BOA][EOA] 特殊定界符，序列长这样：

$$ [\text{text tokens}; \text{current image tokens}; \text{future image tokens}; \text{action tokens}] $$

翻译：前两段（text + 当前图）是输入条件，后两段（未来图 + 动作）是模型要并行生成的目标。注意未来图像 token 是固定长度（图像分辨率固定），动作 token 是可变长度（动作 chunk 长度可变），共享同一个 mask 机制。

② Hybrid Attention 模式

这是 UD-VLA 整个设计的关键：

  • Future Image 块内双向：图像 token 之间互相看，能保证生成图的全局一致。
  • Action 块内双向：动作各维度之间互相看（位置 / 旋转 / 夹爪不是严格因果关系）。
  • 跨块用因果方向：动作能看未来图像，但未来图像看不到动作。这一条把端到端动作预测显式分解成两步：先 foresight（出未来图），再 inverse kinematics（出动作）——但在同一个 forward pass 里完成。
为什么不让未来图看动作？因为那样就引入了"动作 → 未来图"的反向通路，相当于让模型用动作来作弊预测未来，反而抑制了视觉表征的世界建模能力。这是 UD-VLA 一个很显式的设计选择。

③ Joint Discrete Denoising Diffusion Process (JD3P)

把未来图 token 序列 $\mathbf{v}_0$ 和动作 token 序列 $\mathbf{a}_0$ 拼起来，按概率 $\beta_t$ 用 [MASK] 替换：

$$ \mathbf{Q}_t \mathbf{e}_{t,r} = (1 - \beta_t) \mathbf{e}_{t,r} + \beta_t \mathbf{e}_{\text{M}} $$

翻译：transition matrix $\mathbf{Q}_t$ 对位置 $r$ 上的 token 做独立两选一——以 $\beta_t$ 概率换成 [MASK]，否则保持原样。

实际训练时作者并不展开整个 $T$ 步去噪链，而是用单步 mask-predict：

$$ \mathcal{L}_{\text{CE}}(\theta) = -\omega \sum_j \log p_\theta^{(v)}(v_{0,j} \mid \mathbf{v}_t, \mathbf{c}) \cdot \mathbf{1}\{v_{t,j} = \text{M}\} - \sum_i \log p_\theta^{(a)}(a_{0,i} \mid \mathbf{v}_t, \mathbf{a}_t, \mathbf{c}) \cdot \mathbf{1}\{a_{t,i} = \text{M}\} $$

翻译：分别对图像 token 和动作 token 算 cross-entropy（只算被 mask 的位置），$\omega$ 是图像项的下采权重避免它压过动作。一步预测大幅简化训练，等价于扩散过程的单点近似。

④ 两阶段训练

  1. Stage (i) 世界模型式后训练：在大规模视频数据上训 [text; current image; future image]——让 VLM 学会"看一帧能预测下一帧"。这是 UD-VLA 把通用 VLM 升级成"会想象未来"的关键。
  2. Stage (ii) 联合 fine-tune：加入 action token，按 JD3P 同时训练图像生成和动作生成。

⑤ 推理优化

  • Prefix KV-Cache：text 和 current image 是输入，永远不会被 denoise，缓存它们的 KV。
  • Pre-filling 特殊 token：[BOI]/[EOI]/[BOA] 这种永远在固定位置出现的 token 提前填好，节省每一轮去噪的计算。
  • Confidence-Guided Decoding：用 cosine mask schedule $\rho_t = \cos(\frac{\pi}{2} \cdot \frac{T+1-t}{T+1})$ 控制每一轮揭开多少位置；按 max-probability 排序，top-K 高置信度位置用 Gumbel-max 采样更新，其余保持 [MASK]。
  • Decoding Space Mapping：图像位置只允许采图像 token，动作位置只允许采动作 token——避免跨模态串位。这是个简单但关键的工程细节。

关键发现

  • 未来图监督值 +0.43，比"重建当前图"值 +0.18 的两倍还多——关键不在生成更精细的视觉，在让模型预测时间上的下一步。
  • SOTA：CALVIN 4.64 超过 MDT (4.52)、UP-VLA (4.42)、UniVLA (4.26) 等；LIBERO 92.7% 均值；SimplerEnv-WidowX 62.5%。
  • JD3P 的 4× 加速：219 tok/s 对比纯 AR 的 50 tok/s，比独立扩散（ID = 145 tok/s, 2.9×）和 Jacobi 并行（101 tok/s, 2.0×）都快——联合去噪不只是更准，更顺路把推理顺序问题解了。
  • 未见物体上的视觉泛化：作者特别比较了 GR00T N1 和 UniVLA——前者没有视觉预测，未见物体上掉得明显；后者有视觉但推理时不用，掉幅居中；UD-VLA 推理时让视觉持续参与，未见物体成功率最高（论文 Fig 3）。
论文承认一个 limitation：生成的未来帧在细节像素质量上不算高（机器人手臂的细节有时糊），但任务级别的语义和动力学是对的——对动作来说够用了。这也说明"未来观察"对 VLA 的价值不在像素保真，在 hint 出"接下来会怎么变"。

VLA-JEPA：完全不预测像素，让潜在表征对齐"未来"

USTC + Tsinghua + 等 · 2026.02 · arXiv:2602.10098 · LIBERO 97.2 · LIBERO-Plus 79.5

出发点

这篇是三家里出发点最尖锐的——作者觉得"latent action from video"这条线整体上学错了东西。他们列了四个失败模式：

  1. 像素级目标偏向外观：常见做法是用未来作监督（要么直接预测像素，要么压缩 frame-to-frame 差分到潜在），结果学到的是纹理 / 光照 / 背景杂物这些方差大但控制性低的东西。
  2. 真实世界视频放大噪声运动：摄像机抖动 / 背景人物移动这些非交互噪声，往往比真实"被机器人推动"的状态变化更显著——基于 frame-difference 的目标，最后学成了"运动 delta encoder"而不是"动力学 encoder"。
  3. 信息泄漏让 latent action 退化成 shortcut：很多 latent-action pipeline 同时把当前观察和未来观察灌进同一个模块，或者训练时让 latent action 看到未来——latent action 就直接 encode 未来本身，语义上变成空壳。
  4. 多阶段训练复杂脆弱：典型做法 representation pretraining → latent-action learning → policy learning 三段式，stage-wise 不一致，难训。

所以 VLA-JEPA 立的核心原则是"leakage-free latent state prediction"：让 target encoder（V-JEPA2）从未来帧产生潜在 target，让 student encoder（VLA 主干）只看当前观察去预测这个 target——未来从不进 VLA 主干。

方法详解

① 世界状态编码（state encoder）

每条样本来自一个 episode 的多视角观察 $O_v = (I_{v,t_0}, \dots, I_{v,t_n})$。每个视角的帧过 V-JEPA2 编码：

$$ s_{t_i} = \big\|_v F(I_{v,t_i}) $$

翻译：$F(\cdot)$ 是 V-JEPA2 这个用自监督视频对比目标预训过的编码器；$\|_v$ 是把多视角的输出拼起来。$s_{t_i}$ 就是时间 $t_i$ 的统一世界状态表征。

② Latent Action Token + World Model

VLM（这里用 Qwen3-VL）会输出一组特殊的可学习 token $\langle\text{latent}_i\rangle$，每个 token 总结从 $t_0$ 到 $t_i$ 之间的潜在动作：

$$ z_{t_i} = p_\theta^{\text{VLM}}\left(\langle\text{latent}_i\rangle \mid \{I_{j,t_0}\}_{j=0}^v, \ell\right) $$

然后一个自回归 transformer 世界模型把这个 latent 拼回历史 world states 上，预测下一段 world state：

$$ \hat{s}_{t_{i,i+1}} = p_\theta^{\text{WM}}(s_{t_{0:i}}, z_{t_{0:i}}) $$

翻译：world model 接受过去的 world state 序列和 latent action 序列，预测未来 world state 区间。注意：这个 world model 是另一个 transformer，不在 VLA 主干里——它只在训练时存在，让 latent action token 学到东西。

③ JEPA Alignment Loss（核心创新）

训练目标可以理解为：让 world model 预测的 $\hat{s}_{t_k}$ 对齐 V-JEPA2 从真实未来帧编码出的 $s_{t_k}$。原始目标是 ELBO 形式：

$$ \log p(s_{t_{1:T}} \mid z_{t_{0:T-1}}) \geq \sum_{k=1}^T \mathbb{E}_{s_{t_k} \sim F(\cdot)}[\log p_\theta(\hat{s}_{t_k} \mid s_{t_k})] - D_{\text{KL}}[F(\cdot) \| p_\theta^{\text{WM}}] $$

因为 $F(\cdot)$ 是冻结的 deterministic encoder，KL 项消失，目标退化成潜在空间的均方误差：

$$ \mathcal{L}_{\text{WM}} = \sum_{k=1}^T \mathbb{E}_{s_{t_k} \sim F(\cdot)} (\hat{s}_{t_k} - s_{t_k}) $$

翻译：让 world model 预测出的潜在 world state $\hat{s}_{t_k}$ 跟"真实未来帧过 V-JEPA2 编码出来"的 $s_{t_k}$ 拉近。关键是：target encoder 的输入是未来帧、但目标向量被 stop-gradient——所以未来信息只作为"目标"，从不向 VLM 主干传梯度。这就是 leakage-free 的具体含义。

④ 动作头：flow matching

对机器人数据，再加一个 flow matching action head（参考 π₀）：

$$ \mathcal{L}_{\text{FM}} = \mathbb{E}_{a_{0:H}, \epsilon, t}\left[\|v_\theta(a_t, t \mid z_a) - (a_{0:H} - \epsilon)\|_2^2\right] $$

翻译：标准 conditional flow matching，让一个 velocity field $v_\theta$ 把噪声 $\epsilon$ 转回真实动作序列 $a_{0:H}$。条件 $z_a$ 是从 VLM 出的"action conditioning representation"，本质上又是一组特殊 token 的 latent。

⑤ 联合训练目标

$$ \mathcal{L} = \mathcal{L}_{\text{FM}} + \beta \mathcal{L}_{\text{WM}} $$

翻译：动作 loss 和 world-model 对齐 loss 加权和。人类视频上只有 $\mathcal{L}_{\text{WM}}$（没动作标签），机器人数据上两个都算。

⑥ 两阶段简化为"一阶段"

区别于前作的三段式 pipeline，VLA-JEPA 实际只用JEPA pretraining → action-head fine-tuning 两步——pretraining 阶段就是上面 ⑤ 的联合 loss，跑在 Something-Something-v2（220K 人类视频）+ Droid（76K 机器人轨迹）的混合上。

关键发现

  • LIBERO 97.2% 均值：超过 π₀ (94.2)、π₀.₅ (96.9)、OpenVLA-OFT (97.1) 等。
  • LIBERO-Plus 79.5%（7 种扰动均值，相机 / 机器人 / 语言 / 光照 / 背景 / 噪声 / 布局）：明显超过第二名 OpenVLA-OFT (69.6)，验证了"潜在世界模型让表征鲁棒"的设计动机。
  • 人类视频对 ID 影响小、对 OOD 影响大：去掉人类视频 LIBERO 只掉 1.1 点，但 LIBERO-Plus 掉 16.6 点。说明人类视频不补充"动作信号"，而是补充"鲁棒性 / 反复抓握"这种技能层面的先验——这跟 π₀.₅ 的"97.6% 非目标数据有用"的发现是同源的。
  • 失败模式：作者诚实指出 VLA-JEPA 在需要细粒度指令理解的任务上不如 π₀.₅（"它有时会去抓不该抓的物体"），但优势是不容易撞到机器人安全边界。这是 JEPA 路线"重感知动力学 / 轻指令对齐"的副作用。
  • 真实机器人：100 demo 训练，VLA-JEPA 在 ID 上 70%，OOD-task 17%，OOD-layout 47%，分别超过 π₀ 和 π₀.₅。

三条贯穿线（三家共享的设计直觉）

共享的三条判断

  1. 动作监督不够用，必须加"未来观察"作为辅助信号——三家用消融实验直接证明了这一点，去掉未来监督的代价比换 attention pattern、改 tokenizer 更大。这是 2026 这一波 VLA 论文最稳定的共识。
  2. 非对称的注意力是关键——动作/未来在自己的 block 内允许双向（捕获结构），跨 block 要保持因果（避免动作"作弊"看未来再生成自己）。MMaDA-VLA 和 UD-VLA 都用 hybrid attention，VLA-JEPA 用时间因果。三家都没人用纯因果或纯双向。
  3. 世界模型不必"输出未来图给人看"，只需"在训练时存在"——VLA-JEPA 把 world model 完全锁在 latent 里、推理时根本不调用；UD-VLA 推理时生图但承认像素质量不高（不给人看）；MMaDA-VLA 生图但目的是让动作和图互相校准。"未来观察"的角色是梯度信号，不是用户产物。

三个最大的分歧（三家选了三条不同的路）

分歧 1：在哪个空间预测未来？

UD-VLAMMaDA-VLAVLA-JEPA
未来表征VQ 离散 tokenMAGVIT-v2 离散 tokenV-JEPA2 连续潜在向量
预测信息量高（要 reconstruct token id）高（同上）低（只对齐潜在向量）
对 nuisance 鲁棒性低（要预测纹理）低（同上）高（VLA-JEPA 的整个动机）
能否生成可视化未来能（虽然糊）能不能

这是三家最深的分歧——离散 token 派（UD-VLA、MMaDA-VLA）认为预测 token id 让模型学到精细的视觉先验，潜在派（VLA-JEPA）认为这条路把模型变成"纹理预测器"而不是"动力学预测器"。两边都有道理：离散 token 派的 benchmark 分数确实更高（98 vs 97 之类的小幅领先），但 VLA-JEPA 在扰动 benchmark 上的优势同样显著（LIBERO-Plus 79.5 vs UD-VLA 没报）。

一个值得记住的对照：VLA-JEPA 在 LIBERO 上和 MMaDA-VLA 差不到 1 个点，但 VLA-JEPA 在 LIBERO-Plus 7 类扰动均值上 79.5%——这个 benchmark 不在 MMaDA-VLA 的报告里，但同一年 OpenVLA-OFT 拿到 69.6%、π₀ 拿到 53.6%。说明潜在派的鲁棒性优势在扰动 benchmark 上更明显，但在干净 benchmark 上没差异。两条路看起来还没分出胜负。

分歧 2：训练范式是"mask-predict"还是"对齐"？

  • UD-VLA + MMaDA-VLA：mask-predict cross-entropy。把未来图当成"另一种 token 序列"用 BERT/diffusion 的损失训。
  • VLA-JEPA：JEPA alignment——直接对齐潜在向量，stop-gradient 切断未来→主干的路径。

这两条线在更广的表征学习里也长期对峙：BEiT/MAE 是 mask-predict，DINO/JEPA 是对齐。VLA 领域把这场争论原样复制了一遍。有意思的是 MMaDA-VLA 和 UD-VLA 的相似度更高（都是离散扩散），而 VLA-JEPA 一开始就站到了对立面——这暗示后续 VLA 演化可能会沿这两条线分叉。

分歧 3：未来观察在推理时"活着"吗？

训练时推理时
UD-VLA未来图监督仍然生成未来图（KV cache + confidence decoding 加速）
MMaDA-VLA未来图监督仍然生成未来图（与动作 chunk 同步去噪）
VLA-JEPA未来图监督（target encoder）不调用 target encoder，不预测未来

这一条是最具操作性的差别：VLA-JEPA 在推理时只用 student（VLA 主干），完全没有未来感知的开销——但代价是模型在动作生成时已经没有显式的未来 token 可以条件，只能依赖训练时学到的潜在表征。UD-VLA 和 MMaDA-VLA 的"推理时生图"则带来额外计算，但换来"动作和未来相互约束"的好处。

一个值得做的实验：让 MMaDA-VLA 或 UD-VLA 在推理时"关掉"未来图生成（只解码动作 token），看动作质量掉多少。如果掉得不多，那么离散扩散派的"未来生图"其实跟 VLA-JEPA 一样只是训练时的辅助；如果掉很多，那它就是 inference-time scaling 的一种实例。论文里没回答这个问题。

放回 π 系列的语境里看一下

读完这三篇再回看 π 系列编年史，会发现一个清晰的分化：

路线核心信念关键资源典型架构
π 路线 VLA 的瓶颈是数据宽度，加更多种、更便宜、更脏的数据；架构基本不动 VLM + flow matching + action chunking（四代没变）；π₀.₇ 才加了 BAGEL 14B 世界模型 纯 SFT → co-training → RL → 元数据 prompt SFT
2026 三家路线 VLA 的瓶颈是监督信号，让动作头被"预测未来"约束着出 世界模型（离散/潜在）作为训练辅助甚至主干能力的一部分 JD3P / mask-predict / JEPA 对齐

两条路线在"世界模型如何参与"上的差别尤其有趣：

  • π₀.₇ 把 BAGEL 14B 世界模型当成独立外挂——它生成 subgoal 图给高层 policy 看，本质是 hierarchical pipeline 里的一个 stage。
  • MMaDA-VLA 和 UD-VLA 把世界模型融进主策略——同一个 forward pass 里出未来图和动作，没有 stage 边界。
  • VLA-JEPA 把世界模型完全消解成 representation loss——推理时连显式的"世界模型"概念都不存在。

这意味着 2026 这波三家的实验在某种程度上回答了 π 系列没有正面回答的问题：世界模型到底应该是外挂、是融合、还是仅作训练监督？ 目前看：

  1. 外挂（π 路线）部署最贵（5B + 14B 同时跑），但容易复用现成大模型；
  2. 融合（UD-VLA / MMaDA-VLA）训练最优雅，benchmark 最强，但推理时图像生成增加延迟；
  3. 消解（VLA-JEPA）推理最便宜，鲁棒性最好，但 benchmark 不会比融合派更高，对指令的精细对齐略弱。

三条路目前都没有压倒性优势——但融合和消解这两条路在 2026 上半年的 4 个月里同时浮现，是个明确的信号：纯靠数据 + 加大 VLM + flow matching action expert 的 π 范式，已经被这一波从不同角度挑战。

共同未解的问题

  • "未来"的合适时距是多少？ MMaDA-VLA 的目标图是 chunk 末端那一帧（短时），UD-VLA 是若干帧（中时），VLA-JEPA 是潜在状态的短片段。没人系统消融过：长时 vs 短时的未来该怎么 trade off？太短不如不预测，太长不如交给 hierarchical 高层模型——中间的最优点在哪里？
  • 能不能合并三家的优势？ 一种自然想法是：用 VLA-JEPA 的潜在对齐作主损失（鲁棒），但在推理时仍然生成离散未来 token 让动作互相校准（精度）。三家都还没尝试这种"潜在派 + 推理时生图"的组合。
  • 视觉生成的像素质量该不该追？ UD-VLA 承认生成的未来帧细节糊；MMaDA-VLA 没特别报；VLA-JEPA 干脆不生成。如果未来的目的只是给动作 prompt，那不追求像素质量是对的；但如果想顺便给人看（用于可解释性、failure debug），像素质量就成了独立问题。
  • 对人类视频的态度差异：VLA-JEPA 把 SSv2 (220K 人类视频) 当成关键 OOD 鲁棒性来源；MMaDA-VLA 和 UD-VLA 没显式强调人类视频。π₀.₅ 也是"非目标本体数据 97.6%"的典型——但他们用的是其他机器人数据，不是人类视频。"人类视频对 VLA 究竟有多大用"这个问题，看起来取决于是否走潜在世界模型路线——离散派靠机器人示教就够，潜在派需要人类视频补 OOD。
  • scaling 还没被验证：三家的主干都在 8B 量级，没人放出"训练数据 × 模型大小"的 scaling 图。π 系列也没。要回答"世界模型 + VLA 这条路能 scale 到什么样"，还需要至少一篇 30B+ 量级的工作。
  • 评估困难依旧：三家都在 LIBERO / CALVIN / SimplerEnv / 真机上比，但每家选的真机平台不同（MMaDA-VLA 用 AgileX Piper，UD-VLA 用 UR5e + Inspire 手，VLA-JEPA 用 Franka），跨论文真机比对几乎不可能。这是 VLA 领域整体面临的问题，不是这三家造的。

读完这三篇可以带走的一句话

2026 上半年，VLA 的主战场从"如何收集更多动作数据"转移到"如何让模型在出动作之前先 simulate 一帧未来"——三种实现方式（离散联合去噪 / 潜在对齐 / 原生扩散主干）都被各自的消融实验证明非要不可。下一步要回答的，是"未来"应该长成什么样、谁来生成、推理时是否还要它。
