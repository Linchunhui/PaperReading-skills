- **MPO / 2610.35013**：先沿完整交互轮构造 GAE，再把轮内 TD trace 去均值后加回，保持整轮平均信用；前向仍是整轮 token 比率乘积，反向只留当前 token 梯度，以免局部信用在共享求导中相消。关键结果判断：4B 搜索成绩改善，但只有一次训练、选最佳 checkpoint 后五次评估；β=1.5 回落与 token IS 对照给出两项设计证据。六栏职责成立，89.5% 的诊断已作为分析而非普遍规律。
- **PDRVLA / 2610.37381**：从 VLM 中间层用固定查询提取物理 token；训练期利用直接未来潜特征预测和冻结视频模型的可回传映射监督；联合策略阶段保留直接头、移除视频模型，部署再移除预测头，动作专家以物理／语义／本体状态生成动作 chunk。关键结果判断：四个仿真总分较强但有明确任务落后；预测 MSE 消融没有隔离动作成功率的因果收益。六栏职责成立，四步 Euler 与八步动作、训练与推理、不同消融基线都区分清楚。

## 第二组：2610.33966、2610.34283、2610.36077、2610.36671

以下记录形成于阅读这四篇候选之后、回看旧稿与 source-record 之前。

- **InteractiveWorld / 2610.33966**：助手给语言指导、执行者落实、环境按物理状态核验，多轮画面使助手能跟踪执行偏差；三层环境把语言转成动作和可检查状态。Pass、MCR、首错和成功子集动作成本分别衡量不同方面。关键结果判断：41.7% Pass 对 Oracle 100% 显示持续协助缺口；Memory 在部分任务改善而 Planning 下降，真人校准仅 36-task 和三人模拟器子集。六栏成立，主成绩与诊断分开，评测本身的方法职责清楚。
- **ChronoReplay / 2610.34283**：按 episode 恢复当前轮合法历史，保留类别／数值／时间接口，再先按答案长度、有效轮归一化，平衡轨迹族与类别保持族；同一个 checkpoint 做多类读出。关键结果判断：固定访问的三基准均值 48.28→56.86 支持训练收益，额外取帧的 57.98 单列；格式控制 OST/UCS 一升一降，族平衡三组成对种子收益更一致。六栏成立，思路是短概括，方法解释了前缀、接口、权重和训练／推理边界。
- **The Trinity / 2610.36077**：冻结骨干，以能力前缀组织任务和 Harness，Creator 生成并验证练习世界，Explorer 改局部模块并按严格提分规则选择性继承父模块；固定池路由只能使用公开任务信息和可验证历史。关键结果判断：四轮迭代在 Train 及 16 个非机器人 Unseen 集合上提高，18 基准摘要集合不同；模拟课程首次构造 token 近翻倍，不能声称更省。六栏成立，完整系统与 module-only、路由 Oracle 与部署信息均区分。
- **LOWN / 2610.36671**：完整视觉前向保存锚点；每步文本前向检查按锚点置信度排序的一致前缀，足够 k 则提交全部前缀，少于 k 则重看图并按分歧优先提交；路由和多 token 提交共同省计算。关键结果判断：0.353 倍 FLOPs、99.6% 平均分仍伴随具体任务退步，2.2–4.7% 提交被新视觉推翻说明一致性不等于正确性。六栏成立，全部推理步骤在方法，质量／成本和消融／可靠性在结果。
