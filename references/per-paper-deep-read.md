# 串讲与雷达：逐篇完整讲解

先完整读取 [paper-storyline.md](./paper-storyline.md)。每篇正式入选论文保留背景、方向、问题、解决思路、具体方法、主结果、消融或分析结论、总结。多篇模式与单篇使用同一内容底线，展开程度随模式、贡献复杂度和用户要求变化。

## 默认深度与范围

- 同方向串讲、日报、周报和月报默认给每篇可独立理解的完整解读。雷达更紧凑地解释关键操作与证据；无需默认复制单篇的逐段带读、全部推导或 Q&A。
- 明确要求“深读/详细/limu”时，围绕难点增加贯穿例子、公式推演、论证位置与实验控制；不能只把短卡换成长句。
- 模式名“雷达/速读”不允许删除八项主线。明确要求仅摘要或字数上限时遵守，并说明产物范围；导航卡不冒充正文。
- 不设默认总字数、单篇长度、屏数或步骤数配额。先完成理解链，再删重复；篇数增加时篇幅相应增加，生成受限则分批保存后合并。
- 全部用户指定与正式入选论文按同一覆盖标准完成，Top picks 只决定阅读顺序。不能只详读前几篇、把后几篇缩成摘要。
- 自选候选原文不足时进入观察区，不计入已完成深读篇数；用户指定项保留位置，给已核实内容与明确缺口。

## 先核对原文与已有记录

逐篇记录标题/版本、方向/任务、来源覆盖、八项主线、承重公式和图表位置、成本与缺失信息。读取引言、相关工作、方法、主结果、消融/诊断、限制以及必要附录，不能只依据 Abstract 和热度生成正式解读。

旧 HTML、Markdown 或结构化输出可提供解释线索和上游证据；核对身份与版本，核心机制、承重数字和结论条件仍回到允许访问的一手材料。本轮已核验的信息直接复用。用户限定只用附件时遵守范围，不把未见部分补成事实。

每个主要判断能定位到小节、Eq.、Table、Figure 或官方代码版本；没有页码就用章节名。区分作者主张、实验观察、受控对照、理论条件和讲解者推断；未知结构、维度、配置、数据、预算不按常识补造。仅有图注不能声称看过原图，未运行代码不能说亲测。

## 每篇正文组织

方向、任务、版本、原文链接放篇首。正文用以下内容块，也可合并背景与问题、思路与方法，但对应职责必须清楚：

| 内容块 | 要完成的解释 |
| --- | --- |
| 背景、问题与前作 | 具体输入输出、必要场景、旧方案怎样做、卡点与后果 |
| 解决思路 | 改变哪个环节，为什么可能解决前面的卡点；区分新机制、沿用组件与工程配套 |
| 具体方法 | 最小完整路线，再解释关键变换与衔接；训练与推理、必要公式、状态或监督来源 |
| 主结果 | 选能支撑核心贡献的比较，说明对照、指标、原始值、预算/协议和支持范围 |
| 消融或分析结论 | 结论先行的要点；关键设计、负结果、饱和/成本权衡及证据条件，缺失则明确说明 |
| 边界与可借鉴内容 | 数据、规模、环境、成本与失败条件；可迁移机制及需要验证的前提 |
| 总结 | 带条件收束这篇的问题、核心变化、关键发现和未解决部分 |

方法不能只给一段箭头串或组件名清单。通常用若干有解释的步骤，不硬凑 4–7 节；雷达保留决定行为的步骤，单篇再展开推导与更多例子。一个简单操作讲清就结束，复杂模块的关键连接不能省略。

主结果回答“整套工作取得了什么”，消融回答“哪些选择支持或限制这个结果”。不将二者挤成只列分数的一段。雷达消融通常用简短结果要点；原文没有相应实验或材料未包含时按共享规范区分。理论、数据/评测和综述使用对应分析证据，不造模型训练或组件消融。

按理解需要保留小例子与关键原文定位；普通雷达不强制逐篇带读两个原文段落。读者仍无法恢复关键过程时，必须展开难点，不能因“紧凑”跳过。

## 配图、回顾与展示

- 优先保留有教学作用的原图，并解释看哪里；可按已核实机制画教学示意。无可核实图片时继续文字讲解并说明缺图，不虚构图中细节。
- 关键数字和比较条件要核对；表格、公式与图不能代替正文解释。公式用原生 MathML 或完整内嵌渲染器离线展示，紧跟白话解释。
- 每篇正文默认展开，建立问题、思路、方法、结果、消融、边界与总结锚点。长报告靠目录与导览组织，不用截断、等高卡片或默认折叠隐藏方法。
- 全报告 recap 是索引式回看，每篇仍有自己的总结；二者不原样重复。共享背景可讲一次，每篇须保留足够的任务定位。
- 图片压缩后内嵌；2 MB 是优化目标，不因体积删除承重内容。公众号版使用同一证据，保留八项主线，删除外围与重复内容。

## 验收

逐篇执行 paper-storyline.md 的覆盖、连贯性、消融结论与证据检查。完整性一致不等于每篇字数相同或雷达必须和单篇一样长。缺项先补证据或标明缺失，解释跳步先补连接，重复扩写先删重复。

HTML 校验通过后还要检查内容：读者能否讲出问题、切入点、实际操作、结果及消融带来的认识？无法讲出就不能把该条标为完成的独立解读。
