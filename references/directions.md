## 横切原则

### 1. 通用能力优先

默认只收通用方法、基座模型、基础理论、通用 benchmark 和能跨场景复用的工程方法。医疗、金融、法律、材料、生物、农业、遥感、自动驾驶产品、工业检测等垂类应用，只有在方法本身可迁移时才保留。

一句话判断：**拿掉行业背景，这项贡献是否仍然成立？** 成立就留；不成立就剔。

### 2. 论文与媒体文章不能混成一种证据

- arXiv / 论文官网 / 项目页是技术主张的一手来源。
- HF Daily Papers 是热度和社区关注度信号，不替代论文原文。
- 量子位、机器之心等媒体用于发现中文解读、产业背景和作者访谈，不替代论文实验数据。
- 媒体文章提到论文时，优先补回 arXiv / 项目页；找不到一手来源就明确写“仅有媒体报道，尚未核实”。
- 同一工作被多个来源报道时只列一次，把其他来源收进“相关解读”。

### 3. 技术密度优先，宣传稿降权

模型发布、融资、产品上线只有在包含可验证的架构、数据、训练、评测或开源信息时才进入技术雷达。纯宣传、纯商业动态、没有原始证据的“全球首个 / 史上最强”默认剔除。

### 4. 一条内容只选一个主方向

允许标多个次方向，但 HTML 中只在主方向出现一次。主方向选择最具体、最能解释核心贡献的那一个：

`OCR > VLA > 世界模型 > VLM > RL > Diffusion LLM > 基座模型`

这不是价值排序，只是避免同一条内容在多个栏目重复。

## 1. Diffusion LLM

**收录**：扩散 / 掩码 / 连续时间去噪直接用于 token、文本序列或语言模型生成，例如 masked diffusion LM、continuous diffusion for text、LLaDA 类模型。

**剔除**：

- 图像 / 视频扩散；
- 用扩散做数据增强但语言模型本身仍是自回归；
- 分子、蛋白质、音频扩散。

**判定要害**：被去噪的对象是文本或 token。

## 2. 多模态 / VLM / MLLM

**收录**：通用多模态基座、视觉语言理解与推理、any-to-any / omni 模型、统一理解与生成、多模态长上下文。

**剔除**：

- 纯 VLA，归 VLA；
- 主打文档 / 文字识别，归 OCR；
- 纯视觉 encoder、检测、分割；
- 医疗影像、遥感、票据等垂类 VLM，除非贡献是通用方法。

**判定要害**：模型本身接收或输出多种模态，核心主张是通用多模态能力。

## 3. VLA

**收录**：视觉 + 语言输入到连续动作输出的通用机器人策略、跨任务 / 跨场景 / 跨本体策略、具身基础模型、世界动作模型。

**剔除**：

- 纯机器人感知；
- 只调用工具或 API 的 LLM agent；
- 单一固定任务的专用策略；
- 只有离散游戏动作、没有机器人连续控制的 RL。

**判定要害**：视觉 / 语言条件真正进入动作生成或控制闭环。

## 4. OCR / 文档理解

**收录**：OCR、场景文字、文档解析、版面分析、表格 / 公式识别、文档图像理解、文档多模态基座。

**剔除**：

- 通用 MLLM 顺带能读字，但论文主线不在文档；
- 无视觉输入的纯文本解析；
- 票据、合同等单一垂类系统，除非方法可迁移。

**判定要害**：核心能力是从文档 / 图像恢复文字、结构或语义关系。

## 5. RL

**收录**：通用 RL 算法与理论、RLHF / RLVR、PPO / GRPO 变体、奖励建模、自博弈、推理期 RL、用 reward 优化通用推理或策略。

**剔除**：

- 纯 SFT；
- 没有 reward / 环境反馈的 imitation learning 或 behavior cloning；
- 把现成 RL 套到金融、分子、单一游戏等垂类；
- 论文只是提到 DPO / RL，但贡献实际在数据或架构。

**判定要害**：reward 或环境反馈参与了策略优化。

## 6. 世界模型

**收录**：学习环境动态、状态转移、action-conditioned future、可交互世界、支持规划或控制的世界表征 / 世界模拟器。

**剔除**：

- 只生成好看视频、没有环境动态或交互主张；
- 静态 3D / NeRF；
- 不含学习过程的纯仿真器工程；
- 固定单一游戏 / 单一驾驶产品的专用模型，除非方法通用。

**判定要害**：模型学的是“世界如何随状态与动作变化”，而不只是像素外观。

## 7. 基座模型 / LLM

**收录**：

- 通用语言基座、推理模型、预训练方法；
- 新架构、MoE、attention / state-space 变体；
- tokenizer、数据配比、scaling law、长上下文；
- 通用 post-training、模型压缩 / 量化 / 推理效率方法；
- 重要开源基座模型的技术报告。

**剔除**：

- 只做一个业务任务的微调模型；
- 纯应用 Agent，没有基座模型或通用训练贡献；
- 只有产品发布 / 参数口号、没有技术报告或可验证评测；
- 已更适合归入 VLM、OCR、VLA、RL、世界模型的工作。

**判定要害**：贡献改变了通用模型的能力底座、训练范式、架构或部署方式。

## 语义精筛输出字段

每条候选在进入 HTML 前补齐：

```json
{
  "keep": true,
  "primary_direction": "vla",
  "secondary_directions": ["world_model", "rl"],
  "why_match": "视觉和语言条件进入连续机器人动作策略，且方法跨任务复用",
  "why_read": "一句话说明真正值得读的技术增量",
  "evidence_level": "primary-paper",
  "drop_reason": ""
}
```

拿不准时宁可不放。`media-only` 可以进入“观察”区，但不能和有论文证据的技术结论用同一语气。
